## 1. 「🎙️ 课堂补充」格的四种状态

### A · 课上展开（有增量）

```
**🎙️ 课堂补充**（`〈起〉`–`〈止〉`，约 〈N〉 分钟）

- 〈教授做了什么〉：*"〈原话，改写用 [ ]〉"*（`〈时间戳〉`）
- 〈第二点 / 例子〉：*"〈原话〉"*（`〈时间戳〉`）
- **这段改变了什么**：〈确认了 §x 的推断 / 推翻了 v0.9 里的 … / 新增了 …〉
```

标杆（M02 §2.3，p.12）：

> **🎙️ 课堂补充**（`57:45`–`58:41`，约 1 分钟）
>
> - 教授把定义念了一遍，然后**明确降权**：*"So actually **you don't have to memorize the terminology**. It's very [easy] to understand. For example, in this case you can see there are many accounts here, each account has a reference number. So this is just called the ledger account."*（`58:09`）
> - 对科目表的口头概括：*"[for] the assets category we have so many accounts here, each [with a] unique reference; for liability we have two of them; and for the equity we have the common stock, dividends, revenue and expense."*（`58:25`；ASR 把最后四个词识别成 *"cholesterol parameters"*）
> - ⚠️ **编号首位 = 类别（1xx 资产 / 2xx 负债…）这条规律教授没有讲**，是笔记补充。

大段展开时用小标题分点（M02 §2.2.2 用 **①②③** 分了"负债类逐个口头解释 / 权益类 / 十笔每账户一例"），并可用表：

> | 科目 | 教授的口头定义（已校正 ASR） |
> |---|---|
> | 应付账款 Accounts Payable | *"our company is [purchasing] something, but we didn't pay cash yet. So that is our company's liability because anyway we will pay in the future."* |

### B · 讲了同讲义（无增量）

```
**🎙️ 课堂补充**（`〈起〉`–`〈止〉`）：教授〈照念 / 简讲〉了这一页，用时 〈N〉 秒——*"〈一句原话或信号〉"*。〈和笔记判断是否一致；有无值得注意的口误〉
```

标杆（M02 §2.2.3，p.10）：

> **🎙️ 课堂补充**（`57:28`–`57:45`）：教授只用了 17 秒——*"the expanded accounting equation look[s] like this… equity can be further divided into common stock, dividend, revenue and expense, [which] we are already quite familiar with."* 这一页在课堂上就是一个"转场"，和本笔记的判断一致。⚠️ 教授在整堂课里**始终把股利和费用当成"同一种处理"**（`14:39` *"it's the same treatment for the dividend and expense"*）……

### C · ⏭️ 略过（有证据）

```
**🎙️ 课堂补充**：⏭️ **这一页课上没讲。** 〈依据：前一页 `a` 讲完直接到 `b` 已在讲 p.N+2；或教授明说 *"…"*（`ts`）〉。〈建议：了解即可 / 仍要会，因为 …〉
```

标杆（M02 §2.1，p.3）：

> - **p.3 这一页 W2 课上没有重讲**——它在 **W1 开场时已经被讲过**（见 M01 §8 `00:01`–`06:18`）。
> - 五步里的前四步在 `01:12:37` 讲 p.21 时被复述了一遍：*"step one, identify transaction [and] source documents… step two, analyze…"*——**教授把第 1–2 步定性为"已经会了"。**

### D · ❓ 未录到（无证据，不可降权）

```
**🎙️ 课堂补充**：❓ **录音范围内没有这一页。** 〈缺失原因：转录在 `ts` 中断 / 第一句已在讲 p.N / 空档 `a`→`b`〉。**不能标成 ⏭️ 略过**——没录到 ≠ 没讲。本节只能靠讲义与笔记学，**不要因为"课上没听到"而降低优先级**。
```

标杆（M02 §2.7.2，p.45–47）：

> **🎙️ 课堂补充**：❓ **录音范围内没有讲到试算表。** 转录在 `01:38:33` 中断，最后覆盖的讲义页是 p.44（`01:33:20`），之后是课堂练习 2。全文检索 `trial balance` 只命中一处，且是顺带一提（`01:15:35`：*"…we rely more on the balance column accounts"*）。**这不能标成 ⏭️ 略过**——按 [[转录处理规则]] §5，没录到 ≠ 没讲……

### E · ↪️ 明确顺延到下一讲

```
**🎙️ 课堂补充**：↪️ **本节留到下一讲。** 教授在〈源 A/B〉`〈时间戳〉` 明说后续继续，且〈源 A/B〉`〈时间戳〉` 已在本讲最后实讲 p.〈N〉 后正式停课。本节仍按讲义自学，**不可降权**；下一讲录音到位后复核是否补讲。
```

双录音同课时，`A`/`B` 表示来源文件、各有独立时钟，和上方格状态 A/B 不同。每条课堂引文应有来源标签与该源时间戳。

## 10. 分片模式的落盘格式（`merge_apply.py` 读取）

### `shard_k/patch.json`

```json
{
 "note": "EF5560_Fintech_and_AI_in_Finance/notes/M03-线性机器学习与收益预测.md",
 "cells": [
  {"section": "#### 2.4.3 LASSO：绝对值惩罚，能把系数压到零（讲义 p.15）",
   "block": "**🎙️ 课堂补充**（`53:29`–`58:22`，约 4.9 分钟，A · 课上展开）\n\n- 解释归零的机制…：*\"[T]he simple change…\"*（`54:01`）\n- **这段改变了什么**：…"}
 ],
 "s8": [
  {"page": "p.15", "coverage": "✅ 详讲 `53:29`–`58:22` + 🎙️ AI 演示"},
  {"page": "p.20", "coverage": "⏭️ 让学生自读 `01:40:23`"}
 ]
}
```

- `section`：小节标题**原文**，或能唯一定位的前缀（`#### 2.4.3`）。`block`：整个 🎙️ 格，第一行必须是 `**🎙️ 课堂补充**…`，到下一个格标签（`**💡`、`**⚠️`、`**所以呢**`…）之前为止，不含结尾空行。四态写法见 §1。
- `page`：与 §8 表第一列一致（`p.15`、`p.14–15`）。
