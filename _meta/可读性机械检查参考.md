# 可读性机械检查参考

本文件记录 `note_quality.py` 的 R v2 口径，供定位问题和维护工具。它不定义教学质量；解释与独立审查执行 [[可读性总规则]]。这些阈值来自库内工程校准，没有真人实验依据，不能据此声称读者能看懂。

## 1. 计量与范围

一个汉字/可见标点为一个阅读单元；连续英文单词或数字串为一个；行内公式、代码各计两个；Markdown 标记和链接目标不计。段内软换行合并；按 `。！？` 切句，分号不切；列表项分别计数。引用、表格、代码、独立公式另按对应规则。

机器主要查 §0–§7 及 T 主体；§8 页码表的长单元格只警告；§9 和标题含复算/来源/核验/日志/验证/脚本的折叠块，主要保留表前空行检查。**人工/agent 审查覆盖所有本次教学内容，包括被机器豁免的教学折叠块和自测答案。** 不得把核心讲解移到豁免区躲检查。

## 2. 现行 R 阈值

下表的“硬项”是机械约束，“疑点”须结合实际文本判断。目标值不作为写作配额。

| 编号 | 硬项 | 疑点/目标 |
|---|---|---|
| R1a | 单句 >120 单元 | 81–120 提示；目标 20–50 |
| R1b | p90 >60；>80 单元句占比 >3% | 目标 p90 ≤50、占比 ≤1% |
| R1c/d | 无 | ≥2 分号；括注 >30 单元 |
| R1e | 一段 ≥4 处否定澄清 | 3 处提示，目标 ≤2 |
| R2a | 段落 >200 单元或 ≥7 句 | 151–200 或 6 句提示 |
| R2b | 列表项 >150 单元 | 81–150 提示 |
| R2c/d | 段内 ≥3 圈号 | ≥4 处加粗提示 |
| R3a | 连续正文 >800 单元 | >500 提示 |
| R3b/c | 五级以下标题；表前无空行 | 实际显示仍需查看 |
| R4a | ≥9 列 | 7–8 列提示 |
| R4b/c | 单元格 >80 单元或 ≥3 句 | >40 单元或 2 句提示 |
| R4d/e | §2 表前无引导 | 一行合计 >200 单元提示 |
| R4f/g | 无 | 列解释/读法启发式 |
| R5a | 段内 ≥6 个不同公式 | 4–5 提示 |
| R5b/c/d | 无 | 并排公式、行内 >60 字符、代码 >30 行 |
| R5e | 正文小数省略前导零 | 用 0.5；原件代码保真 |
| R6a/b/c/d | 无 | 术语密度、压缩或首现解释线索 |
| R7a/b | 无 | 路径/长小数/时间串；长英文嵌段 |
| R8a/b/c | 无 | 页码定位、首段、误解理由线索 |
| R0 | 豁免块 >5 | 必须写具体必要理由 |

未列实现细节以工具实际版本输出定位；发现说明与实现不一致先记录并修正，不推导教学结论。R4f/g、R6b/c/d、R8c 找的是字面线索，不能确认已经解释或尚未解释。

## 3. 运行、保留与豁免

新写/整篇重写保留 `readability_rules: v2`，机械硬项清零；局部修改的历史项处理见 [[笔记制作与融合验收流程]]。不删除/降级字段绕过检查。历史 `readability_spec: sentence-table-v1` 不启用另一套规则。

必要的原表/原话可在块前写 `<!-- 可读性豁免: 具体原因 -->`，同时在附近提供可读解释。不能豁免语义缺口、删除条件、批量修改原件或利用统计范围逃避审查。机器误报保留原始输出和具体处理依据；作者不能无证据成批标“已核”。

统一命令、JSON 能力边界与 current/historical 区分见 [[笔记检查器说明]]。机械通过与独立教学审查、实际视觉查看、来源核验分别记录。
