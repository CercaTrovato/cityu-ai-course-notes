## 教学阻塞

1. **B1 · 酒店状态流程缺资格判定到写工具的硬门槛。** §2.11.6 约 5132–5141 行的正文分清 eligible=true/false/null，并规定仅 true 可继续。5178–5183 行流程图 F 仅问“版本及引用业务约束全核吗”，成功后到 H，再由 I 问“需要下单且批准绑定当前对象吗”。在 H1 三晚 3800 的变式中，版本、证据和“不合格”判定都能验证正确；若读者把 F 理解为“判定核实”而不等于“判为合格”，便能走到 I，误把批准当成可以越过业务硬条件。应把当前、来源、eligible=true 和同对象有效批准分别画清，false 返回不兼容，null 澄清/补证。可用“条件核实但超预算”与“结果为 true 但批准仍在旧版本”两例复核。
2. **B2 · AIME 答案地位自相矛盾。** p.37（413 行）及 §2.8.2 作答下方明说讲义本页仅印题面，2866 行却称“答案 70 以讲义为准”。我按两个进位表达式相减、穷举因数可独立推出 70，能解决题目但无法确定证据标签。保留“按本笔记推导得 70”，课堂仅可定位的进制改写另标；若另有给定答案，在阶段二以具体材料确认。§1.3 149 行称 function calling 在 recap 出现一句，§9.3 6075 行写它未出现，同类口径也须核清，不能把 API 供事实等同完整函数调用讲解。
3. **B3 · p.3–5 缺视频入口，题解无法复做观看。** 三处候选嵌图只显示同一播客封面，§2.2 955–957 行给出播客名和 p.4/p.5 的时间，但没有可定位的资源链接，§8 却称已记录入口。读者可复述访谈片段的转录解释，仍无法从笔记执行观看。阶段二若确认源件链接，按三页各自入口和时间就地链接，播放及核音另标。p.4 的英语直接答语在精读层，应让页级入口一跳抵达该题。
4. **B4 · 时间口径与“长短”判断没有完成同一动作。** §2.6.2 2270 行说整段时长看吞吐，§2.6.3 2305 行加 TTFT 却将 1,000 个 token 全计为首 token 后新增，随后写“短回答看 TTFT，长回答看吞吐”。已知的首 token 不应再计入其后间隔。以连续 1,000 个可见 token 的教学近似，末 token 时间为 13.3+999/302≈16.61 s 与 0.4+999/120≈8.73 s，约到 2,570 token 两者才换序；仍不含工具、停止及核验。给出 $TTFT+(N-1)/r$ 的近似条件，再区分末 token 与任务完成，并统一“字/token”。§6.3 和 §7 第 2 题把两项指标各有一位赢家推成许可类型与速度无关，单一快照只能说明许可不能代替速度测量。
5. **B5 · 每接受成本总费用范围在定义与操作之间漂移。** §2.10.1 4590 行将总费用写成“所有请求的 $C_{req}$ 之和”，但该符号在 §2.6.4 只算 token 账单，§2.10.1 紧接着又允许计工具、人审等。独立拿表来做部署决策会漏算非请求费，甚至反向选型。表内定义改成“按本次评测预先声明纳入的完整工作量费用，失败及重试计入；例仅纳 token 费”，§2.6.4 的“再除成功率”限定为相同统计单位下的平均每任务费用除接受率，别拿任意单次请求价格直接除。§7 案例 2 的“数据不出境”也须跟正文一致写为满足部署、日志及工具数据路径条件后才成立。
6. **B6 · 页级题目回指过宽，部分题的英文只能在主题内部再次寻找。** p.33/37/41/45/49/53/57/69/77–79/81/83/87 都有页级解释或答案，但题目链接多跳到包含数页资料与多个题目的大主题；例如 p.57 要从 §2.8.7 总览经过榜单、公式再找两道原题，p.77–79 三个入口跳同一大节。把每页完整题面与中英解析相邻放入页内，或用精确锚点定位到该页题组并保留就地关键条件。源题转写及必选题列表待阶段二回源，不先给完整认定。
