## 阶段一发现的回源结论和新增阻塞

1. **B1 · 酒店流程的业务门槛。** 保留阶段一结论。原 p.87 只要求识别不兼容选项，教学补图的写操作节点属于新增流程。把“是否核实判定”“判定是否合格”和“是否获当前对象批准”画成不同门槛。三晚、3800 港元且所有材料核验无误时，仍应在资格 false 处分流；当前合格但批准绑 v1 时，也不可执行。
2. **B2 · 答案来源冲突涉及 p.33、37、53，修订阶段一仅指 AIME 的范围。** 直接以实际源 PDF 跑 Poppler 提取文字，p.33 有 C/A/No，p.37 有 72/2/70，p.53 有 Wout Weghorst 和西瓜籽经过消化道的给定解释。重新用原 PDF 渲染三页，与随派单 PNG 的 SHA 分别完全相同，三个可视页都不显示这些答案。不得一律说“PDF 只给题面”或当成可见页脚答案。每问分开记“PDF 文字层含给定答案，本轮页面渲染未显示”，独立推导/外部核验另列。化学机理、体育赛事未独立验证，西瓜籽只限讲义日常误解题。p.45 的 B/C 是源页**可见**答案钥匙，缺配图无法独立作答；p.49、57 的可见给定答案也应保留其来源。§1.3 与 §9.3 对 function calling 的冲突可按源 p.81/87 直接关闭：前者说检索或 API 供事实，后者说 RAG 与 tuning，两页均未讲 function calling 操作。页脚不能单独确认省略内容的主题或未来教学计划。
