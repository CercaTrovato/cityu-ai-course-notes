## 要修的问题

1. **§3.3／§5.1 把 IQR 的数学围栏写成箱须。** §2.4 第 479、497、517–519 行已经正确区分：计算得的 −0.625/6.375 是围栏，须止于范围内实际观察 1/4。到 §3.3 第 918、927–934 行又把 k 写成“须的倍数”、把计算出的 −1 到 7、[1,1] 和 2.94–6.55 都叫“须”；§5.1 第 1331 行沿用。初学者会画错 whisker 或误以为刚好观察到围栏。统一写“IQR 围栏倍数／判别边界”；保留 §2.4 的实际箱须约定。
2. **§4 总图的 G→H 和走读会让读者把缩放结果用于 cell 39。** 第 1284–1291 行明示箭头是状态顺序，又把 G 换尺子接 H；但 §3.4 的 X_std/X_rob 是旁路输出，§3.5 第 1121–1129 行从 air_clean 原单位列（评分已填补）计算 cov/corr/热图，未将两个 scaler 的输出送入。Pearson 对同一成对数据的正线性缩放不变，也不能用来证明实际走了 G，因为协方差会变。改图为 F→G 和 F→H 并标明缩放比较支线，或显式标成讲解顺序、说明 H 的数据来自 F。
3. **§2.2 第 269 行对峰度的表述会误导分布判断。** “峰度近 0 像正态尾”与后面的四阶矩解释之间缺关键限制。建议写“超额峰度近 0 只说明标准化四阶矩接近正态参照；不能判定尾部形状或正态；较大正值说明极端偏差在四次方里贡献更强”。同段 §5 英文 std 定义宜把“平方偏差和除 n−1”明确放进开方括号。
4. **§7.3.1 的原题范围有一处缺口。** 表把 id 判为名义字段，但“每个类别变量的频数与百分比”解析未解释为何七个类别字段频数表不列 id。§1.4 已给 68,133 个 id 无重复，直接补“id 每个值频数 1、约 0.001468%，用唯一值汇总，不枚举所有标识”；不要在表里生成个人标识。§7.3.3 的 dtype 与两图目前靠历史 HTML，阅读路径清楚，但第 1706–1723 行部分名义/序数条目缺明确“离散”、current_grade 缺连续／记录精度说明，补原题要的完整字段口径；HTML 跳转及数据属性可信度待第二阶段。
