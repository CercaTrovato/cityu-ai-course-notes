## 断点

1. **M06-A｜p.86 的截止日文字会少算当日。** §2.24.1 三条上游步骤分别写“资产负债表日之前”，与 ThroughBSDate 及本节“截至报表日”读法冲突。例 7/31 报表、7/31 当日收到 100，日期小于 7/31 将漏收款并高估应收 100。保留截图未知，参考规则明确包含截止日；若含时分秒用下一天排他边界，且按入账/履约或应用生效事实定日期。
2. **M06-B｜p.92 的日期策略并非必须写在 ON。** §2.24.7 说“必须放在外连接的 ON”，同段正确建议 Access QBE 先建期间子查询，p.92 页级也采用先筛。统一成“先限制匹配侧，再保留左侧”；可通过预筛、合适方言的 ON 表达。继续保留仅有期外记录 E99 的反例，后置 WHERE 即使 OR CallID IS NULL 也不能救回。
3. **M06-C｜QBE 多表仍能漏连接。** §2.14 说“必须手工拖一条线”或自动有线，容易让人以为设计视图会阻止未连接查询。本例两表 5×4 可组合 20 行。改为显式检查连接线及 Join Properties，既有关系可自动带出而未建时须手工连；没线时不能直接 Run 后把笛卡尔积当内连接。也可在 p.64 提示不能把已有 1/∞ 自动认作所需连接方向。
4. **M06-D｜扩展附件已有和上游定义缺源需统一。** §2.24.1 旧句写“仍需缺失的原数据库与前置查询”，另处已说本批有扩展表，只缺具体保存定义、参数及截图同版性。写清已到位的附件与未证实的原查询层，讲义画面能复算的是有限结果，不把附件已得当七题全部实际重现。
5. **M06-E｜没有分配不能表述成确认从未收款。** §2.10.1 S-6/7 不在 Duality 被直译为“一分钱都没收”，与 §2.25.3 对收款日志、应用及业务完整性的限定冲突。改成“本例没有已记录对应分配，无法从表判断已实现账期”；E-78 “一单没开”的描述也可收在“给定七笔销售无该编号”。p.88 的“未售”同样限给定期间、已知完整记录。
6. **可改善的入口。** §1.3 预习从 p.34–38 做，但整页图本身已给答案。可在深读先读英文题或提示把 p.33 的输入和题面抄出，后翻图核对；p.54 的 Show Table 图片默认高亮 Cash，正文应明说操作要另选 CashReceipt。§1.3 重排说明可准确区分前半页级 31 屏与后半按查询归组。前述都是在现有候选基础上可直接修正的路径。
