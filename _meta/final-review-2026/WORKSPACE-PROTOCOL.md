# 五课复习工作区：固定框架与逐轮接续

生效：2026-11-27。依据本人 11/23 原始策略与 11/27 当前要求；本文件是工作规则，不是完成学习的证明。

## 目标与职责

目标是学会识别题型、选方法、解释与独立作答，并最终完整覆盖全课。本人2026-11-27明确选择：**先完成考试范围和模拟，再补不考内容的完整学习**。考试所需的少量前置就地补足，不因此把整章排除内容提前列为必修；模拟后仍做复盘/补弱，再走全课补全。采用逐步互动：先了解已有理解，再讲一个小点、做题、必要提示、改条件复测；不一次灌输整章，也不替本人回答。

总监督负责跨课安排、来源缺口、进度汇总与共享看板收尾；讲解、出题、批改和学习记录由对应复习会话在本课 review/ 内完成。最终收尾会话继续管作业，不在复习工作区改提交状态。文件是接续依据，不要求本人复制聊天或靠跨会话消息传递。

## 固定的框架与可调的路线

- `final-2026/framework.md` 固定知识范围、单元 ID、目标、依赖、题型与原有教学入口；`framework-lock.json` 保存本轮正文 SHA-256 与单元结构。原有五课共 73 主单元，IS5542 另有 U12A–E 五个子单元。
- `final-2026/exam-guide.md` 是当前考试依据。教师新增说明可修订考试优先级、排除、题型与携带材料，但保留来源版本，不把明确不考的内容从全课框架删除。
- `final-2026/route.md` 只改当前停点、下一轮目标、练习深度/顺序及调整理由。保留旧顺序和变化依据；不能因为一次答错反复重构课程或删掉难点。跨过前置时应有实际回答或补桥记录。
- `final-2026/progress.json` 继续沿用本课现有字段和状态枚举，是学习结果的机器入口；不要统一重命名旧字段、重编单元或清空历史。`next_step` 与 route 的下一步必须一致。
- `preparation.md` 管资料准备和待补责任；`sources.json` 管来源身份和版本。取到资料、完成教程、看过讲解、独立做对、延后复测是不同状态。

需要改变知识骨架或学习目标时，先向本人说明具体变化；获得明确决定后再升框架版本并保留旧映射。事实勘误和新正式考试通知可以及时写入 exam-guide/来源记录，不必等待骨架重建，也不默认获得网站提交/发送权限。

## 每次进入课程复习会话

1. 读本课 `review/AGENTS.md`、`README.md`，再读本规则。
2. 读 `exam-guide.md`、`preparation.md`、`framework.md`、`route.md` 和 `progress.json`；再读最近一轮 session、当前未关闭错题与相关源页。
3. 从文件报告当前停点与下一步。没有 session 只是未登记学习，不等于本人毫无基础；先问实际进度，不能把旧聊天结论覆盖新文件。
4. 按一个小点开展互动。区分概念、读题、计算、英文表达卡点；先让本人尝试，再逐级提示。教学按根/课程规则核源；不靠诊断删除全课覆盖。

## 每轮结束必须落盘

一轮是一组已经发生的知识点互动，不是每一句消息。本人还没答题时只能登记等待，不能造答案、错题或分数。

将实质对话整理为 `sessions/YYYY-MM-DD-NN-unit-id.md`，保留：

- 日期、session ID、对应稳定单元、来源页/题号和题目身份（教师原题/自编/往届线索）。
- 本人关键原问题与原作答，提示先后和纠错过程；长原话可折叠，但不能只留“已讲清”。保留大部分有学习价值的问答，不要求保存工具输出或无关闲聊。
- 讲解中的知识、可复用做题步骤、常见误读、必要英文关键词与答题表达。
- 独立作答/提示后作答/未作答、用时、评分依据与未知；看过题面或解析分别记录。
- 本轮停点、仍不会什么、下一轮动作；延后复测安排是计划，实际发生后才写通过。

真实错答才在 `mistakes/` 建条目，引用 session 与题号，记错因、本人原答、纠正理由、后续变式及关闭证据。不因代理预判容易出错就记成本人错题。session 内容先按适用规则完成一次独立轻量抽检，再原子写回；原始本人作答与学习事件不因待审丢弃，但未审解析不得称教学已验收。

随后同批更新 progress（保留本课枚举与证据）、route、README 的当前停点；写前比对哈希，写后回读。补弱/路线调整不能把既有成功记录抹掉，若复测失败则新增带日期的表现与下一步。

## 检测与模拟

教学题、已看答案的题和独立检测题分开。每课模拟前核题面/解析是否已经见过、真实考试格式和材料条件。优先用可靠且未曝光的教师题；不足时制作明确标为自编的平行卷并按规则独审，不冒称真题。完整模拟后逐题复盘，再用新情境延迟复测；练熟原题高分不等于独立检测通过。

## 资料与检索边界

当前教师讲义、当期公告、最后复习课和教师 mock 优先；带时戳口述与 ASR 不冒充人工逐字听校。官方往年卷仍须核课程/学期和适用性；学生回忆与商业指南只作补充，逐条回源后才能进入训练。不得声称“全网搜尽”；记录实际查过的入口、查询、日期、取得范围与尚未取得项。

遇登录、权限、付费或必须本人确认的材料缺口，具体说明需要本人协助什么；继续独立可完成的工作。已决定跳过的 Studocu Premium 不再自动重开；IS6400 两份未另发数据保留原数值缺口，用明确自编数据练方法，不冒充原题结果。

## 保存、检查与三端同步

沿用电脑与手机 Remotely Save 自动同步已关闭的既有确认，不开启同步；未观察实时手机状态不得声称新核。原件只读，scratch 在库外。使用 safe_write.atomic_write、任务隔离完整性基线、写前哈希与写后精确回读。

每轮先执行 `_meta/tools/review_workspace_check.py --course <课码>` 核框架和记录引用；它不认证教学正确或本人掌握。然后按 SUPERVISION/ONLINE-SYNC 同批完成本批 GitHub 资料保存及远端核验、本地看板回读、线上发布回读。课程负责本课记录；总监督负责共享收尾；无跨会话发送授权时在本课 handover 写清待收尾，不发送消息或改他课。

看板读取真实 sessions/mistakes，不能靠改更新时间生成完成度。分开列已讲、提示后会做、独立做对、复测通过的数量与证据；不把等权单元比例解释为学习时长/考试通过概率。失败逐端保留状态与下一步，不谎称同步完成。
