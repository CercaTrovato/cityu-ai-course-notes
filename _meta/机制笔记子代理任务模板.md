# 机制笔记子代理任务模板

按 [[机制理解与可读性标准]] 的当前简化流程执行。调用者设置 `reasoning_effort: medium`；提示词中写“中推理”不能代替调用参数。获得用户授权后才派子代理，本轮已授权只读 vault、在任务临时目录产候选，由主代理统一写库。

本轮全量整改的范围、图文理解和验收时机优先按 [[可读性总规则]] §1.3、§11.3、§14 执行：逐篇全正文，评估重点只决定排序；所有候选完稿后集中语义与视觉验收。代理只写 scratch，不调用下级代理或派中途验收；最多一次整篇作者自查。模型按管理者明确派单参数，规则编辑本轮指定 gpt-6.1-sol，不推定其他代理已采用该模型。

## 一次给清楚任务

将以下变量替换为真实路径和主题，再派发；不要把未替换模板当成可执行任务。

```text
任务：修复 <课程/模块> 的课堂笔记；输出完整正文候选和精确改动。
读者：没听过课；具体算法第一次见；财会、金融、伦理、法律零基础。
允许读取：<现笔记、课程规则、概念台账、原材料、已有源审报告的绝对路径>。
写入范围：仅 <vault 外的本任务 scratch 目录>。
禁止：写 vault/原件/作业；读取个人评分成品；提交、推送、联系其他会话。
核心清单：<逐项列本讲实际用到的算法、系统、计算和推理；明确背景项理由>。
已知错误：<逐项给旧文字/位置、正确口径及来源；无需重复完整源审>。

语言与完整性：先读 [[可读性总规则]]。每句话先明确具体对象、动作、结果，
再用术语概括；一句多个步骤/条件就拆开，写出因果或计算的中间理由。
不是只解释词名，也不只修开头/末尾类比。表格逐列解释符号/缩写、单位、
频率/分母、算法或来源与一行实际读法；如t须给统计问题、标准误、完整例和
判定条件，区分时间下标。复算API/行数/误差日志集中§9或折叠，保留证据。
逐篇覆盖导读/预习/正文/速查/自测答案及全部适用教学内容，不只改3个抽样难段，
不只做句号/编号或R机械清理。日期、公式数值、原题、英文来源、引用、转录
内容与状态保真，尽量保留完整标题，必要改标题须附受影响引用的精确补丁。
图文理解按总规则§11.3；图数无配额，已有有效图保留，每张新增图有具体学习
目的和至少1个例子走图。候选frontmatter保持readability_rules: v2。
报告具体改写与剩余难点，不声称用户已看懂，不以L/G PASS验收可读性。

每个核心必须有：具体问题、输入输出与参数角色、状态步骤、真实控制/数据流图、
操作所需符号读法与原理依据、同一小例贯穿到输出/停止、实际边界、至少两项
失败/条件变式与有理由答案。类型要求取并集，不用L0或“定义型”免讲。
保留既有逐页正文、原题答案与课堂英文实文；新例/新推导标“笔记补充”，
原数据不足列已知/未知及能得到的结论，不能编官方数值。

交付：exact-byte read-before.md + before_sha256；candidate.md；changes（唯一old/new）；
图文需求记录（章节/目的/障碍/保留或补图理由）；图源路径及来源；render状态
与实际观看范围（未看须待核）；教学语义/视觉验收保持pending。

新重要数字的实际calc/results；必要结构诊断与真实来源限制。
mechanism_review 保持pending；主代理合并和最终记录。不编Q/R分数。
完成一篇就交回，再处理下一篇，不等整个课程包完毕。
```

## 写候选时的具体约束

- **基线不可覆盖**：首次保存原 bytes；已存在先核 SHA 再复用，失败立即停该补丁。修改后增量另存新 base，禁止重跑旧 builder 读取已修稿覆盖原基线。
- **插入点行首锚定且唯一**：`###` 是 `####` 的子串，裸替换会破坏层级。匹配完整标题行，验证恰一处；保留原编号标题，避免重复补段。
- **数学转义安全**：优先在 Markdown 文件写 LaTeX，再读入候选；Python 中使用 raw string。实际控制字符 `\t`/`\f`/`\b` 不能混成 `\times`/`\frac`/`\bar`。货币美元按渲染规则转义，英文实文不改。
- **图的语义自足**：拒绝、未知和正常出口清楚；纠错重试要恢复本步前状态；每轮候选/概率按当前状态重算。长流程优先纵向，关联图边标签拥挤可用完整关系表重画，不制造业务先后。
- **创作与验收时机**：复用已有源审，对新增重要计算真算，法律/标准核一手版本与时间；必要渲染与防损允许，但不登记教学通过。最多一次整篇作者自查；全部候选完稿后集中教学语义与视觉验收，旧 E 标签/篇幅分只定位缺口，不机械凑标签或重复全库验收。
- **报告范围**：SQLite 不称 Access 实跑；解析不称看过最终图；字段存在不称有实质内容；代理产笔记不等本人通读/学会；材料融合版本不等机制验收。

所有代理只在 scratch 保存基线、候选、图源和补丁。最末管理者发起单一发布者按基线→候选精确合并，写前重读并比对 `before_sha256`／CAS，调用 `safe_write.atomic_write`；源文件有冲突立即中止该补丁并报告，禁止覆盖或重建他人修改。发布后的文件完整性与嵌入目标须核对；教学验收未过不写通过。提示词降低跑偏，不替代实际数字、来源和安全证据。工具不可用时保留待补范围，不为关闭状态编造完成。
