# 机制笔记子代理任务模板

作者与审查者的任务分开派发，不能由同一代理审自己写的内容。读者统一为高中知识起点，具体深度按 [[可读性总规则]] 与 [[机制理解与可读性标准]]。独立审查的长期授权、模型层级、执行顺序与异常分支见 [[笔记制作与融合验收流程]] §3；不要复制旧“本轮已授权”或固定模型参数。

## 1. 作者任务单（需要委派制作时使用）

```text
任务：<课程/模块；新写/重写/融合；真实范围>。
读者：没听课的高中知识起点初学者，不默认会 ML/金融/会计/法律/微积分/Python。
只读：<规则、课程细则、台账、目标原稿及全部来源的绝对路径>。
只写：<E:/app-data/codex/scratchpad/英文任务目录/作者子目录>。
禁止：改 vault/原始材料/个人状态；提交推送或联系其他会话。
核心任务与背景边界：<真实清单及来源，不把本讲关键操作留黑箱>。
已知限制：<材料缺失、时间戳/源版本/已确认错误>。

先读总规则、机制标准、模板和制作流程，按任务依赖组织。
先具体问题、对象和动作，写中间结果及为什么，再接术语/公式和边界。
七格不强制展示；来源、完整原题/选项、逐问中英解析、正文术语配词保留。
同一例走到任务终点；图区分真实控制/数据/因果/关系，图旁给具体读法。
补充标来源，不造数或官方答案；代码运行/推演/未运行如实区分。
不为脚本凑字数、标签、图数、类比、短句或空白，不把 PASS 当教学质量。
可以必要回源、复算、渲染和一次作者自查；不提前填写教学通过。

交付：原始 bytes 副本及 SHA（不得覆盖）、候选、真实修改范围及学习单元、
来源/计算记录、图源/实际观看状态、已知难点和未核事项。
教学保持待独立审查，由主代理统一处理和写回。
```

## 2. 独立高中知识起点审查任务单（必须）

默认新建无写作历史上下文的审查代理。先把下方第一阶段交给它，待 `stage-1.md` 落盘并由主代理确认后，再用 follow-up 提供第二阶段规则/来源/diff/机器输出。第一派单不给第二阶段路径，不把作者卡点或预期答案写进提示。保留第一阶段原文及后续修正理由；两个阶段属于一次审查，不重复全篇。

```text
你负责独立可读性审查，不参与撰写/直接修改候选，不给分。
读者起点：高中日常语言、四则运算、简单代数/百分数；无本课经验。
你仍需保持专业准确，但不能替正文补充专业知识后判通过。
候选：<绝对路径及 SHA-256>。
派单范围：<全篇，或本次全部新增和受影响单元；包括图/摘要/自测依赖>。
可读的教学前文/链接：<真实路径>；未在范围的旧内容不冒称复验。
只写：<scratch/stage-1.md> 与 <scratch/independent-review.md>；不改 vault/候选/用户字段。
第一阶段只形成 stage-1；第二阶段形成/更新 independent-review，保留 stage-1 原文。

第一阶段：只读候选与必要教学链接，不读作者结论、脚本分数、旧审查报告。
先从正文自行识别学习任务与直接依赖，再逐单元顺读，解释对象、量、动作、理由和结果。
按任务实际复做/作判断，并改一个关键条件检验是否能迁移。
遇到仅凭前文无法继续的一步先记断点；不得用常识脑补。
检查具体例如何回到正式规则，类比是否丢失条件，图表与文字是否同义。
未看图明确写未看；不能将“我会”写成“正文教会了”。
保存 stage-1.md，注明候选 SHA、识别的范围、首次卡点与未核项，返回主代理。

第二阶段由主代理另一次 follow-up 提供以下材料后才进行：

读取 <总规则/课程细则/机制要求/原始基线与 diff/来源与必要计算/机器疑点路径>。
核派单范围与实际变化/依赖是否一致，漏审有教学影响的内容须补审。
引用前文须记录候选中实际回链和唤醒句，回链不能替当前单元补核心步骤。
核真实缺口、来源限制、误报与偏好；不因原题/标签/脚本齐全撤销真实断点。
每个问题给位置/短摘录、此时初学者的问题、现有解释、缺的桥梁、可能误读、
最小修复建议。任务无法完成、会答错或必须借助未教的专业知识是阻塞；
任务已可独立完成，仅措辞/额外同型例是建议。争议项给具体卡点/误答输入。
没有问题也写实际学习动作和正文依据，不靠打勾证明。
列全部受审单元、未核范围、候选 SHA、作者/审查者真实标识及阅读条件。
不造真人评分，不宣称所有高中生看懂，不替作者补整篇答案，不重写正式文件。
```

## 3. 定向复核任务单

```text
你是本篇原独立审查者。最终候选 <路径/SHA>。
原发现 <报告路径>；修复范围 <单元/差异与依赖>；主代理的事实核对 <证据>。
仅复核实际缺陷及受影响依赖，核正文是否补上关键桥梁且未改错来源/条件。
保留原发现，逐项记录关闭依据或仍阻塞；新增问题如实列，不重新给整篇评分。
更新你自己的独立报告，注明最终候选 SHA 和实际复核范围。
若修改超出原范围明确需补审，不能只更新哈希声称复核完成。
```

## 4. 安全与完成边界

代理只写指定 scratch；主写者写前核真实基线，精确合并唯一锚点，原子写并回读。数学 LaTeX 保留反斜杠，脚本避免字符串转义损坏；标题变动同步精确链接。事实/源题/个人状态不因教学改写改变，发现并发差异停相应补丁。

主代理必须读审查报告、核执行身份与范围，处理阻塞后再做机械记录门槛。审查记录的字数/字段完整不证明教学有效；工具缺失或无法独立审查时按流程保留待审，不伪造结果。
