# Obsidian 五分钟上手 + 本库使用说明

---

## 1. 打开这个库

**✅ Obsidian 已装好，直接用就行。**

| 项 | 内容 |
|---|---|
| 版本 | **1.13.7**（Windows 桌面版最新；1.13.8 只发了 Android 包） |
| 安装位置 | **`E:\Obsidian`**（按要求装在 E 盘，C 盘无残留） |
| 快捷方式 | 桌面 ✅ ／ 开始菜单 ✅ |
| 卸载 | Windows「应用和功能」里搜 Obsidian，或运行 `E:\Obsidian\Uninstall Obsidian.exe` |
| 安装日期 | 2026-09-09 |
| 来源校验 | 官方仓库 `github.com/obsidianmd/obsidian-releases`；SHA256 与 winget 官方 manifest 逐位一致 |

**首次打开（30 秒）**

1. 双击桌面的 **Obsidian** 图标
2. 首次启动显示 vault 选择界面 → 点 **Open folder as vault**（打开文件夹作为库）
3. 选 `D:\上课资料\CityU`
4. 完成。**不需要导入、不需要转换**——Obsidian 直接读文件夹里的 `.md` 文件

> Obsidian 个人使用免费，**不需要注册账号**。启动时若提示登录，直接跳过即可。

> Obsidian 只会在库里多出一个 `.obsidian/` 文件夹存配置，不改动你的任何笔记文件。
> 你随时可以用记事本、VS Code 打开这些 `.md`，它们就是普通文本文件。

## 3. 本库的约定

### 双链 `[[...]]`

笔记之间一律用 `[[文件名]]` 互相引用，点击即跳转。指向某一节用 `[[文件名#小节标题]]`。

**链到一个还不存在的文件是正常的**——它显示为灰色，表示"这个东西以后会有"。比如 M01 里链到了 M02，而 M02 还没写。

### 文件命名

- module 笔记：`M01-主题.md`（两位数字，保证排序正确）
- 目录前缀 `_` 的文件夹（`_meta`、`_prep`）是元数据层，不是笔记正文

### frontmatter

每篇笔记开头 `---` 之间的部分是属性（课程、周次、状态等）。Obsidian 会在笔记顶部把它渲染成属性面板。

`status` 字段的含义：
- `v0.9` = 只根据讲义写的，还没合并课堂转录
- `v1.0` = 已合并转录

`transcript` 字段：
- `none` = 那节课没录音，**永远不会有**
- `pending` = 有录音，转录还没导出
- `merged` = 已合并进笔记

### 折叠的答案

自测题的答案用 `<details>` 折叠，在 Obsidian 的**阅读视图**（`Ctrl + E` 切换）里点击才展开。**在编辑视图里答案是直接可见的**，做自测时记得先切到阅读视图。

### Mermaid 图

本库的图都用 Mermaid 代码块写，Obsidian **原生支持**，不用装插件。切到阅读视图就能看到渲染后的图。

## 4. 建议开启的两个设置

| 设置 | 路径 | 为什么 |
|---|---|---|
| **显示属性面板** | Settings → Editor → Properties in document → `Visible` | 一眼看到笔记状态（v0.9 还是 v1.0、有没有转录） |
| **默认阅读视图** | Settings → Editor → Default view for new tabs → `Reading view` | 自测答案默认折叠，Mermaid 图默认渲染 |

## 5. 可选插件（都不装也完全能用）

| 插件 | 用途 | 值不值 |
|---|---|---|
| **Dataview** | 用查询语句自动生成表格，比如"列出所有 status = v0.9 的笔记" | 笔记攒到 10 篇以上再考虑 |
| **Spaced Repetition** | 间隔复习。可以直接把术语卡变成抽认卡 | 考前一个月装，很值 |
| **Excalidraw** | 手绘图 | 想自己画图时 |

> ⚠️ 本库的笔记**不依赖任何插件**。所有内容用原生 Markdown + Mermaid 写成，换任何编辑器都能读。这是有意的设计——避免被工具锁死。

## 6. 手机上看

Obsidian 有 iOS / Android 客户端。同步方案：

| 方案 | 说明 |
|---|---|
| Obsidian Sync | 官方，收费，最省心 |
| iCloud / OneDrive / 坚果云 | 免费，把 vault 文件夹放进同步盘即可 |
| 不同步 | 手机上只看 Notion 的进度看板，笔记只在电脑上看 |

> 你已经在用 Notion 追踪进度，手机上**看进度用 Notion、看笔记用电脑**是最省事的组合。真需要手机看笔记时再考虑同步。
