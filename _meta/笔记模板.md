# Module 笔记模板

模板负责导航，教学方法见 [[可读性总规则]]。保留 §0–§9 外层结构；这是十个编号区块（旧称“九节骨架”），不再强制每个概念七格展示或固定定义优先。Tutorial 可按 cell/任务组织 §2，保留适用的复习、来源和状态信息，不生搬 Module 页码。

## 使用说明

先读制作流程、概念台账和全部本讲材料，列真实学习单元及依赖，再在库外任务目录分块写候选。不要等长输出结束才保存，不使用固定 token 上限或行数作为工具事实。各块合并后检查结尾、结构和来源；正式库用 `safe_write.atomic_write` 与写前/后哈希核对。

七格原本关心的定义/动机、原例、课堂补充、通俗解释、误解和知识关系仍需按实际教学任务考虑，**不要求七个标题或重复内容**。按问题与推理依赖呈现；已有解释能兼顾多个职责，不为填格重复。转录工具实际依赖的 `**🎙️ 课堂补充**` 材料定位块仍保留，见下文，不能混同七格教学模板。

### ★ 预习可用性：讲义每一页都要有实质讲解（2026-09-09 用户决定）

重排不减覆盖。每一内容页须在 §2 有实质解释，封面/学习目标等非内容页明确分类并说明依据；学习目标接到相应学习单元。行政页要解释现行要求，课堂略过不删自学内容，图片/嵌入对象无法读取明示缺口。§8 映射不能代替讲解，页码命中不能证明覆盖。

### 题目、公式与代码

执行 [[课件题目处理规则]] §2b，完整原题、全部选项及逐问中英解析在 §2 对应位置，长题可折叠保真；中文任务入口先帮助读者定位，不能用译解替代原文。公式用 `$…$` 或单独 `$$…$$`；不用代码块/反引号写数学，表格数学竖线用 `\mid`。讲解顺序、符号/单位/算例和代码逐步解释按总规则 §8。

## frontmatter

填写真实值；日期未知用 null 并说明，不猜课次/周次，不把 pending 改成通过。新写/整篇重写保留机械口径 v2；框架字段不代表审查已执行。

```yaml
---
course: <课程码>
module: M0N
week: null
date: null
source:
  - <原材料及确定版本/页数>
transcript: pending
prerequisites: []
new_concepts: []
tags: []
status: v0.9
updated: <真实日期>
readability_rules: v2
teaching_standard: novice-v1
---
```

`transcript` 取 pending/none/merged 等真实材料状态；`status` v0.9 表示尚无转录的讲义稿，v1.0 表示已完成所声明材料融合。独立审查范围和结果记录在回执，不用材料版本或 status 代替。

## 转录接口与交付

已有笔记的课堂定位块、§6.1/§8/§9.1/§9.2/§9.5 及工具所需结构按 `transcript-merge/reference/formats.md` 保留；新单元将课堂块放在相应讲解附近，不让原话打断关键计算。没有转录也保留真实材料状态。融合工具未迁移前，不能随意改标签/锚点导致解析错位。

完稿必须按 [[笔记制作与融合验收流程]] 派独立高中知识起点子代理审查，处理缺陷并通过必要机械/来源/视觉/文件检查；再正式写回和完成 §6 同步。只改模板不表示所有旧稿重新验收，未完成审查不得交付教学通过。
