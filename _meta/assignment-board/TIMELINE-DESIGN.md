# 时间线界面改版依据与验证

2026-11-11。用户指出原版是冗长任务清单、难以看清整体安排，要求按模块或横向日历展示。

## 参考与采用

- [Linear Timeline](https://linear.app/docs/timeline)：实际查看官方产品图。借鉴分组、时间尺度和里程碑的层次，主屏集中展示安排，粒度更细的说明通过详情进入。
- [Asana project views](https://asana.com/features/project-management)：同一数据可切换不同视图。采用横向日历和模块概览，保持任务、日期、状态、证据和导出契约同源。
- [monday.com Timeline Widget](https://support.monday.com/hc/en-us/articles/360017206280-The-Timeline-Widget)：参考分组、日期尺度和里程碑区分。正式节点用明确文字和菱形，内部建议用标签及虚线边框，不单靠颜色。

## 本看板具体取舍

- 默认四周横向日历，支持七天、前后翻页和今天。跨课按课程分行，单课按工作模块分行，也可跨课按模块聚合。
- 一格先展示两项，余项通过“还有 N 项”进入完整列表；项目说明、下一步、依赖、验收和历史进入右侧详情，不在主屏堆长文。
- 模块概览按块展示记录分布与下一步。分布不等于真实工时或作业总体完成百分比。
- 无实际开始日期就不画跨度条。已完成项目只有真实 completed_on 才放入日期格，不能把计划日期或 observed_on 当完成日期；其余通过完成记录入口查看。未排期与范围外事项另有明确入口，不静默丢失。
- 继续提供总监督个人事项、搜索、JSON 导出和助手读取入口；不改变课程事实、数据结构或只读权限。
- 修复四周被长标题撑出屏幕的问题；390px 窄屏只在日历内部横滚，左侧固定模块，详情占满屏宽。后台刷新在时间线数据未变时保留当前视图和详情。
