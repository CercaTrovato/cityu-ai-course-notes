# 分散录音批处理规则

本规则补充 [[转录处理规则]] 的接收、归属与接缝步骤；教学、独立审查、原子写回及同步继续按 [[笔记制作与融合验收流程]]，公开与云端保存按 [[备份与公开发布规则]]。一个文件可以跨多个讲次，一次课堂也可以对应多个文件。

## 1. 先收集来源，再命名课程

先盘点用户指定的微信下载目录、本地录音机、转录工具历史库与课程目录。只处理课堂候选；音乐、合成配音、项目会议等另列排除依据，不因同在聊天目录而纳入课程。截图中的文件名是线索，不能证明下载完成、实际内容或新增状态。

每个来源先给本批稳定 ID，保存原始路径、原名、设备／应用、字节数、完整 SHA-256、媒体时长及容器日期原值。复制到库外本批持久目录并复核哈希；保留原件，不把“复制并改名”解释为允许移动、删除来源或修改音频头。课程和讲次未定时，使用 ID，不先假定 part1。

文件系统创建／修改时间、微信发送／下载时间、媒体 creation_time 分开记录；全部只作线索。实际授课日期需有用户说明、课堂内容、可信录制墙钟与课表等证据；单一导出时间不升级为上课日期。

## 2. 三层去重与复用

1. 文件 SHA-256 相同：字节级重复，保留各来源路径，复用一份有效转录，不重复计为新课。
2. 文件哈希不同，但同编码的全部音频包序列、包数与解码参数相同：记录容器不同、音频载荷一致；保留双方文件哈希与载荷哈希，可以复用已有转录，但不宣称文件逐字节相同。实现须明确串行哈希的包边界（包长度与字节），并记录 codec、采样率、声道与 extradata，不能只凭大小或时长判重。
3. 转码、剪辑或只有时长相近：只列疑似对应。用多个分散窗口的课堂语句／声轨确认同源、覆盖边界和时钟关系。时长相近、文件名相近、相同课名都不足以判重；不能丢掉可能互补的片段。

已有转录和已融合笔记不因重新导出同一音频而再升级材料版本。重转需要有实际质量问题／新参数依据，并保留原版本与重转原因；改变容器日期本身不需要重转。

## 3. 先识别归属，再转录全文与对齐

核现有本地环境和缓存模型，优先复用；安装／下载环境仍按用户授权处理。首尾短样本只用于初筛，不能当全文、完整性或隐私检查。自动语种误判、静音幻觉、复读和数字识别必须保留疑点；不能把错误语种样本直接写进笔记。实际课堂混合语言要保留，不因统一英语过滤丢掉实质中文。

全文转录保留每个来源独立的零点、原始分段及生成参数；校正版不覆盖原始识别证据。保留机器删除片段／疑点。每源独立 scan，通读全文后按 10–15 分钟对齐，记录全部教学、练习、行政及未纳入原因。

建立来源到课堂／讲次的多对多映射：源 ID → 相对时间窗 → 课程 → M/T/上一讲顺延 → 讲义页／notebook cell → 证据与置信状态。一个源跨讲时保留整份音频和原时钟，不能拆分后伪造新零点；一个源只到课堂中段时不得声称覆盖整堂。

## 4. 用接缝证据决定 part、A/B 或未知

对每条可能接缝保存前源末句、后源首句、共同语句／声轨锚点和检验结果，判为连续、重叠、确定缺口或未知。只有确认先后才用 partN；大范围重叠用固定 A/B 或来源 ID。来源 ID 在排序改变后不变。

无共同锚点、只有话题可接续时，写“内容支持先后，接缝连续性待核，缺口长度未知”。不能用编号顺序、独立时钟、两段时长相加或语义跳转推算课堂总时长。精确时长与覆盖率须说明计算分母；未知重叠保留未知，不能硬凑完整课堂。

多源引文逐条携带固定来源 ID 与该源原时间戳，核本源局部文本及数字。多文件审计的时间戳／词集并集不代替逐源核验；覆盖不明仍标 ❓、不可降权。课堂略过／明确顺延须有既有规则要求的实质证据。

## 5. 状态分开，分包闭合

每源登记：已定位、已复制并核哈希、身份待核／旧源复用、全文转录、通读对齐、教学候选、独立审查、正式融合、本地命名归档、Drive 上传／回读、Git 远端核实。状态须有产物路径和实际证据；“转录完成”不等于“融合完成”，某包已闭合不代表整批完成。

按已确认的课程／学习单元分包，完整候选先审、问题定向修复、主代理单一写回。处理一个来源也要核受影响的前后讲、M/T、摘要、考点和作业事实；保留他人并发改动，写前比基线哈希。手机和电脑同步关闭确认在本批持续有效。

运行脚本、进度、原始清单、中间转码和候选放库外 scratch；需长期留存的来源、处理证据与回执放本批持久输出目录。根目录不新增全库 ZIP，不以保存产物为由删除来源。正式课程目录只放已确认命名的音频副本、转录和来源清单；原音频不入 Git，按既有 Drive 规则上传并回读。未完成项以来源 ID、原因及下一步列清。

## 6. 本次验证出的具体边界

2026-10-25 的微信“新录音 15/16/17”重新导出后，文件哈希改变而音频包字节序列与包数一致；媒体 creation_time 也变成导出当天。因此同名不能直接当重复，不同文件哈希也不能直接当新课堂，导出日期不能冒充授课日期。具体哈希及实现版本见本批来源回执，不修改旧回执的历史事实。

## 7. 本批实际补强：公开节选、物理段数与证据冻结

近处私谈和课堂混在一轨时，允许先发布有保守区间清单的课堂文字节选，明确原始段数、选取段数、排除段数和本机原件；节选不能叫完整转录。音频未形成可公开副本时保持本机，不为追求上云率直接传全文件。公开文本去除的段首不能继续充当唯一引文定位，改用公开课堂段首并保留原时钟；区间终点只是定位时须说明不是声学结束时刻。

同秒时间戳并集会把多源物理段数折叠，甚至出现coverage大于1；必须分别报物理段数、逐源引用核对和来源缺口，不能用audit统计推整堂完整。转码/归一化会改变波形，分散样本相关仅提供有限同源证据，不降阈值伪称完整音频身份。编码全身份与有限样本两种结论分开。

release绑定的对齐/来源/截图证据在包完成后冻结。后续来源继续对齐使用新版本文件，例如align-final，不能覆盖旧已绑定文件后只重算哈希冒充旧审查。云端元数据仅界面四舍五入大小时如实记录，精确字节/哈希未取得就保持未核；不绕过浏览器安全策略补验证。
