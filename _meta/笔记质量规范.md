# 笔记质量规范（可量化 · 可脚本检查 · 与写作者无关）

> **一句话**：把"透彻、可读"从形容词变成一张固定的元素清单 + 一组有校准依据的阈值，让任何写作者（不论模型、推理强度、当天状态）照着做都能写出与 IS6400 M02 同等透彻的笔记；写不出时，`_meta/tools/note_quality.py` 能抓住。
>
> **起因（2026-09-16）**：IS6400 M03 / M04 通过了当时全部脚本检查（逐页覆盖、伪公式、表格、锚点、小节首元素、对抗自检 12 项），用户却明确指出它们"可读性差、没有照顾到没有知识基础的读者、知识没有解释透彻"，明显不如同课 M02。原因是现有规则是**定性**的——"先说人话""术语就地解释""公式配数字例子"这些要求 M03/M04 在形式上全都做到了（七格 22/22、15/15 齐全，每条误解都带理由，公式都有符号表），但每个概念只得到 M02 三分之一到一半的讲解量、一个小节塞 3–4 个概念、"换个说法"只是复述。**形式检查抓不住"薄"。** 本规范补的正是这一块。

**与现有规则的关系**（避免两套规则打架）：

## 1. 读者画像 → 写每一段之前的三问

读者画像不变：**商科硕士，统计 101 学过但忘了大半，Python 会一点，第一次见这个术语，没听过课。**

把它变成每写一段之前必须过的三问（写作者自问，脚本查其后果）：

| 三问 | 答不上来时的动作 | 脚本对应 |
|---|---|---|
| **Q1 这段话里有没有一个词，是读者第一次见、而我没停下来解释的？** | 就地加括号解释（中文 + English + 一句人话），或补一句唤醒 | §6 术语首现、§4 先修唤醒（E 层） |
| **Q2 读者读完这段，能不能不看讲义、自己把这个概念说给别人听？** | 说不出来 = 只有定义没有理解。补"为什么需要它""换个说法"或一个手把手例子 | §5 元素清单（E 层）、G1 密度 |
| **Q3 这段是我在讲，还是讲义在讲？** | 引用讲义可以，但引用之后必须有自己的话把它翻译成人话 | own_cjk（报告项）、§5.1 是什么格结构 |

> 校准时的一个反直觉发现：**引用多不是问题**。M02 的引用块占比 0.47 反而高于 M03（0.27）/ M04（0.21）——因为 M02 大量引用转录里教授的原话。问题不在引了多少，而在引了之后有没有讲。所以引用占比只报告、不设门槛。

## 2. 粒度规则：一个小节讲一件事

这是校准里**最能区分好坏**的结构性指标（附录 A）：

| 指标 | 4 篇透彻标杆 | M03 / M04 | 阈值 |
|---|---|---|---|
| §5 术语数 ÷ leaf 小节数 | 0.72–1.16 | 1.82 / 2.07 | **≤ 1.6** |
| 内容页数 ÷ leaf 小节数 | 1.36–2.17 | 3.14 / 4.33 | **≤ 2.5** |

**规则**：

1. **一个 leaf 小节（###/#### 的最底层标题）原则上只承载 1 个新概念**；配对概念（支持度 / 置信度、Lasso / Ridge、名义 / 序数 / 区间 / 比率这种必须并列讲的一组）最多 4 个，且并列讲时每个概念仍要有自己的"是什么 + 例子 + 误解"。全篇平均 ≤ 1.6。
2. **一个 leaf 小节原则上覆盖 ≤ 3 页讲义**；超过 3 页的连页（如 10 页的 PCA 几何推导）必须拆成 `####` 子节，每个子节一个台阶。全篇平均 ≤ 2.5。
3. **拆分的依据是概念而不是页码**：同一个概念散在 p.32 与 p.35–39 就合成一节（M04 §2.7 的做法是对的），一页里有两个概念就拆成两节。
4. **承载术语的小节不得少于 150 字**（G2c）。这只是防"标题党"的地板，不是目标；目标见 §3 的密度门槛。

> ❗ M03 §2.9「集中趋势、分位数与离散程度」用 630 字讲了均值、中位数、众数、百分位数、四分位数、极差、IQR、方差、标准差 9 个概念（每个 70 字），这就是"薄"的典型形态。按本规则应拆成 §2.9.1 中心在哪（均值/中位数/众数）、§2.9.2 分位数、§2.9.3 散得多开（极差/IQR/标准差），每节各带自己的七格。

## 3. 三层判定与阈值（脚本 note_quality.py 的逻辑）

```
PYTHONIOENCODING=utf-8 /d/anaconda3/python.exe _meta/tools/note_quality.py <笔记> [--pages N] [--tut] [--strict|--legacy] [--sections] [--json]
```

| 层 | 内容 | 不过怎么办 |
|---|---|---|
| **L 合规** | 原 `notecheck.py` 七项：逐页覆盖、伪公式、表格管道 / 货币 / 双链别名、标题特殊字符、围栏与 details 配对、同文件锚点 | 逐条列出，退出码 1。**必须修到 0** |
| **G 硬门槛** | 下表 10 项。阈值来自附录 A 的校准 | 任一不过 = **FAIL**，不许标 v0.9 |
| **E 元素清单** | §4 先修唤醒 + §5 每型必备元素 + §6 术语首现 | **strict 模式**（frontmatter 有 `quality_spec: v1` 或 `--strict`）计入 FAIL；**legacy 模式**（2026-09-16 之前写的笔记）只报 △ WARN，判定写 `PASS（存量宽限）` |

### 3.1 G 硬门槛（M 笔记）

| 编号 | 指标 | 阈值 | 校准依据（标杆 → M03 / M04） |
|---|---|---|---|
| G1 | §2 中文字数 ÷ **内容页** | **≥ 250 字/页** | 547 / 288 / 342 / 320 → 172 / 131。取 250 给标杆最低值 288 留 15% 余量 |
| G2a | §5 术语数 ÷ leaf 小节数 | **≤ 1.6** | 1.16 / 0.72 / 0.80 / 0.98 → 1.82 / 2.07；IS5113 M03 的 1.52 判为可接受（其密度 357） |
| G2b | 内容页 ÷ leaf 小节数 | **≤ 2.5** | 1.55 / 1.36 / 2.17 / 1.91 → 3.14 / 4.33 |
| G2c | 承载 §5 术语的小节字数 | **≥ 150** | 防标题党地板（M02 最短的承载术语小节 §2.10.3 为 159 字） |
| G3a | 小节首元素 | 必须是段落（引用块可以；表格 / `$$` / 代码块不行） | 模板可读性第 5 条，原 ⑦ 项 |
| G3b | 每个独立公式（双美元号）的符号 | 都要"有着落"：同节 ±30 行内有符号表；或公式后 8 行散文用行内公式逐个点名；或该符号在前文带符号表的公式 / 散文里出现过；或公式自带 `\underbrace` / `\text{中文}` 注释；或是纯数字代入式 | 模板可读性第 3 条 |
| G3c | 有独立公式的小节 | 必须有数字例子（正文或表格里出现 `= 数字`、`≈`、小数、千分位数） | 同上 |
| G3d | 每个 `python / sql / bash` 代码块 | 前 3 行内有"在做什么"的段落，后 8 行内有逐行说明（表格 / 列表 / 「逐行」标签） | 模板可读性第 4 条 |
| G6 | 「所以呢」 | 每个 `###` 单元（含其 `####` 子节）至少一处，覆盖率 ≥ 0.80 | 模板可读性第 6 条；按单元算是因为 EF5560 M02 把它放在每组子节的末尾 |

**内容页**的定义：讲义总页数 − §8 表里被标为下列类别的页。类别是**固定词汇**，脚本按它算，写作者不得自创：`封面` / `章节标题页` / `学习目标页` / `分隔页` / `空白页` / `行政页`（评分、联系方式、日程）/ `安装截图页`。写法：§8 该行的「笔记小节」列写 `—（封面）`，或「内容」列含这些词。**每标一页都要在 §1.3 或 §9.1 说明理由**——这是唯一能降低 G1 分母的手段，所以必须可审计。

## 4. 先修概念：L0 不等于"可以直接用"

台账把"统计：均值、中位数、方差/标准差、分位数、正态分布"划进 L0-A，意思是**不必开一节讲它**。但读者画像是"统计 101 学过但忘了大半"，M03 §2.9 一句"方差与标准差是 L0，只列符号"就是把读者丢下了。本规范在台账之上加一层：

| 概念在台账里的位置 | 处理 | 最低形态 |
|---|---|---|
| **L0-零**（真正无需解释）：平均数、百分比、表格、行 / 列、模型、训练集、准确率、变量、函数（编程意义）、`for` 循环等 L0-B | 直接用 | — |
| **L0-唤**（统计 101 / 线代 / 微积分：中位数、众数、方差、标准差、标准误、正态分布、分位数、对数、指数、概率密度、期望、相关系数、协方差、矩阵、向量、转置、逆矩阵、特征值 / 特征向量、导数、梯度、假设检验、p 值、t 值、置信区间、显著性、方差分析、卡方、似然、线性组合、内积、欧氏距离、熵、自由度、残差、$R^2$、标准化、偏度、峰度、条件概率、贝叶斯） | **在本篇 §2 第一次用到时给一句话唤醒**，之后随便用 | 括号 ≤ 30 字：`标准差（一列数平均离均值多远）`；或 §1.1 表里有它一行 |
| **L0-唤 且本讲要拿它算东西**（如 M03 要算标准差、M04 要求特征向量） | **升级为 L1，在本篇就地展开**（是什么 / 为什么 / 数字例子），并登记回台账 | 完整七格中的至少 是什么 + 数字例子 + 常见误解 |
| **L1，首现 < 本讲** | 回指 `[[M0X#小节]]` + 一句话唤醒（台账原规则） | 同 L0-唤 |
| **L1，首现 = 本讲** | 完整七格 | §5 |
| **L1，首现 > 本讲** | 一句话预告 | — |

**脚本**：E 层「先修唤醒」用上表 L0-唤 词典逐词查 §2 首次出现处：25 字内有括号、或同行有 `[[回指]]` / `§x.x` 指向、或该词在 §1.1 表 / §5 术语卡里 → 通过；否则列出。**不允许的写法**：`见 M02`、`L0，不解释`、`略`。

**"必须重讲而不能只回指"的判定规则**：本讲的公式、算例或代码**直接操作**这个概念（把它当输入或输出）→ 必须重讲（第三行）。仅作为背景提到 → 唤醒即可（第二行）。例：M04 PCA 里"特征向量"是要算的对象 → 重讲；M03 §2.9 提到"正态分布下 IQR ≈ 1.35 s" → 唤醒即可。

## 5. 概念分型与每型的必备元素清单

§2 的每个 leaf 小节属于且只属于下面一型。脚本按标题 / 内容启发式判型，写作者可在标题下一行用 `<!-- 类型: 公式型 -->` 显式指定（Obsidian 不显示 HTML 注释）。**元素用固定的加粗标签**，脚本靠标签识别——标签写错一个字就等于没写。

### 5.0 所有概念型小节的共用元素（继承模板七格，另加「所以呢」收束句）

正文七格及「与其他概念的关系」以 `_meta/笔记模板.md` 为准；下表列出质量量表检查的共用标签。「所以呢」是七格之后的收束句，由 G6 按 `###` 单元检查，不替代概念关系说明。

| 固定标签 | 要求 | 脚本查什么 |
|---|---|---|
| `**是什么**` | 两句结构：**第一句**不含任何新术语，说"这是在解决什么问题"，带一个生活化或本课数据里的具体例子；**第二句起**才是严谨定义（可引讲义原文）。承载术语的小节，自己的话 ≥ 80 字 | 标签存在；what_cjk ≥ 80 |
| `**为什么需要它**` | 不讲清这个读者记不住。至少回答一个："没有它会怎样" / "它在本讲漏斗的哪一步" / "考试或作业哪里用" | 标签存在 |
| `**课件原例**` | 讲义的例子 + `（讲义 p.XX）`。没有就写"讲义此处无例子" | 标签存在（不作门槛） |
| `**🎙️ 课堂补充**` | 无转录写"待转录补充" | 标签存在（不作门槛） |
| `**💡 换个说法（笔记补充）**` | **≥ 2 个独立角度**（各自成段或列表项，每个 ≥ 40 字），**其中至少 1 个不靠数字**——类比、比喻、反过来说、用读者已有的东西打比方。"再算一遍 Iris 的数字"是数字例子，不是换个说法 | alt_angles ≥ 2 且 alt_nodigit ≥ 1 |
| `**⚠️ 常见误解**` | **≥ 2 条**，每条 `❌ 错误说法 → 为什么错 / 正确的是什么`。理由必须有 `→` 或 `——` 或"因为 / 其实 / 而是" | misc_n ≥ 2 且每条带理由 |
| `**所以呢**` | 一句：这个概念在本讲漏斗里处于哪一步、下一节为什么接着讲 | 每个 ### 单元至少一处 |

### 5.1 定义型（一个术语、一个分类、一个框架）

共用元素 + **判定口诀**（放在换个说法里：读者怎么一眼判断"这是不是 X"）。分类型（名义 / 序数 / 区间 / 比率这种）另加**每一类一个本课数据里的例子**。

### 5.2 对比型（A vs B、两条路、三种方式）

共用元素 + **对比表**（列 = 被比的对象，行 ≥ 3 个维度：定义 / 什么时候用 / 优点 / 缺点 / 本课例子）+ **判断口诀**（"看到 ___ 就选 A"）。脚本查：小节内有表格。

### 5.3 公式型（小节里有独立公式）

共用元素 + 下列六件，缺一不可：

| 固定标签 / 形态 | 要求 |
|---|---|
| 公式（独立公式，LaTeX） | 见模板「★ 公式与代码的写法」 |
| 符号表（表头含 `符号`） | 每个符号一行：是什么、单位、**已知还是要算的** |
| `**数字例子（手把手）**` | 见 §7：至少 3 步、每步一行算式、最后一个结果能和讲义或脚本对上 |
| `**为什么公式长这样**` | 逐项解释：为什么相乘 / 为什么除以这个 / 为什么 $n-1$ / 为什么开根号。**这是 M03/M04 全部公式型小节共同缺的一件** |
| `**极端 / 边界情况**` | 至少 2 个："全是一类时 = 0""两类各半时最大""分母为 0 时无定义""完全线性时 = 1"这类 |
| 常见误解 ≥ 2 | 至少 1 条针对公式本身（分母、符号、范围） |

### 5.4 算法流程型（一个过程：CRISP-DM、梯度下降、递归特征消除、PCA 五步）

共用元素 + **编号步骤**（`1.` `2.` … 每步一行，写清输入 → 动作 → 输出）+ **手算一遍**（用课程数据或讲义数据走完整个流程，每步给中间结果）+ **停止条件 / 什么时候别用它**。

### 5.5 案例数据型（一个数据集、一页 Excel 算例、一个课堂小测）

通用结构（此类型的「换个说法」可省）+ **数字全部标脚本来源**（`脚本 xxx.py`）+ **读法**（这组数字告诉我们什么，两句话）+ **换一组数会怎样**。

### 5.6 图表读法型（直方图、箱线图、散点矩阵、平行坐标…）

通用结构（此类型的「换个说法」可省）+ **怎么读**（横轴 / 纵轴 / 一个点 / 一根线各代表什么）+ **图会怎么骗人**（≥ 2 条误解，例如"箱线图看不出双峰"）+ **本课数据画出来长什么样**（文字描述，数字来自脚本）。

### 5.7 代码型（小节主体是代码块）

`**这块在干什么**` → 代码块 → `**逐行**`（表格或列表，每个关键行一句） → `**输出**`（实际输出的关键数字） → `**为什么这么写**`（换个参数会怎样） → `**⚠️ 易错点**`。这是 T 笔记的标准形态，M 笔记里的代码块也照此。

### 5.8 勘误型（讲义写错了）

`**是什么**`（错在哪）+ 讲义原文引用 + **正确版本** + **考试怎么写**（按讲义还是按正确的） + `**所以呢**`。

### 5.9 行政型（评分、日程、安装截图、教材）

> 示范保持一个小节以便对照；正式返工时按 §2 粒度规则应拆成 §2.11.1 协方差 / §2.11.2 相关系数。

### 12.1 现状（薄版，637 字，覆盖 5 页 = 127 字/页）

**是什么**

先说人话：想知道"SAT 分数高的学校毕业率是不是也高"，就看两列数是不是**一起变**——一个高于均值时另一个是否也高于均值。协方差是这个"一起变"的原始度量，但它的大小随单位变；相关系数把它除以两个标准差，压到 −1 到 +1 之间，单位就消掉了。

讲义 p.29 用 **Colleges and Universities** 数据（49 所文理学院与研究型大学）提出三个问题：Top 10% HS 与 Graduation % 有关吗？Acceptance Rate 与 Expenditures/Student 有关吗？Median SAT 与 Acceptance Rate 有关吗？

讲义 p.30 **协方差**：

> A measure of the **linear association** between two (continuous) variables, X and Y.

$$\text{总体（COVARIANCE.P）: } \operatorname{cov}(X,Y)=\frac{\sum_{i=1}^{N}(x_i-\mu_x)(y_i-\mu_y)}{N}, \qquad \text{样本（COVARIANCE.S）: } \operatorname{cov}(X,Y)=\frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{n-1}$$

讲义 p.32–33 **相关系数**：

> A measure of the linear association between two variables, X and Y. **Unlike covariance, the scale of variation of each variable does not influence correlation.** The correlation value is **always between −1 and +1**.

$$\rho_{xy} = \frac{\operatorname{cov}(X,Y)}{\sigma_x\,\sigma_y}$$

> Correlation is **linear** concept, it may not be able to recover **nonlinear** relationships.（p.33，配四张散点图：(a) 正相关 (b) 负相关 (c) 无相关 (d) **一条 U 形曲线——有明确的非线性关系但线性相关为 0**）

| 符号 | 含义 |
|---|---|
| $x_i, y_i$ | 第 $i$ 个对象在两个属性上的值 |
| $\mu_x, \bar{x}$ | X 的总体均值 / 样本均值 |
| $N, n$ | 总体 / 样本大小；样本版分母是 $n-1$ |
| $\sigma_x, \sigma_y$ | 两个变量的标准差 |
| $\rho_{xy}$ | 相关系数，无单位，$-1 \le \rho \le 1$ |

**课件原例**（讲义 p.31，纯图片页，已视觉复核）

Excel 表格算 Graduation %（X）与 Median SAT（Y）的样本协方差：Mean(X) = **83.245**、Mean(Y) = **1263.102**；每行算 $(x_i-\bar{x})(y_i-\bar{y})$（第一行 Amherst：93 − 83.245 = 9.755；1315 − 1263.102 = 51.898；乘积 506.27），Sum = **12641.77551**，Count = 49，**Covariance = 263.3703231**（= 12641.78 / 48），与 Excel 的 `COVARIANCE.S` 一致。旁边散点图 "Graduation Rate vs. Median SAT" 呈明显正相关。

**为什么需要它**

相关系数是 T03 作业第 2.4 题的主角（相关矩阵 + 热力图 + 找与 `log_price` 最相关的 3 个特征），也是 M02 多重共线性的探测工具（Airbnb 里 `accommodates` 与 `beds` 相关 0.829——[[IS6400_Business_Data_Analytics/_meta/数据集卡片\|数据集卡片]] §5.1）。**协方差为什么还要教**：它是 M04 PCA 的核心对象（协方差矩阵的特征向量就是主成分），本讲先把它的定义立住。

**🎙️ 课堂补充**

待转录补充。

**💡 换个说法（笔记补充）· 数字例子**

T03 cell 39 对 Airbnb 算出与 `log_price` 的相关：accommodates **0.578**、bedrooms 0.483、beds 0.470、bathrooms 0.377、review_scores_rating 0.081、number_of_reviews −0.025。读法：**0.578 是"中等偏强的正线性相关"**——能住的人越多价格越高，但远不是决定性的（0.578² ≈ 33%，这与 T02 回归 R² ≈ 0.4–0.5 的量级一致）。

**协方差 vs 相关的直觉**：把 Graduation % 从"百分数"改成"小数"（93 → 0.93），协方差会缩小 100 倍（263.37 → 2.63），相关系数**一个字都不变**。所以横向比较两对变量谁关系更强，只能用相关系数。

**⚠️ 常见误解**

- ❌ "相关系数 0 = 没关系。" → p.33 图 (d)：U 形关系相关为 0。相关只抓**线性**关系，散点图必须一起看。
- ❌ 把协方差的大小当关系强弱。→ 协方差 263 大还是小？没法说，它带着 "%×分" 的单位；只有相关系数可比。
- ❌ 分母写成 $n$。→ 讲义 p.30 明确区分总体版 $N$ 与样本版 $n-1$；pandas 的 `cov()` / `std()` 默认用 $n-1$。

**所以呢**：相关系数量的是"一起变"，但"一起变"不等于"一个导致另一个"——下一页讲义专门泼冷水。

**薄在哪**（对照 §5.3 公式型六件套）：符号表有、数字例子有（Amherst 一行），但 ① "是什么"第二句起就是三段讲义引文，读者不知道"乘积"在干什么；② 没有"为什么公式长这样"（为什么相乘、为什么除以 $n-1$、为什么除以两个标准差）；③ 没有极端 / 边界（ρ = ±1 长什么样、分母为 0）；④ "换个说法"两段都是数字，没有一个类比；⑤ "标准差"没有唤醒；⑥ 一节两个概念、五页讲义。

### 12.2 按规范重写（厚版，1683 字，337 字/页）

**是什么**

前面几节都在描述**一列**数字（它的中间在哪、散得多开、形状歪不歪）。这一节换成**两列**：比如 49 所大学，每所都有"毕业率"和"SAT 中位数"两个数，我们想知道——**SAT 高的学校，毕业率是不是也高？** 光看两列数字看不出来，需要一个能把"一起变"量化成一个数的工具。协方差（covariance）就是这个工具的原始版本：它把每所学校"毕业率比平均高多少"和"SAT 比平均高多少"相乘再取平均，同向就为正、反向就为负。相关系数（correlation coefficient）是它的标准化版本：把协方差除以两个标准差（standard deviation，一列数"平均离均值多远"，M03 §2.9 刚讲过），结果被压进 −1 到 +1 之间，单位消掉了，任何两对变量都能横向比较。

严谨地说，讲义 p.30 给协方差的定义是：

> A measure of the **linear association** between two (continuous) variables, X and Y.

讲义 p.32–33 给相关系数的定义是：

> A measure of the linear association between two variables, X and Y. **Unlike covariance, the scale of variation of each variable does not influence correlation.** The correlation value is **always between −1 and +1**.

两个定义都强调 **linear**（线性）——这个词是本节所有陷阱的根源，后面会反复回来。

**为什么需要它**

它是本课后面三处内容的地基：① T03 作业第 2.4 题要求算相关矩阵、画热力图、找出与 `log_price` 最相关的 3 个特征；② M02 讲过的多重共线性（两个自变量高度相关时系数不稳）就是用相关系数探测的——Airbnb 里 `accommodates` 与 `beds` 相关 0.829（[[IS6400_Business_Data_Analytics/_meta/数据集卡片\|数据集卡片]] §5.1）；③ M04 的 PCA 要对**协方差矩阵**求特征向量，主成分就是从协方差里长出来的。协方差本身不好读（单位怪、大小没法比），但它是这三处的共同起点，所以讲义先立协方差、再立相关系数。

**课件原例**（讲义 p.29、p.31；p.31 为近纯图片页，已视觉复核）

p.29 用 **Colleges and Universities** 数据（49 所文理学院与研究型大学）提出三个问题：Top 10% HS 与 Graduation % 有关吗？Acceptance Rate 与 Expenditures/Student 有关吗？Median SAT 与 Acceptance Rate 有关吗？

p.31 是一张 Excel 表，算 Graduation %（X）与 Median SAT（Y）的样本协方差：Mean(X) = **83.245**、Mean(Y) = **1263.102**；每行算 $(x_i-\bar{x})(y_i-\bar{y})$，第一行 Amherst 是 $93 - 83.245 = 9.755$、$1315 - 1263.102 = 51.898$、乘积 $9.755 \times 51.898 = 506.26$；49 行的乘积加总 Sum = **12641.776**，除以 $n - 1 = 48$ 得 **Covariance = 263.370**，与 Excel 的 `COVARIANCE.S` 一致（脚本 `verify_w3w4.py` 复算 263.3703）。旁边的散点图 "Graduation Rate vs. Median SAT" 呈明显正相关。

**公式**（讲义 p.30、p.32）

$$\text{样本协方差：}\quad \operatorname{cov}(X,Y)=\frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{n-1}$$

$$\text{相关系数：}\quad \rho_{xy} = \frac{\operatorname{cov}(X,Y)}{s_x\, s_y}$$

| 符号 | 是什么 | 已知还是要算 |
|---|---|---|
| $x_i, y_i$ | 第 $i$ 所学校的毕业率、SAT 中位数 | 已知（数据） |
| $\bar{x}, \bar{y}$ | 两列各自的平均值 | 先算 |
| $x_i-\bar{x}$ | 第 $i$ 所学校的毕业率**比平均高多少**（可正可负） | 中间量 |
| $n$ | 学校个数（p.31 里是 49） | 已知 |
| $n-1$ | 样本版分母；总体版（`COVARIANCE.P`）用 $N$ | 讲义 p.30 两版都给了 |
| $s_x, s_y$ | 两列各自的样本标准差（§2.9 的 $s$） | 先算 |
| $\rho_{xy}$ | 相关系数，无单位，$-1 \le \rho \le 1$ | 要算的结果 |

**数字例子（手把手）**：p.31 的 49 行太长，这里用 5 所学校的迷你版走一遍（💡 笔记补充，数字由脚本 `demo_cov.py` 算出）。毕业率 X = 80, 85, 90, 75, 95；SAT Y = 1200, 1250, 1300, 1150, 1400。

1. 先算均值：$\bar{x} = 85$，$\bar{y} = 1260$。
2. 每所学校算"比平均高多少"再相乘：

| 学校 | $x_i-\bar{x}$ | $y_i-\bar{y}$ | 乘积 |
|---|---|---|---|
| 1 | $80-85=-5$ | $1200-1260=-60$ | $(-5)\times(-60)=300$ |
| 2 | $0$ | $-10$ | $0$ |
| 3 | $5$ | $40$ | $200$ |
| 4 | $-10$ | $-110$ | $1100$ |
| 5 | $10$ | $140$ | $1400$ |

3. 乘积加总 $300+0+200+1100+1400 = 3000$，除以 $n-1 = 4$：$\operatorname{cov} = 3000 / 4 = 750$。
4. 两个标准差：$s_x = 7.906$，$s_y = 96.177$（都是 §2.9 的 $s$ 公式，脚本算的）。
5. 相关系数：$\rho = 750 / (7.906 \times 96.177) = 750 / 760.3 = 0.986$——几乎完全正相关。pandas 的 `Series.cov()` / `Series.corr()` 给出同样的 750.0 与 0.9864。

**为什么公式长这样**：第 2 步的"乘积"是整个公式的灵魂。学校 4 毕业率低于平均（−10）、SAT 也低于平均（−110），负负得正，乘积 +1100——它在为"一起变"投赞成票；如果某所学校毕业率高、SAT 反而低，乘积就是负数，投反对票。把所有票加起来再平均，就是协方差：正数说明多数学校同向偏离，负数说明反向。除以 $n-1$ 而不是 $n$，和 §2.9 样本方差的理由一样——用样本均值代替真均值会让偏差偏小，少除一个把它补回来。相关系数再除以 $s_x s_y$，是因为协方差的单位是"%×分"，把毕业率改用小数记（0.80 而不是 80）协方差会缩小 100 倍（脚本验证：750 → 7.5），而相关系数纹丝不动（0.9864 → 0.9864）——除掉各自的尺度，剩下的才是纯粹的"同步程度"。

**极端 / 边界情况**：
- 两列**完全在一条上升直线上**（比如 $y = 2x + 3$）：$\rho = 1$（脚本验证）；完全在下降直线上：$\rho = -1$。这就是"−1 到 +1"两端的含义。
- 两列**有明确关系但不是直线**：$x = -2,-1,0,1,2$、$y = x^2$，散点是一个 U 形，但 $\rho = 0$、协方差也是 0（脚本验证）。这就是讲义 p.33 图 (d) 的情况——**相关只抓线性关系**。
- 某一列**完全不变**（比如所有学校 SAT 都是 1300）：$s_y = 0$，相关系数分母为 0，**无定义**；pandas 会返回 `NaN`。

**💡 换个说法（笔记补充）**

把协方差想成一场投票：每所学校投一票，"我的两项指标是同向偏离还是反向偏离"。同向的票是正数、反向的票是负数，而且偏离得越远票越重——一所毕业率和 SAT 都远高于平均的学校，一票顶普通学校好几票。协方差就是把票加起来取平均：正数多说明"一起涨"，负数多说明"一个涨一个跌"。相关系数则是把票面金额换成统一货币——不管你原来用的是"%"还是"分"，换算完都在 −1 到 +1 之间，这才能拿去和别的投票结果比。

另一个角度：相关系数 = 两列数各自**标准化**（减均值、除标准差，变成"离平均几个标准差"）之后的协方差。标准化之后两列都没有单位、都以 1 个标准差为刻度，所以协方差自然落在 −1 到 +1 之间。这也解释了为什么 T03 里做完 `StandardScaler` 再算协方差矩阵，得到的就是相关矩阵。

**用课程数据读一次**：T03 cell 39 对 Airbnb 算出与 `log_price` 的相关：accommodates **0.578**、bedrooms 0.483、beds 0.470、bathrooms 0.377、review_scores_rating 0.081、number_of_reviews −0.025。读法：0.578 是"中等偏强的正线性相关"——能住的人越多价格越高，但远不是决定性的（$0.578^2 \approx 0.33$，即只能解释约三分之一的变动，与 T02 回归的 $R^2$（M02：模型解释了因变量多少比例的变动）约 0.4–0.5 的量级一致）；−0.025 则是"看不出线性关系"。

**⚠️ 常见误解**

- ❌ "相关系数 0 = 两者没关系。" → 只能说没有**线性**关系。p.33 图 (d) 和上面的 U 形例子都是"关系明确、相关为 0"。散点图必须和相关系数一起看。
- ❌ "协方差 263 比 750 小，所以 p.31 那对变量关系更弱。" → 协方差带着单位（%×分），大小随量纲变，不同数据集之间**不可比**；只有相关系数可比。
- ❌ "分母写成 $n$ 也差不多。" → 讲义 p.30 明确区分总体版 $N$ 与样本版 $n-1$；pandas 的 `cov()` / `std()` 默认用 $n-1$，Excel 的 `COVARIANCE.P` 用 $N$，两者在 $n=49$ 时差 2%，考试按讲义写样本版。
- ❌ "相关强 = 一个导致另一个。" → 相关系数完全对称（$\rho_{xy} = \rho_{yx}$），它不知道谁是因谁是果。下一节专门讲这一点。

**所以呢**：相关系数量的是"一起变"的程度，而且只量直线式的一起变。但"一起变"不等于"一个导致另一个"——SAT 高的学校毕业率高，可能只是因为两者都由"生源好"决定。讲义下一页（p.34）专门泼这盆冷水。
