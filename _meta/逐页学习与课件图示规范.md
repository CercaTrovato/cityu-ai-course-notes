# 逐页学习与课件图示规范

笔记必须同时支持预习、课中逐页跟读和课后复习。读得通只是其中一个条件。本文统一规定源页、课堂定位与原图的交付要求；解释方法仍见 [[可读性总规则]]，重绘工具见 [[教学图示规范]]，独审与写回见 [[笔记制作与融合验收流程]]。适用于五门课及新增课程。

本文取代旧规则中“默认跨页按主题重排、只用 §8 补偿课堂定位”“课件图必须重画、不嵌位图”“只检查空文本或低文本页”的要求。可编辑要求适用于自制／重绘图，不禁止保留有来源的课件原图。取消字数和图数配额，不取消每页知识、每张教学图和每个适用机制的覆盖。

## 1. 三种用途必须分别成立

| 场景 | 读者实际要做的事 | 必须具备的内容 |
|---|---|---|
| 预习 | 没听课也能从当前页理解下一页，并复做例题 | 必要前置桥梁、逐页解释、完整原例与原题、图文对应和当前条件 |
| 课中 | 老师翻到任意页，立刻找到这页、辨认图中对象并接着听 | 按源页顺序的正文入口；每页独立定位；本页原图与读图说明；相邻页的变化 |
| 课后 | 按知识关系回顾，解释机制、解题和辨别易错处 | §3 结构总览、§4 速查、§5 英文术语、§6 考点与 §7 有理由的自测，精确回到逐页正文 |

§1.3 交代本讲源文件和编号，并给出这三条使用路线。补充推导可以分层或折叠，但当前页理解所需条件与关键解释必须就地可见。课中入口不能只是一张宽泛的页码表。

## 2. 正文保持逐页可跟读

1. **默认顺序**：M 笔记 §2 按原课件物理页顺序组织。相邻页可组成主题小节，但每个内容页必须有唯一的页级标题或锚点及实质讲解。页内按问题、对象、动作、理由组织；在依赖首次需要处搭桥，不用打乱整讲顺序解决前置缺口。§3–§7 负责跨页知识重组。
2. **页的身份**：记源文件／source ID、物理页号、页内印刷号（不同时）、标题。多个来源不能共用含混的“p.10”；PPTX 记 slide 序号，T 笔记用 cell 序号／任务步骤，不伪造 PDF 页码。动画构建、增量揭示或重复示意页须辨认本页新增／改变内容。
3. **本页讲什么**：保留本页独有的论点、条件、数字、图、公式、例子、问题和来源地位，解释它们如何支持结论。不能用“本页展示神经网络”“见上一节”或一段主题概述代替。不是逐字翻译或每页固定字数；只有几句话的页按实际含义讲足即可。
4. **复用不吞页**：完全重复页可精确回指已讲页，说明重复内容和本页无新增；有任何新增标线、权重、节点、结果、问句或限制就解释该增量。每个页入口仍可单独定位，并保留必要唤醒及本页图，重复原图可复用同一资产。
5. **非内容页**：仅纯封面／结束封面、无知识内容的目录／分隔页可简记；学习目标须连接实际教学位置。行政页解释要求与行动；含图、引用、案例或定义的“分隔页”仍是内容页。全部页在 §8 登记具体处置，不按标题或文本长度豁免。
6. **确需重排**：在 §1.3 写清理由，并提供同一笔记内完整的按页顺序跟读入口；每个入口须有本页讲解／图及增量，不能仅跨跳到大主题。可复用共同解释，不维护两份互相漂移的完整正文。不得把“更适合自学”作为牺牲课中使用的理由。
7. **导航**：§8 每个物理页一行，至少写“源／物理页｜原页标题｜正文精确链接｜原图或非内容处置”；不能仅以“21–30 → §2.4”交付。正文页级标题含页号，Obsidian 链接用完整标题原文。无课堂转录时不推断老师跳页。

## 3. 先视觉读源页，再决定怎样写

作者须实际查看本次来源范围的全部页面，文字多的页同样可能含关键示意、颜色、箭头和空间关系。文本提取、OCR、PPTX shape 文本及图片数量只能辅助；不能据此宣称已完成视觉阅读。

缩略联系表用于总览和找到图片；只有标签与关键关系都可辨认时才算该页实际读过。涉及小字、箭头、公式、权重、坐标或原题时，放大到能辨认的尺寸。记录实际打开的载体、页号和读出的要点，不能用生成了 PNG 或存在截图代替查看。

PDF 可直接按页视觉读取，或渲染到库外 scratch 再看；PPTX 必须结合实际幻灯片渲染、speaker notes、表格和必要嵌入对象。有匹配版本的 PDF 可作视觉载体，须核页序对应，不能假定其保留动画或备注。无图像查看能力时列明未核页和影响；相应视觉／完整学习状态待核。

源页视觉与最终笔记显示是两次不同的核对：前者防漏知识，后者查图片清晰度、公式、嵌入和读图动线，不能互相替代。

## 4. 课件原图与补充图各尽其用

### 4.1 原图应当进入正文

凡承载教学含义的课件结构图、示意图、曲线、流程、时间展开、句法树、示例照片、界面或标注图，默认以原图或保留完整语义的裁图嵌在对应页解释旁。读者应能认出老师正在指的图。Logo、背景纹理等装饰无需搬入；每项省略须有具体理由，不能整讲笼统写“无配图必要”。

保留原图不要求每页贴整张幻灯片。裁图必须保留必要标题、图例、坐标、节点、端点、权重、标注与条件；保留来源页和裁切范围。无法提取独立图片时可渲染整页再裁切，不能只用 pdfimages 的输出判断课件是否有图（矢量线和文字可能未在其中）。

课件原图错误时保留可辨认的原貌，在旁明确勘误；需要正确示意则另附修正版并说明差异，不能静默修掉原图或让错误图无提示出现。确实无法获取／清晰显示原图时明确受限；可给忠实重绘及来源差异，但不能冒称原图已保留或原图对照已完成。

### 4.2 嵌图必须伴随讲解

在图旁解释：这张图回答什么；从哪里看；节点／层／箭头／轴／颜色／符号分别代表什么；沿一条具体路径或一个例子怎样读到结果；本页相对前页改变了什么。只给图注或“如图所示”不合格。解释用中文并对齐图上英文，说明原符号与笔记符号的对应。

神经网络图须能对上输入、隐藏和输出层、连接、偏置及公式索引；不能用另一个节点数不同的小网络替代原图辨认。RNN 须能对上时间展开、状态和共享参数；LSTM 须能对上原图的状态通道、门、乘加符号和当前页高亮路径。它们是本次事故的示例，不是只适用于 IS6400 的例外。

### 4.3 补充机制图仍然必须按需落实

原图保留与补充机制图是两项判断。课件未画清的核心迭代／分支过程仍需真实控制流程，结构难点用结构图，几何／激活曲线用准确曲线或示意，不能全都改成矩形箭头图。

按 [[教学图示规范]] §1 的触发条件逐个学习机制检查，记录“已有图满足／需要补图／不适用及理由”及正文位置。原图已完整表达所需机制并讲清时可复用，不为图数再画一次；原图的分类图不能冒充算法流程图，§3 总览不能替代 §2 局部难点。没有触发条件的单步事实不强行造图。

### 4.4 资产与来源

最终使用的课件图放 `<课程>/notes/figures/<ASCII模块名>/`，它是长期学习资产；批量渲染、未使用裁图及预览留 scratch。原件只读。嵌图使用库内相对路径／完整 vault 路径，不依赖临时目录、登录链接或本机盘符。使用足以看清原标注的分辨率，并提供可打开的清晰大图入口。

原图记录来源相对路径、来源 SHA-256、页号、图 ID、裁切范围或提取方式、成图路径和 SHA-256、正文位置。原图无需编造 DOT／JSON 模型；来源和可复现的提取信息就是其证据。自制／重绘图保留可编辑源码与数据，仍按现行工具规则核语义及显示。来源版权和发布边界继续按 NOTICE 与 [[备份与公开发布规则]]，不因截成图改变。

## 5. 逐页证据与验收

### 5.1 一份源页清单贯穿制作和检查

在候选之前建立 `page-evidence.md`（或等价结构化清单），与候选一同维护，避免事后凭正文页码倒推“已覆盖”。每个源页一行；图多可在该页下列各图 ID。最少包括：

| 字段 | 记录什么 |
|---|---|
| 来源定位 | 真实源文件／哈希、物理页／slide／cell 与原页标题 |
| 源页视觉 | 实际查看载体／页与可辨识范围；未读部分具体列明 |
| 本页教学要素 | 独有知识、原图、题目、公式、例子与相对前页增量 |
| 正文对应 | 页级精确标题／锚点，具体解释位置；不只写大节号 |
| 图的处置 | 原图 ID／资产／解释位置；重复复用、装饰省略或受阻及理由 |
| 补充图判断 | 适用机制、所需图型、实际图位置或不适用依据 |
| 缺口与结果 | 未读／待补／待核／已核及具体证据，不批量填“全部通过” |

这份证据可链接已有题目／图资产记录，不另抄原题或生成多套同义台账；§8 是读者导航，`page-evidence` 是制作证据，职责不同。正式交付把实际依赖清单和图资产保存在持久审查目录并绑定回执，不能只留 scratch 路径。

### 5.2 同一次独审中的两种阅读方向

沿用制作流程的两阶段和一位独审，不增加额外全篇轮次。第一阶段按候选顺读，检查预习解释链及复习回指。第二阶段拿到原课件后按源页顺序核本次全部页：老师指到该页和该图时，笔记能否定位、辨认、解释和接到下一页。原图与对应解释必须一起核；只检查候选已有的主题会漏掉源页缺失。

主代理负责实际来源视觉、原题／计算、最终显示和页清单完整性；审查者负责独立学习尝试及第二阶段源页对照。审查者无法看某图时明示限制，交由具备能力的独立复核处理；不能用主代理的“已看”代替独立理解证据。范围仅为本次及受影响内容，整篇整改则覆盖全篇。

以下问题均为实质阻塞：某内容页只有范围引用；独有图／条件／题目遗漏；教学图未保留且无真实受限说明；原图在正文却无可执行读法；原图与文字对象无法对应；需要的流程／结构图缺失；源页或最终图未实际看清；课中只能反复搜索大主题才能定位当前页。机器绿色和旧回执不能关闭这些问题。

### 5.3 与现行回执衔接

继续使用 `note-review-v2`，不虚构新机器认证：`sources` 的证据包含逐页要素与原题，`visuals` 同时包含源页视觉、原图资产与笔记实际显示，`understanding` 包含三种场景的独立审查结论。把页清单／图资产登记为 `assets`，未关闭问题留 `unresolved`。受影响源页含教学图或机制需要补图时，`visuals` 不能填 `not_applicable`。

现有脚本只核有限字面、文件和哈希，不自动保证每页看过、图解释完整或三种用途可用。缺失上述人工证据即不得宣称学习验收完成；脚本退出 0 仍只是机械结果。正式交付分别报来源总页数、实际视觉页数、正文页级覆盖、教学图保留与缺口、适用流程覆盖及三种场景结论；数字帮助发现遗漏，不替代证据。

## 6. 生效与存量

新写、整篇重写按全篇执行；局部融合按全部新增／变化及受影响源页执行，保护未变状态，不据局部通过宣布整篇达标。仅改规则不改写旧审查历史、不自动升级任何笔记，也不启动无人授权的全库内容重写。

存量须区分“旧标准已审”“本标准待核”“已发现待修”“本次已核范围”。图块扫描只能做筛查，不能以有 Mermaid／嵌图即判合格，也不能以无图即判每篇都不合格。优先整改用户正在使用且已发现缺口的笔记；全库是否贯彻必须以逐篇源页与机制核查为准。
