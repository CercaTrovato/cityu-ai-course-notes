# 独立高中知识起点教学断点审查：有限案例证据与审查协议

## 0. 审查边界与方法

- 本报告只审查指定失败样本、其当前版本对应段落，以及 AC6761、IS6400、IS5113 各一个短段落。
- 正式库只读；没有改笔记，没有读取现行《可读性总规则》或作者旧回执，也不依据标签齐全、公式算对、脚本 PASS 判定教学通过。
- 模拟读者起点：没有听课，会高中基本运算，首次接触金融、会计、算法与伦理术语；审查者仍按专家标准核对概念，不声称做过真人高中生实验。
- “第一处无法仅靠前文回答的问题”指：读者按顺序阅读到该处时，当前段落及其此前已给内容不足以让他说明对象、动作、因果或判定依据。后文若补上，会记录为“延迟桥梁”，但不会抹去首次阅读时的断点。
- 严重程度只描述该局部对既定学习任务的影响：**高** = 可能导致核心任务做错；**中** = 能跟着例子，但难以迁移或容易形成错误模型；**低** = 主线可完成，局部术语或边界仍需补桥。

## 3. 建议固化的独立审查协议

### 3.1 角色隔离

1. 每次新写、重写或实质融合完成后，由**未参与该段写作、未看作者自评与检查器结果**的独立子代理审查。
2. 审查提示明确读者起点：仅有高中基本运算；没有听课；首次接触本段学科术语。审查者保持专家准确性，不扮演真人，不把模拟阅读写成用户测试。
3. 先读待审正文与必要前文，再看规则或机器报告；防止先按指标找标签、句长和格式，而忽略真实学习任务。
4. 审查范围与改动范围分开：可只审受影响单元；不得由一个局部样本推断全篇或全库达标。

### 3.2 逐段判定动作

对每个样本必须完成以下动作，而不是给总分：

1. **写出学习任务**：读完后应能解释、计算、判断或迁移什么。
2. **固定读者已知**：列出真正来自此前正文的概念；标题、链接和后文答案不算已经解释。
3. **顺序阅读并停在第一处断点**：提出一个初学者必须能回答的具体问题。若只能靠猜、外部知识、跳到后文或照抄结论回答，即为候选断点。
4. **定位桥梁类型**：缺的是对象、动作、因果、分母/单位、时点、观察主体、判定阈值、前提、边界、近似与正式概念的区别，还是从例子到新题的迁移步骤。
5. **做一次新输入检验**：轻微改变数字、角色、顺序或情境，检查读者能否沿同一机制得到答案。只能复述原例，说明“例子完整”仍未达到可迁移。
6. **做反误读检验**：写出一个文本允许产生但学科上错误的解释，并指出是哪句话诱发。没有具体误读证据时，不为找错硬判。
7. **做精度回查**：对每个类比、口诀和“简单说法”，重新代回正式定义，检查是否删掉阈值、分母、主体、时间、必要条件或适用边界。
8. **给最小修复原则**：优先补一个桥接句、一步演算、双边表、近似反例或限定词；不因“易懂”删除专业区分，也不因“完整”重复整段。

### 3.3 审查输出的必填字段

每个样本至少记录：

- 文件、起止标题、准确行号；
- 学习任务；
- 第一处无法仅靠前文回答的问题；
- 缺失桥梁的具体类型和内容；
- 严重程度及其对任务的影响；
- 已有解释在哪里，避免重复添加；
- 一个可能误读或一个新输入迁移失败；
- 最小修复原则；
- 本次未检查的范围。

不要只写“高中生能懂 / 不能懂”“术语太多”“句子太长”“建议加例子”。这些结论无法指导精确修复。

## 4. 少量通用规则与适用边界

1. **先固定对象与观察主体，再给方向和公式。** 适用于资产流、会计主体、算法状态、伦理行动者等多主体问题。单一主体的纯定义不必机械加图。
2. **首次计算先走具体数值与状态变化，再抽象符号。** 适用于公式承担机制解释的场景；若符号已在紧邻前文稳定使用，可直接复用，不要求重复教学。
3. **每次切换身份、时点、分母或评价基准都要明示。** EF5560 的交易者/LP、起点/整笔/终点，AC6761 的客户/银行，都是高风险切换。若上下文只有一个明确口径，不必重复标签。
4. **例子必须暴露至少一个可迁移操作。** 给最终分类或答案不够；应展示一次如何从输入生成中间结果。无需把所有行都重复计算。
5. **类比必须可反解回正式定义。** 类比若删掉阈值、条件或边界，应加一句“类比到此为止”并恢复精确定义。DBSCAN 的“谁也不认识”说明更简单可能更错。
6. **后文补充不能完全抵消首次断点。** 若核心术语在首次使用时会改变当前操作，应就地给最小桥梁；纯扩展、证明或后续专节内容可以预告后置。
7. **易懂不等于降低学科深度。** 应删的是无功能术语堆叠和跳步，不是适用边界、因果链和关键区分。把康德缩成黄金法则、把 debit/credit 永久缩成左右、把 DBSCAN 噪声缩成孤立点，都会损害准确性。

## 5. 脚本能查与不能查

### 5.1 脚本适合检查

- 标题、固定字段、折叠块、表格、公式定界符、链接和文件引用是否存在或破损；
- 术语是否在首次出现附近有定义性文本；
- 公式附近是否出现符号、单位、示例、边界等候选证据；
- 过长段落、连续名词、未解释缩写、表格缺列、图无说明等高风险位置；
- 同一词在不同位置出现互相冲突的数值或单位；
- 审查记录是否包含文件、行号、断点问题、桥梁、误读和未检范围等必填字段。

这些结果只能用于**定位候选处**，不能自动判定读者已经理解。

### 5.2 脚本不能可靠判断

- 读者是否知道当前观察的是池子、个人钱包、银行账本还是客户账本；
- 一个公式输出的是总余额、增量、比率、边际量还是最终答案；
- 因果链是否闭合，还是只有相邻句子看似相关；
- 类比是否悄悄改变了正式定义；
- 示例能否迁移到新数字、新角色或新情境；
- 后文解释是否来得太晚，导致首次阅读已经形成错误模型；
- 伦理或法律论证是在检查逻辑、权利、后果还是个人偏好；
- 内容算对、标签齐全以后，零基础读者是否能独立完成学习任务。

因此，机器检查应输出“候选风险与证据位置”；最终教学判定须由独立审查者用顺序阅读、具体追问、反误读和新输入迁移完成。

## 6. 本次结论边界

本次证据只支持上述局部结论和审查协议，不支持宣称四篇笔记全篇达标，也不支持推断 CityU 全库质量。当前 EF5560 对应段落已经显著补齐对象、时点和身份桥梁；其余三个抽样分别暴露了主体切换、阈值类比、准则生成三类不同断点，足以说明独立审查应围绕学习任务与可迁移机制，而不是统一追求“更简单”或依赖格式指标。
