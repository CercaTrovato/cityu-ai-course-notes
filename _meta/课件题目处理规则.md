# 课件题目处理规则：逐问作答，逐项验收

> 起因：EF5560 M04 讲义 p.26 有三个小问，旧笔记列出了题干和诊断，却把参考思路散放在后文，读者无法按题目直接核对三问的答案。**逐页覆盖、正文够长、`note_quality.py` PASS 都不能证明题目已解答。**

## 1. 哪些题必须登记

逐页 / 逐张幻灯片 / 逐个 Notebook cell 查找讲义中的 Question、Exercise、Quiz、Check、Discuss、Case、Try it、选择题、简答题、计算题、图表提问、代码待填空和正文明确要求读者作判断的问句。图片里的题、speaker notes 和嵌入对象也要看。**一题有三个小问就登记三个小问**，不能以“本页已讲解”代替逐问检查。

课件里的公开教学练习属于本规则；**个人已提交或待评分的本人作业成品按 [[备份与公开发布规则]] 允许公开**。个人完整作答仍在 `assignment/` 单独组织；讲义正文与完整作业互链，来源、可提交及本人提交状态分别记录。

## 2. 每个小问的最低答案形态

在对应笔记 §2 的讲义页码附近给出“**题意 / 第 1 问……第 2 问……**”，并让读者不用跳到 §7 或别的文件就能看到：

1. **先给直接答案**：选择题写选项和内容；判断题写是 / 否及适用条件；开放题写结论及边界。原题若问“两项”，就明确列两项；若问“额外检查”，答案不能重复题干已给的检查。
2. **再讲为什么**：写出用到的定义、输入、推理顺序、反例或选项排除理由。计算题列公式、符号、单位、逐步代入和结果核对；代码题说明关键行、运行结果与失败路径；讨论 / 案例题覆盖题干的每个对象与约束，不用空泛模板代替分析。
3. **标清来源和地位**：`✅ 讲义 / 官方答案` 标页码或 cell；`🎙️ 课堂确认` 标可核时间戳；无官方答案时写 `⚪ 参考作答（笔记推断）`，列支撑讲义页、数据或脚本。课件没有给足信息时，明确写“无法唯一确定”、缺什么信息和可成立的条件，登记到 §9.5；**不编造教授答案或测试结果**。
4. **给能迁移的解释**：至少指出“换一个数字 / 条件 / 选项时怎么重做”或一个常见错误，让零基础读者能独立解同类题。不能只放最终选项、题干复述、页码映射或“见某节”。

§7 自测可重用题目并给折叠答案，§6 可提炼答题框架，§8 保留页码映射；这三处都**不能替代 §2 的逐问答案**。原题保留和英文应试对照按下文 §2b：中文题意概述只能辅助理解，不能替代完整教学题面和全部选项。

### 2a. 难句与难逻辑的讲解深度（2026-10-07）

每道课堂／课间练习同时执行 [[课堂练习完成与解析规范]]。原题中的对象、代词、方向、时间和最低／最高限制要翻成最简单的人话，再说明它影响哪一步；最难推理给具体小例和常见错法，不以“同理”或专业名词省略原因。总结提炼本题答案、判断顺序与误区，附与核心难点对应的改条件例。讲义 §2 的逐问答案和完整案例分别保持原有目录组织，公开范围按现行规则执行；解析齐全不等于官方已核或本人已提交。

### 2b. 原题保真与英文应试对照（2026-10-15，全库强制）

适用于五门课的 M / T 笔记、公开课堂／课间练习，以及制作、重写和转录融合所触及的教学题目。读者既要理解中文解释，也要能识别英文考题并组织英文答案；不把中文化等同于学会。

1. **先保留原题**：在 §2 对应页附近保留原语言的完整题干、必要情境、全部小问、选项字母与全文、数据／单位及限制。英文原题保留英文，编号与否定词不改；图表／代码作为题面组成部分一并保留或忠实转录。只允许统一换行、连字和排版，不静默改数字或题意。长题可用折叠块保留完整题面，外面仍有读题入口；页码、附件链接和中文概述不能替代题面。
2. **再解题意**：另写中文意思，解释对象、动作、时间、代词和决定答案的词，例如 only、most directly、at least、unchanged、provided that。选择题给全部选项的中文含义；不能把译文中的解释冒充原题条件。
3. **逐问讲清楚**：紧接原题给直接答案和推理。选择题每个选项都解释成立／不成立的原因，保持原字母对应；多问题按原编号回答。计算题保留输入、公式、单位、代入、结果及其解释；改条件练习按既有规则保留。
4. **连接英文作答**：英文授课或英文考试的题目，每个作答单元均有简洁、完整句的英文参考答案；计算题写结果、单位与解释，不能只放算式。用词与题面一致。仅列术语、答案字母或中文答题模板不算完成。非英文题保留原语言；英文应试场景另补英文关键术语与参考答案，不伪造英文原题。
5. **来源分开**：分清“英文原题／讲义给定步骤或答案”“中文译解”“英文参考答案（笔记自拟）”。官方答案与课堂确认仍按 §2 标页码／时间戳；自拟英文即使结论合理也不能写成教授原句。材料不足要用有条件的答案说明未知，不为凑英文补事实。演示无问句时保留实际演示，不新编教授问句；原题语法／数据有误保留原文，并在译解及 §9 勘误。
6. **正文就地配词**：首次用于推理的术语用中文（English），就地解释用途；独立学习单元需要识别旧词时一句唤醒并配英文。优先采用讲义用词，常见同义译名可注明；缩写首次写全称。§5 双语词表、课程术语表与英文答案相互一致，但都不能替代正文配对。按可读性总规则拆段，不能为补英文堆一段新词，也不能因术语密度提示删英文。
7. **验收须能回到原文**：对全部适用题建立 `源页／题号及小问 | 原文位置 | 选项应有／实有 | 中文题意与解析位置 | 英文参考答案位置 | 关键词／术语 | 来源地位 | 缺口`。逐源核对否定、数量、币种、期间、条件及选项字母，另核正文首现词。题面、全部选项、中文解析、英文答案任一适用项缺失，状态为“部分”；原件缺失标“受阻”，不补造通过。机器计数只辅助，不能替代题意和译解判断。

个人评分作业、本人姓名与本人提交信息已按 2026-10-21 用户授权允许公开，执行 [[备份与公开发布规则]]；不据此暴露凭据或第三方个人信息。既有未改笔记不因规则更新自动验收通过，也不因此启动重复全库盲读；后续制作／融合按受影响范围执行，用户指定整改时再逐篇处理。

## 3. 题目台账与完成判定

**新增必填核对维度**：按 §2b 记录原文、选项、中文译解／解析、英文参考答案和正文术语。任一适用维度缺失不得记完整；过去“完整”记录只代表其当时实际检查范围。

每篇笔记对应的讲义题目清单至少记录：`课程 / 模块 / 源文件 / 页码或幻灯片或 cell / 题号及小问 / 对应笔记小节 / 答案来源 / 状态 / 待核问题`。首轮跨课状态见 [[课件题目覆盖台账]]；该台账是持续更新的审计记录，不得把“候选页数”写成“已验收题数”。状态只能是：

- **完整**：每个小问都有直接答案、过程 / 选项解析、来源与边界，已回到原题逐字核对；有计算或代码的结果已经复算。
- **部分**：已有一些答案，但漏小问、漏推导、漏选项排除、来源不明或缺关键约束。
- **受阻**：原材料不足以唯一作答、缺官方数据 / 图片 / 解答，笔记写明缺口与所需证据；不能写成“完整”。
- **历史私有**：仅保留旧台账当时状态；现行本人评分作业允许公开，公开状态不能代替题目完成／验收状态。

全文搜索 `问：`、`？`、`答案`、`待补` 只能发现候选；**最终必须与原讲义逐页核对**。`note_quality.py`、`link_check.py` 和页码覆盖检查不懂题意，不能替代这张台账。只要存在未处理的公开讲义题目，就不得宣称该篇讲义题目“全部完成”。

## 4. 回补与验收顺序

先在只读原材料中确认题目的全部小问及题干约束，再找官方答案、课堂转录、数据 / 代码，最后写参考作答。按 [[机制理解与可读性标准]] 顶部 2026-10-02 简化流程，一次定向检查难句、关键步骤与改条件例，发现缺口直接补正文；全部小问仍对照原题清单，不恢复重复全量盲读或评分。完成后回写 §2、必要的 §7 / §9.5、课程考点库和题目台账，并做受影响的必要格式、计算、链接与完整性检查；旧 strict 仅定位缺口，不把脚本结果当讲清楚的证明。真实课堂未覆盖的题仍要答；无转录时答案来源只能写讲义 / 数据 / 笔记推断。
