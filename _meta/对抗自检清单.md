>
> ```python
> clean = re.sub(r'```.*?```', '', t, flags=re.S)      # 去代码块
> clean = re.sub(r'`[^`\n]*`', '', clean)              # 去行内代码
> ```
>
> **自检脚本报出的问题，先怀疑脚本，再怀疑笔记。** 报错要能复现到具体行号才算数。
>
> ⚠️ **第二个已知盲区**（2026-09-10 全库复跑时踩到）：脚本只认 `p.N` 和 `p.N–M`，**省略前缀的连写**——`p.28、30–33`、`p.56, 57, 58`——只会算到第一个数。EF5560 M01 的 §2.6.1 标题写成 `p.28、30–33`，脚本就把 p.30–31 报成"未讲解"，其实讲了。

### ☐ 9b. 链接真的能跳到位（2026-09-10 新增）

两类静默失效的链接，Obsidian 都**不报错**，点了才发现落错地方：

| 失效类型 | 症状 | 规则 |
|---|---|---|
| **同名文件裸链接** `[[术语表]]` | 五门课各有一份，落到哪一份看运气 | 带目录 + 别名：`[[<课程目录>/_meta/术语表|术语表]]`；只有根目录文件可裸写 |
| **slug 式锚点** `[[M02#2-5-2-四条假设]]` | 打开文件但停在顶部 | 锚点 = 标题原文（去 `#|^[]`）：`[[M02-…#2.5.2 四条假设（讲义 p.17–18，⭐ 必考）|M02 §2.5.2]]`；表格里管道写 `\|` |
| **Markdown 式同文件锚点** `[§8](#8-讲义页码映射)` | 同上，停在顶部（GitHub 上能跳，Obsidian 不认 slug） | 同文件跳转也用双链：`[[#8. 讲义页码映射\|§8]]`。2026-09-11 全库 144 处已改；模板 §1.3 那句已改，**不要照旧笔记抄** |
| **表格里的双链别名竖线没转义** `\| [[术语表\|术语表]] \|` | 单元格被竖线切开，多出一列，链接显示成两截 | 只要在表格行里，别名竖线一律 `\|`（行内代码里的也一样，GFM 不豁免）。2026-09-12 全库 80 处已改；检测：表格行里带别名的双链若没有 `\|` 即为错 |

**机械做法**（两段脚本，跑完都应为 0）：

```python
# ① 裸链接指向重名文件 —— 期望：无输出
import re, io, glob, os, collections
files = [f for f in glob.glob('**/*.md', recursive=True) if 'course_files_export' not in f]
byname = collections.defaultdict(list)
for f in files: byname[os.path.splitext(os.path.basename(f))[0]].append(f)
dups = {n for n, v in byname.items() if len(v) > 1}
def body(f):   # 去代码块；行内代码只用来判定"链接是否在代码里"，不能先删（标题本身可能含反引号）
    t = re.sub(r'```.*?```', '', io.open(f, encoding='utf-8').read(), flags=re.S)
    spans = [m.span() for m in re.finditer(r'`[^`\n]*`', t)]
    return t, spans
def in_code(pos, spans): return any(s <= pos < e for s, e in spans)
for f in files:
    t, spans = body(f)
    for m in re.finditer(r'\[\[([^\]\|#/]+)(#[^\]\|]*)?(\|[^\]]*)?\]\]', t):
        if in_code(m.start(), spans): continue
        if m.group(1).strip() in dups and not os.path.exists(m.group(1).strip() + '.md'):
            print('重名裸链接', f, m.group(0))

# ② 锚点与目标文件的标题逐字比对 —— 期望：无输出
#    覆盖三种写法：[[文件#锚点]]、同文件 [[#锚点]]、Markdown 式 [x](#锚点)（2026-09-11 补：原版漏了后两种）
def clean(h): return re.sub(r'\s+', ' ', re.sub(r'[#|^\[\]`]', '', h)).strip()
def heads(tgt): return [clean(h) for h in re.findall(r'^#{1,6}\s+(.+?)\s*$', re.sub(r'```.*?```', '', io.open(tgt, encoding='utf-8').read(), flags=re.S), re.M)]
for f in files:
    t, spans = body(f)
    for m in re.finditer(r'\[\[([^\]\|#]*)#([^\]\|]+?)(\\)?(\|[^\]]*)?\]\]', t):
        if in_code(m.start(), spans): continue
        name = m.group(1).strip(); base = name.split('/')[-1]
        tgt = f if not name else (name + '.md' if os.path.exists(name + '.md') else (byname.get(base) or [None])[0])
        if not tgt: print('目标缺失', f, m.group(0)); continue
        if clean(m.group(2)) not in heads(tgt): print('锚点失效', f, m.group(0))
    for m in re.finditer(r'\[[^\]]*\]\(#([^)]*)\)', t):        # Markdown 式同文件锚点
        if in_code(m.start(), spans): continue
        if clean(m.group(1)) not in heads(f): print('锚点失效(md)', f, m.group(0))
```

> ❗ **起因**：2026-09-10 首次全库审计，251 个裸链接指向重名文件、**407 个锚点没有一个能匹配**（全是 GitHub 式 slug，且不少是章节改号后的旧号）。四个子代理各自写的时候都"看起来对"，因为 Markdown 预览不会验证锚点。**只有跑脚本才知道。**
> ❗ **第二次（2026-09-11）**：上面脚本 ② 的正则要求 `[[` 后有文件名，于是同文件的 `[[#…]]` 和 Markdown 式的 `[x](#…)` 从来没被查过——全库还剩 **144 处** slug 锚点（源头是模板 §1.3 的示例句被每篇笔记照抄）。**先怀疑脚本的覆盖面，再相信"脚本无输出"。**

### ☐ 12b. 公式与代码的渲染（2026-09-11 新增）

Obsidian 用 MathJax 渲染 `$…$` / `$$…$$`；**写在代码块或行内代码里的公式不会被渲染**，读者看到的是 `x̄_j = (1/n_j)·Σ_{t∈j} x_{t−1}` 这样的等宽乱码。规则在 [[笔记模板]]「★ 公式与代码的写法」。

**机械做法**（期望：输出为空）：

```python
import re, io
MATHY = re.compile(r'[Σ∑√∈≈≠≤≥×÷∂∞αβγδεθλμσπρτφω]|[\u0302\u0304\u0305]|²|³|ᵀ|⁻¹|\bargmin|[a-zA-Z]_\{')
t = io.open(fn, encoding='utf-8').read()
for lang, b in re.findall(r'```([a-zA-Z]*)\n(.*?)```', t, re.S):
    if lang in ('', 'text', 'math') and MATHY.search(b) and not re.search(r'\b(import|def |print\(|pd\.|np\.|plt\.|SELECT|FROM)', b):
        print('代码块里的伪公式:', b.strip().splitlines()[0][:80])
for s in re.findall(r'`([^`\n]{3,120})`', re.sub(r'```.*?```', '', t, flags=re.S)):
    if MATHY.search(s) and not re.search(r'\.(py|csv|md|txt|pdf|ipynb)|/|\(\)|\bdf\b|pd\.|np\.|^\d+\s*[—–-]+\s*[∞\d]+$', s):   # 末项排除 ER 图的基数记号 1—∞
        print('行内代码里的伪公式:', s)
```

> ❗ **起因**：2026-09-11 全库扫描——28 个代码块 + 157 处行内代码是伪公式，集中在 EF5560 M02（11 + 15，LaTeX 0 处）、IS6400 M02（105 处行内）、IS6400 T01/T02、EF5560 M01。AC6761 的四篇一开始就用了 LaTeX（48/20/23/13 处），说明**这不是做不到，是没定规则**。

> ⚠️ 表格单元格里的公式：竖线要写 `\mid`，写 `|` 会把表格切断；写 `\|` 在 LaTeX 里又不是竖线。
