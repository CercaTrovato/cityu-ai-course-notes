## 2. 导致漏检的规则与机制

下列旧措辞保存在 [rules.diff](rules.diff) 的删除侧，当前规则已定向修订；旧教学回执原文不追改。

| 位置 | 旧规则的问题 | 影响与修订 |
|---|---|---|
| 根入口 §4、设计规格“机制二” | 默认按学习逻辑重排，并说用 §8 页码映射补偿课中顺序 | 多页落到同一主题大节仍可能被判覆盖。改为默认源页序、每个内容页独立入口和解释；知识重组放复习层；重排也必须完整跟读 |
| 材料处理 §3、§7.4；设计规格图表行 | “必须重画为 Mermaid 或表格”“不嵌位图” | 阻碍保留教师结构图、曲线、照片和标注。撤销原图禁令；教学原图入正文并解释，自制／重绘图另保留源码 |
| 教学图示规范 §2 | “教师原图可作为只读来源，正文重画” | 把原图限制在作者参考侧，读者看不到。改为原图优先保留，必要补图并列；勘误不静默改原图 |
| 材料处理与对抗清单 | 视觉检查主要围绕空文本／低文本页 | 混合文字、矢量连接、细小标注可能漏掉。改为全部源页实际视觉读取，小字和关键关系须放大 |
| 模板 §2、可读性总规则 §1.2 | 用 p.X–Y 的主题小节示范；允许多页共享解释，缺少页级交付契约 | 范围覆盖替代本页新增内容，课堂无法迅速定位。增加页级模板、源版本／页号、本页增量及原图、§8 每页链接 |
| 制作流程与独审任务 | 以候选的学习单元为主要审查方向，第二阶段未强制按源页跟读 | 候选没写出的原图／页面不易进入审查范围。第二阶段增加源页→正文的全范围对照，与原有顺读属于同一次独审 |
| 图示触发与发布门槛 | 规定何时画流程／结构图，但没有逐机制落实清单；允许 visuals 不适用 | 容易以有几张流程图当完成，或从候选无图推断无须图。记录每个适用机制的图／理由；源页有教学图时不能填视觉不适用 |
| 设计规格“篇幅不限”旧解释 | 仍写“唯一保留的硬约束”是 §8 归属 | 与正文覆盖、图文教学和质量门槛冲突。改成取消上限不取消逐页讲解、原图及三场景验收 |

1. 开写前实际查看源页并建 `page-evidence`，列本页内容、原图、题目与增量，不能事后只按正文页码倒填。
