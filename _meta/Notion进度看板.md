## 2. 🎓 学习进度 · 字段与流水线

八个勾选框就是学习流水线，从左到右推进：

```
📄 课件  →  🎙️ 已录音  →  📝 已转录  →  🤖 转录已交AI
                                              ↓
        🔁 复习  ←  ✅ 自测通过  ←  👁️ 已通读  ←  📔 笔记已生成
```

| 字段 | 类型 | 什么时候勾/填 |
|---|---|---|
| `Module` | 标题 | `<课程码> M<两位数> · <中文主题>` |
| `课程` | 选择 | 四门课之一 |
| `周次` / `上课日期` | 数字 / 日期 | 日期目前多为**据文件时间戳推断**，需本人确认 |
| `状态` | 选择 | 未上课 → 已上课待处理 → 笔记v0.9 → 笔记v1.0 → 已通读 → 已掌握 |
| `📄 课件` | 勾选 | 讲义文件已在本地 |
| `🎙️ 已录音` | 勾选 | Notta 录了这节课 |
| `📝 已转录` | 勾选 | 转录文字**已导出到** `<课程>/transcripts/`（只在 Notta 里存着不算） |
| `🤖 转录已交AI` | 勾选 | 转录已按 [[转录处理规则]] 合并进笔记 |
| `📔 笔记已生成` | 勾选 | notes/ 下有对应 .md |
| `👁️ 已通读` | 勾选 | **本人**读完一遍（不是 AI 写完） |
| `✅ 自测通过` | 勾选 | 笔记第 7 节自测做过且答对 |
| `复习次数` / `下次复习` | 数字 / 日期 | 间隔复习用 |
| `笔记路径` | 文本 | vault 内相对路径，如 `IS5113_AI_Ethics_and_Regulations/notes/M01-….md` |
| `卡点/备注` | 文本 | 为什么卡住、缺什么 |

**状态与勾选框的关系**：勾选框记录客观事实，`状态` 是人看的汇总。两者可能短暂不一致（例如笔记已生成但还没通读），以勾选框为准。

## 3. 📌 作业与 DDL · 字段

| 字段 | 说明 |
|---|---|
| `任务` | 简短可辨认的名字 |
| `课程` / `类型` | 类型：个人作业 / 小组项目 / 课堂演示 / 考试 / 阅读 / 其他 |
| `截止` | **带具体时间点**（如 9/22 12:00 +08:00），不要只写日期 |
| `占分` | 占总评的百分比；不确定就写「未明说 + 推测」 |
| `状态` | 未开始 → 进行中 → 已提交 → 已评分 |
| `要求摘要` | 题目、篇幅、提交方式。信息不全时用 ❗ 开头标出缺口 |
| `关联 Module` | 关联到进度库的对应行 |
| `来源` | 出处，精确到文件名 + 页码 |

## 4. AI 什么时候更新 Notion

**每写完一个 module 笔记，必做**：

1. 该 module 行：勾 `📔 笔记已生成`，填 `笔记路径`，`状态` 改 `笔记v0.9` 或 `笔记v1.0`
2. 合并了转录：补勾 `🤖 转录已交AI`，`状态` 升 `笔记v1.0`
3. 笔记里发现新作业 → 在 DDL 库建行，关联回该 module
4. 有卡点（缺材料、缺规则、待确认）→ 写进 `卡点/备注`，**不要只在对话里说**

**不要替用户勾的**：`👁️ 已通读`、`✅ 自测通过`、`复习次数`。这三个是本人的学习行为，AI 勾了就失去意义。

**没有 Notion 访问权的 AI**：把该更新的内容整理成一段清单交给用户手动填，并说明自己无法直接写入。

## 5. 建议的视图

在 Notion 里手动加这几个视图（AI 不代建，避免打乱你自己的布局）：

| 视图 | 类型 | 配置 |
|---|---|---|
| 待处理 | 表格 | 筛选 `状态 = 已上课待处理`，按上课日期升序 —— **这就是「还有什么没学」** |
| 转录缺口 | 表格 | 筛选 `🎙️已录音 = ✓` 且 `📝已转录 = ✗` —— 提醒去 Notta 导出 |
| 按课程 | 看板 | 按 `课程` 分组 |
| 复习日历 | 日历 | 按 `下次复习` |
| DDL 倒计时 | 日历/表格 | DDL 库，按 `截止` 升序，筛掉已提交 |
