## 3. 关键事实镜像

- 旧版 54 页、新版 56 页都回源；新版新增 p.26–27；旧 p.26→新 p.54，旧 p.53–54→新 p.55–56。
- 当前现存源：新版 p.25 已显示 `2008 / 2012 / 2016 / 2020`，旧版仍显示日期序数百分比。新版 SHA 与原独审登记一致；不能编造具体替换日期。
- P1、P2 是两个独立时钟；P1 首句半句，缺首长度未知；P2 有收尾。两源各自无倒退或 ≥120 秒空档不证明整堂完整。
- 两条 M01 引用不属于 P1/P2 audit 范围，必须单列跨源核验。
- Class 2 课堂明确无需 validation；144/36/60 是讲义规范，不是本堂候选选择日志。
- 正收益占比 = always-up 分数；不自动等于事后多数方向，也不自动成为事前可部署的唯一基准。
- active return 与 excess return 的减数不同；个股零基准须跟实际目标走。
- β 有尺度、t 无尺度；t/p 是推断量，不是预测变量排名工具。
- 同一组非缺失行、含截距、无惩罚的简单 OLS 且两列方差非零时，`R² = corr²`；最终候选用既有三行 `x=[0,1,2]`、`y=[1,2,2]` 算得 `corr=0.8660254`、`R²=0.75`，不能外推到多元或无截距模型。
- CPI 是消费者价格指数（Consumer Price Index）；在 M02 的新闻例中只承担“数据所属月份 ≠ 公开时间”的信息时点桥，不被写成因果证据。
- M02 可执行预测代码契约只认证给定材料中的登记回归组；不认证恒生／CSI 全特征、完整逐月预测或真实策略执行。
