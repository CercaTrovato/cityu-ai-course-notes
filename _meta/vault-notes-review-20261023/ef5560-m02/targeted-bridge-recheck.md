## 1. §2.3.4 相关系数计算桥

### 实际复做

候选沿用后文既有三行教学数据：`x=[0,1,2]`、`y=[1,2,2]`。我独立复算得到：

- 均值：`x̄=1`、`ȳ=5/3`；
- 偏差：`[-1,0,1]` 与 `[-2/3,1/3,1/3]`；
- `Sxy=1`、`Sxx=2`、`Syy=2/3`；
- 样本协方差 `1/(3−1)=0.5`；
- 样本标准差 `sx=1`、`sy=sqrt(1/3)=0.5773502691896257`；
- `corr=0.8660254037844387`，平方为 `0.7500000000000001`。

这些数与 JSON 的 NumPy 结果、正文四步和后文含截距简单 OLS 的 `R²=0.75` 一致。

### 教学裁定

该补丁关闭真实断点。原文已经解释 cov/sd 的定性意义，却从公式直接跳到课程相关系数 0.02/0.12/0.05；一个只会高中代数的读者无法据正文把两列原数变成相关系数。新桥现在提供：原行 → 两列均值 → 逐行偏差 → 偏差乘积/平方和 → 协方差和标准差 → corr → corr² 与含截距简单 OLS R² 对照。

来源地位清楚：标题和正文均标“笔记教学例”，明确复用 §2.4.1a 的三行，不是新市场证据；又明确不能把强相关搬给真实 SPY。标准差为零时停止报告 corr 的边界也紧邻公式。没有引入新的课程数值或市场结论。
