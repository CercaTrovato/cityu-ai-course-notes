### B1 · 条件均值的公式符号没有就地搭桥

- 位置：96、165、2184 行。
- 具体卡点：正文用 `E[r_t \mid x_{t-1}]` 作为核心概念，但只用口语说“知道信号后平均水平会不会变”，没有解释 `E`、竖线 `\mid`、下标 `t-1` 在同一个表达式里分别表示什么。目标读者不默认学过概率统计，容易把竖线当除号，或者以为“条件均值”就是全样本平均。
- 已有说明：§2.1 的口语问题已经解释了概念方向，§2.2.5 也解释了 `t-1` 时点。
- 缺桥：缺一个把公式逐符号翻成人话的最小例子。
- 可能误读：把“条件均值变化”理解为每个月实际收益必然变化，或把 `x_{t-1}` 当同期信息。
- 最小修复：在 §2.1 第一次出现后加 3 行符号表和两组离散信号例：`E`=同类月份的平均，`|`=“在……已知/成立的条件下”，`t-1`=预测前已知；例如低动量组平均 0.3%、高动量组平均 0.8%，只说明条件平均不同，不保证任何单月。

- 缺桥：缺一个统一表，把“描述性 always-up”“事后多数类上限”“事前冻结的方向基准”分开。
- 可能误读：看到 CSI 51.7% > 48.3% 就宣称有方向增益；或在测试结束后挑 always-up/down 当可交易基准；或把“基准命中率”永远定义为正收益占比。
- 最小修复：在 §2.7.2 首次定义时改为：① 若比较 `always-up`，基准分数=正收益占比；② 若比较“多数类”，分数=`max(正占比,负占比)`，但测试期事后多数只用于描述难度；③ 可部署基准的方向必须在训练期选择并冻结。随后 §4、§5、§6、§7 全部统一用同一术语，逐市场注明是哪一种基准。

### B7 · §2.9a 交易复利跨过指数/对数知识起点

- 位置：1915–1964 行。
- 具体卡点：新单元要求读者把 log 收益变成 simple 收益、处理现金、分数仓位、复利、CAGR、Sharpe，但 `exp`、`ln`、CAGR、Sharpe 在本单元未定义。读者能照抄计算器数字，却不能解释为什么 `exp(0.1)-1`、为什么净值连乘、为什么 `ln[1+w(exp(g)-1)]` 不等于 `wg`。
- 已有说明：仓位/收益/现金/净值的主体和时点很清楚，两期账户表也能核对；明确了这只是教学规则，未认证真实策略。
- 缺桥：缺 log 与 simple 的具体关系、`exp` 的人话解释、复利的账户意义、CAGR 的公式及“年化平均 log 收益不等于 CAGR”的最小数值例。Sharpe 只点名。
- 可能误读：把 0.1 log 收益当 10% simple；把空仓当 0 收益；把 `mean(log)×12` 当账户 CAGR；认为 0.5 仓位时 log 收益可直接乘 0.5。
- 最小修复：在本节开头加“只需会按计算器 `e^g`”的桥：`1+simple=e^{log}`，并用 100 元账户说明；给 CAGR=`(V_end/V_start)^(1/years)-1`；说明 Sharpe 只在此披露口径、不要求本节计算。再让迁移题逐步写账户金额，而不只给最终式。

## 4. 定向问题与最小修复

### P1 · LaTeX 符号损坏

- 位置：926 行写成 `$hat r$`。
- 影响：会显示为字母 `hat r`，不是预测收益符号。
- 最小修复：改为 `$\hat r$`。

### P2 · “MSE = R² 分子”与正文精确定义冲突

- 位置：1597 行已正确说 MSE=SSE/T；2536 行却写“MSE = $R^2$ 分子”。
- 影响：读者会忘记 `1/T`，并把平方误差总和与均方误差当同一个量。
- 最小修复：将 2536 行改为“MSE 是 SSE 除以 T；同一评分行下，模型与基准两边的 `1/T` 在 OOS R² 比值中抵消”。

### P3 · “标准 K 折必然泄漏”表述过强

- 位置：1357 行。
- 影响：核心警告方向正确，但“必然把未来放进训练折”容易被拿反例反驳；普通 KFold 的某一折可能只有过去训练，但整体方案仍有折使用未来，且不遵守逐时点信息集。
- 最小修复：改为“普通随机 K 折或不带时间约束的 K 折整体上不能保证每个验证时点只用过去；多数折会用到相对该验证折更晚的数据，因此不适合作为本课默认方案”。

### P4 · active return 与 excess return 段落破碎

- 位置：1626–1647 行，尤其 1631–1640 行。
- 影响：出现“Class3 实际 README/数据用 excess=total−period risk-free，零表示匹配无风险。不得将其原结果改成 active”三个短句，但没有先定义两者，且缺标点/完整句。读者容易把“相对市场”和“相对无风险”混为同一目标。
- 最小修复：改成两行对照：`active return = 个股收益 − 市场收益，0=与市场持平`；`excess return = 总收益 − 同期无风险收益，0=与无风险持平`。明确 p.44 当前行讨论哪一个，Class 3 数据实际使用哪一个，不能互换。

### P5 · §2.9 标题超过正文证据边界

### P6 · §3.1 图形结构暗示五关串联

### P7 · “比较预测变量看 t 不看 β”会与“不用 p 排名”打架
