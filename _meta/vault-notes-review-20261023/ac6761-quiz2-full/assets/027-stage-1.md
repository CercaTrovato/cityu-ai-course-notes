## 具体问题

### F1 · P2 · 初次使用 Access 的定位与保存验收缺两步

证据：L65 进入 Query Design，L67 随即说“第一列选实际字段”，未说明这是窗口下半部设计网格的 `Field` 行，而上半部也有 Sale 字段列表。L72 说“保存查询名称为 QueryA，关闭工作副本后再核保存状态”，L133 只补充查看查询分类，没有给新手保存入口或关闭后重开验证方法。

影响：逻辑筛选能理解，但完全没用过 Access 的读者可能不知道应在哪块网格选列，也无法按文字独立判定是否真正把 QueryA 保存进数据库。这是本题要求的操作结果，不是外观偏好。局部修复即可，无需重写 SQL 或增加整课数据库先修。

建议最小修复：明确下半部网格每列代表一个输出字段，在 `Field` 行下拉选取（或双击上半部对应字段按顺序加入），保留 Show；给出 `Ctrl+S` → 输入 QueryA → 确认，并写关闭后重新打开同一工作副本，在导航窗格的 Queries/查询中打开 QueryA，确认三列、E-10 条件及五行结果。语言可按实际 Access 版本调整，不必补截图配额。
