## 年化 log 表与 239 间隔路径复算

使用原 `market_index_returns_240m.csv` 与 `market_index_prices_240m.csv` 实际复算恒生列：

- 收益文件有 240 条月度 log return。第一条是 2006-07，使用价格文件未保存的 2006-06 前置价格；其余 239 条可与当前 240 个可见价格逐行核对。
- 240 条 log return 的年化对数均值：`mean(log return) × 12 = 1.705655%`，表中显示 `1.71%` 正确。
- 将该年化 log 均值转成同口径有效年收益：`exp(0.01705655446) - 1 = 1.720285%`，表中显示 `1.72%` 正确。
- 240 条 log return 的样本波动率年化：`std(ddof=1) × sqrt(12) = 21.774697%`，表中显示 `21.77%` 正确。
- 若把全部 240 条 log return 连乘，财富因子为 `exp(sum) = 1.406537611`；它包含不可由当前价格文件独立核对的 2006-06→2006-07 首段。
- 可见价格路径为 `16971.33984375 → 22881.01953125`，财富因子 `1.348215270`，即 100→`134.821527`，表中累计显示约 `135` 正确。
- 可见价格点数为 240，所以路径间隔数为 239；`1.348215270^(12/239)-1 = 1.511468008%/年`，v2 的 `1.511468%/年` 正确。

因此 `1.71%/1.72%` 与 `1.511468%` 的差异来自样本起点不同：前者使用 240 条收益并含隐藏的前置月，后者只使用 240 个可见价格之间的 239 个间隔。v2 已明确它们不是同一口径，没有把有效的 240 收益统计误删，也没有发现额外百分比单位错误。
