## 检查范围与处理

- 提取并检查 5,995 个文档／分页／压缩包文本单元，覆盖 Markdown、JSON、Notebook、HTML、Office、PDF、CSV、SQLite 及嵌套 ZIP。检查隐藏工作表、批注、文档元数据、链接关系与可读嵌入对象。
- 对 503 个图像／低文本 PDF 页面／解码图片做中英文 OCR，64 个 OLE 对象提取内容；另核对 82 个 Notebook 内嵌输出图，其中 72 个独立图像均已做 OCR（67 个新增、5 个与前述图像重合）；两个 WMF 已经 Windows GDI 渲染并实际查看，一个是 Sale—Cash Receipt 关系图，另一个渲染为空白。没有因此修改原课件。
- 原有 145 个“密钥”模式命中核为 NIST／Maersk URL 中的词段及 sklearn 样式选择器；没有据此删除正常代码或引用。131 个 CSV 另做严格数字边界检查：一处 8 位数是订单号，并非学生学号；评论中的联系电话已处理。长数字命中主要来自模型数值、数据 ID 与本人已授权公开的学号，按上下文核对，不把正则命中直接当个人信息。
- 发现 8 个不同的第三方私人联系邮箱值，以及评论正文中的 1 处联系电话，分布于 10 个实际文件（包括重复大纲、幻灯片、笔记、CSV 和其 ZIP）。已另做发布副本移除，并检查 PDF 注释链接及 ZIP 内部内容；具体路径与原件／公开副本 SHA-256 见 [脱敏文件清单](redacted-files.json)。不在公开报告重复邮箱值。
