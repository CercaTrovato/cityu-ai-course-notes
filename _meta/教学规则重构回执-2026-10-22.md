# 教学规则重构回执 · 2026-10-22

本次交付是长期规则和流程重构，依据用户“高中生能理解”的解释起点，以及“今后必须派独立子代理审查，脚本只作有限辅助”的明确要求。没有批量重写课程正文，没有升级存量笔记的教学状态，也没有更改本人学习/提交字段。

## 1. 为什么前几轮修改仍会失败

问题不是缺少“先说人话”这句话，而是实际执行目标、读者假设和验收方式互相冲突。以下结论来自文件与具体失败样本，不是对所有历史稿的总体判定。

| 原因 | 本次直接证据 | 为什么会持续漏检 |
|---|---|---|
| 把可见形式当目标 | 总规则要求对象/动作先行，根模板却强制定义优先、七格、“所以呢”；质量文档保留大量旧配额 | 作者容易先填标签/表格，再按术语总结，缺的推理桥梁仍不出现 |
| 前置假设过高 | 根/课程/材料规则仍默认有 ML 或 Python 基础，台账登记被当作掌握证明 | 数学、语法、统计和主体切换处由作者常识自动补齐，初学者无法继续 |
| 作者自审缺少信息增量 | 旧统一流程允许主代理自己核对，多个入口停用独立盲读 | 作者知道自己的意思，容易将未写出的步骤视为已解释；取消重复评分时连独立读者也丢掉 |
| 脚本与回执形成错误安全感 | 旧 gate 接受四个 passed 和非空 evidence 字符串；M07 泛化处理多条 R 疑点 | 格式正确、数字正确、哈希相同只证明有限事实，不能推出理解连续 |
| 规则叠加而未清理入口 | 多处“当前/本轮优先”、旧模型/并行默认与新流程并存；根流程还有先同步后审查 | 换 agent 后可沿不同入口执行另一套标准；补丁数量越多，职责越模糊 |

审计基线是提交 `d21b2d7a1773c821dc9c506821e15c7cf82ad031` 的规则。旧行号与逐项证据保留于[独立规则审计](teaching-rule-audit-20261022/rules-audit.md)，历史发现与后续关闭未被覆盖。

### 1.1 可复现反例：机器通过，教学仍失败

用户指出难懂的 EF5560 M07 修订前版本 SHA-256：`9e87e36755c714bfb815104736f8759ba568c44be64e8cc24f7446c54224dec0`。本次用候选版 current 检查器复查：退出码 0，L=0、C.hard=0、R.hard=0、R.warn=80，依旧 PASS，教学字段为 `not_assessed_by_script`。见[复查摘要](teaching-rule-audit-20261022/counterexample-summary.json)及[原始机器输出](teaching-rule-audit-20261022/counterexample-machine-check.txt)。

旧 AMM 段落有符号表和六步正确计算，但读者尚未弄清池子/钱包、总余额/新增付款、交易前/整笔/交易后的三种价格，就先遇定义、长英文与公式。问题是对象、时点和关键理由没有在需要时出现；再加标签或缩短句子不能自动修复。

跨学科局部证据包括客户/银行账本的主体切换、DBSCAN 社交类比丢失密度门槛、伦理案例要求构造 maxim 却缺操作入口。它们支持“解释桥梁须按任务判断”，不支持推断这些笔记全篇质量。详见[有限案例审查](teaching-rule-audit-20261022/novice-audit.md)。本次没有修这些正文，留作后续定向整改线索。

## 2. 新框架：职责分开，教学依赖连续

### 2.1 初学者起点与课程终点

永远从高中日常语言、四则、简单代数和百分数起步，不默认大学数学、ML、编程或学科知识。当前需要的前置知识就地搭最短桥；只作背景的模块说明作用/输入输出与边界，停止无关追补。研究生课程的术语、英文、公式、原题、必要推导和条件保留。

“更通俗”不等于更模糊。噪声点可以有少量邻居，不能讲成“谁也不认识”；恒定乘积是模型选定规则，不能讲成价值守恒；银行和客户看同一笔钱，须先固定谁的账本。类比能解释直觉，还必须接回正式定义和条件。

### 2.2 通用解释链与类型边界

按具体问题→对象/动作/状态→关键理由→结果与抽象→边界/迁移组织，不强制这些标题。解释“为什么”前分清规则性质：定义/约定、逻辑推导、经验关系、程序实现或规范要求；不能把“根据公式”当理由。

不同任务的深度由 [[机制理解与可读性标准]] 规定：算法追踪状态和结束，财会计算说明主体/单位/时点，伦理法律映射事实与判据，纯概念用正反例，行政事实给来源和行动。不为纯概念造数学，不把核心操作降为背景，也不设每词图数、例数或题数。

### 2.3 去掉模板配额，保留信息责任

保留 §0–§9 导航、来源标记、完整原题与中英解析、材料定位和必要机制深度。七格改为内部覆盖问题，取消强制可见标签、定义优先和逐节“所以呢”。重复页可共用完整解释，独有内容和全部题目不减少。转录工具依赖的 `**🎙️ 课堂补充**` 及 patch/时间戳协议继续保留，未擅自迁移解析器。

## 3. 今后的必需流程

1. 作者读全部来源和规则，保存真实基线，在 scratch 完成候选；来源/计算/图源/范围清单齐备，教学保持待审。
2. 主代理派**未参与写作的独立子代理**，按高中知识起点实读本次全部教学范围。新写/重写审全篇；局部融合审所有新增和受影响正文、图、摘要、自测及顺延内容。
3. 第一派单只提供候选和教学前文/任务，审查者自行识别依赖、实际复述/复做/判断，先落盘 `stage-1.md`；之后才 follow-up 规则、真实 diff、来源和机器疑点。自动带入的上下文须披露，不能假称完全盲审。
4. 独立报告记录具体问题、首次断点、已有解释、缺失桥梁、可能误读和位置；不靠自己的专业知识补齐后判通过，不打读者分数，不以标签/脚本论证质量。
5. 主代理核事实并处理意见，作者修正文；原审查者只复核具体缺陷及依赖。阻塞是无法完成任务或会作错关键判断；纯措辞偏好/额外同型例通常是建议。
6. 主代理核来源、重要计算、实际图文和机械问题，绑定最终候选/独立报告/资产，过门槛后单一原子写回，再按统一流程 §6 同步并回读。

两阶段是一次审查的信息隔离，不是两轮全篇盲读。不得恢复无缺陷重复全库 Q/R、评分或强制用户逐篇试读批准。子代理模型严格低于主模型；没有合规代理可用时继续候选与辅助核对，保持待独立审查，不能作者换身份代签通过。

纯维护有明确例外：仅错别字/链接/元数据且不改变教学含义，真实 diff 确认后走 `--check-only`、适用链接与 CAS/原子写/回读，记录 non-teaching，保留原教学状态；公式、数字、条件、方向、图义和解释顺序不属于该例外。

## 4. 规则和工具改了什么

[[可读性总规则]] 统一教学，[[机制理解与可读性标准]] 定类型深度，[[笔记模板]] 负责导航，[[笔记制作与融合验收流程]] 管角色/证据/同步，[[笔记质量规范]] 定阻塞条件，[[对抗自检清单]] 提供一次集中核对，[[机制笔记子代理任务模板]] 分作者/独立审查/定向复核。R 机械细节移到 [[可读性机械检查参考]]。

根 AGENTS/CLAUDE、五门课两类入口与细则、原题/练习/材料/图示/作业入口、两份融合技能及其模板、README 和设计规格同步修正，去除旧默认基础、先写后审、默认创作并行和旧“当前”口径。完整路径与前后 SHA 见[变更索引](teaching-rule-audit-20261022/change-index.json)。

工具没有增加教学评分。`note_quality.py` 继续有限 L/C/R 与 historical，新增明确的 `teaching_assessment: not_assessed_by_script` 输出。`note_release_gate.py` 用 note-review-v2 绑定独立报告、最终候选与作者/审查者标识；还修正 current 结果缺失可漏判、异常退出和子进程 UTF-8 边界。`merge_apply.py` 未改，通过既有调用获得新记录门槛；材料 audit、dry-run、CAS 和原子写未撤销。

记录门槛不能鉴定代理标识是否真实、是否真独立、是否读懂或语义正确。主代理必须核实际调度和报告；字段齐/报告长不作为质量证据。旧 note-review-v1 保留历史，不追改，也不能用于本框架的新教学发布。
