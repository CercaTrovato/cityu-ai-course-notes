# 备份与公开发布规则

本规则依据 2026-10-21 用户明确要求生效，优先于旧入口中的“开工必做全库 ZIP”“个人材料／作业默认私有”“源音频一律不入 Git”。有日期的历史回执保留当时事实，不因本规则追改成已公开或已推送。

## 1. 日常保存与恢复

- 取消每次开工、每日定时及转录融合前的全库 ZIP；日常通过 Git 历史与 GitHub 远端保存版本。
- 开工检查工作区、暂存区和未跟踪文件；已有未提交改动不是云端备份。确认目标有可恢复的 Git 版本；未提交目标保留本任务原始字节与 SHA-256 到库外 scratch，不为此复制整库，也不擅自提交其他会话成果。
- 开工运行 `integrity_check.py snapshot <任务标签>`，收工 `verify`；快照只记录状态，不能恢复正文，并发任务另存自己的基线。
- 保留 `safe_write.atomic_write`、写前哈希比对、写后回读、原始课件只读、电脑与手机自动同步关闭等防损要求。发现损坏停下报告，只从真实已有版本恢复，不凭记忆重建。
- 每批已完成且核验后的 CityU 工作，按本规则提交并推送 GitHub；这是用户对后续日常保存流程的授权。用户当前任务明确要求先仅本地处理、暂停或不推送时，以该要求为准；2026-10-21 前阶段规则修改与清理先仅本地执行，后续用户已明确授权全库检查、提交与推送。
- 提交前 `git fetch`，逐项检查实际差异、新文件、遗漏及发布范围，仅纳入本批成果，不混入其他任务改动；不得附 AI 署名、绕过钩子或 force push。
- 推送后用远端查询核对对应分支提交 SHA；本地提交、暂存、`push` 尝试和 GitHub 已核实分别记录。失败或受阻明确写“云端未更新”，不能把本地已保存称为云端完成。

## 2. 全库资料公开范围

- 用户已授权公开知识库中的本人个人材料、个人姓名／学号、个人作答、已提交或待提交稿、练习解析、学习导览、代码、结果、个人邮件整理、简历素材和核验记录；`assignment/`、旧 `assignments/` 与个人材料不再因类别被整体忽略。学习导览与正式提交稿仍分开组织。
- 讲义、数据和转录纳入 GitHub 发布范围；源音频按 §4 保存到 Google Drive，由 GitHub 索引链接。库外资料不会因此自动复制入库；文件大小或平台限制须列清单并落实适当上传方式，不得静默漏掉再声称“全部上云”。
- 密码、访问令牌、私钥、会话 cookie、认证／同步配置不公开；本人的公开授权不扩展到第三方的私人通信、学号／联系方式、名单座位表等个人信息。混合文件先生成去除这些内容的发布副本，原件只读，记录原件与副本对应及尚未覆盖项。
- 仅继续排除上述敏感配置、第三方个人信息、运行缓存、锁文件、临时产物和每次重建的完整性快照；不把个人作业一概称为“不可发布”。材料公开不改变来源版权或原有许可，沿用 `NOTICE.md`。
- `.gitignore` 放开只是允许纳入 Git，不代表已扫描、已提交、已上传。首次全量发布还须检查全部新增材料及嵌入附件中的秘密／第三方信息、超限文件和实际远端覆盖；是否完成以本次发布清单和远端核实为准。
- GitHub 公开、Canvas 提交、发送邮件、本人学习、评分是独立动作／状态；本规则不授权代提交作业或发送邮件。

## 4. 原始音频保存到 Google Drive，GitHub 保存索引（2026-10-21 用户补充）

- 原始 `.mp3/.m4a/.wav/.flac` 音频保存在 Google Drive；GitHub 只提交来源说明、文件名、课程／讲次、大小、原始 SHA-256 与可下载的 Drive 文件链接，不把大音频放进 Git 历史。
- 本次目标文件夹为 [CityU-Course-Audio](https://drive.google.com/drive/folders/1PxFVj2jAvPRMMKd56gxqvxbWjmIlnyvo)，权限为“知道链接的任何人可查看”；后续不得把密码、私人通信等排除资料放入这个公开文件夹。
- 音频先检查可用的转录、文件元数据及已知隐私内容；实际没有逐字重听时必须注明，不能把 ASR 扫描当作音频逐字隐私保证。发现私人信息时先另做发布副本；完整原件保留本机，不直接公开。
- 上传完成后逐文件回读 Drive 文件 ID、名称、字节数及父目录，核对分享权限与可下载性；可取得服务端哈希时比对，没有哈希就明确仅验证了名称／大小／权限，不虚称逐字节云端校验。
- GitHub 的音频索引与机器清单须覆盖全部本次音频，区分已上传、失败、隐私待处理和链接待核；上传失败不能记“全部保存”。链接必须来自完成后的实际回读，不预造文件 ID。
- 连接器遇大小限制时改用已登录浏览器的正常文件上传流程；保留源格式和字节，不为缩小体积擅自转码。上传不代表本地文件可删除，清理原件仍须用户明确要求。

## 5. 脱敏发布副本

原始课件和已提交作业保持本地字节。含第三方私人联系信息的文件先在库外生成脱敏副本，按公开相对路径将该副本写入 Git 索引；提交前核副本及其哈希，保留原件／发布版本映射。此时工作区与 Git 中的公开副本有预期差异，后续禁止未经隐私检查的 `git add -A` 覆盖这些发布副本。既有远端历史没有因此重写，不能声称历史已清除。
