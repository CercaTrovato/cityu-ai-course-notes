3. Ridge Regression (40 points)¶

In Section 3.4, Ridge Regression, try the following values of alpha: 0.001, 0.01, and 0.1.

Evaluate the performance of the three Ridge Regression models and compare their results. Identify which alpha value provides the best model performance.

In [41]:
import numpy as np
import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import Ridge
from sklearn.metrics import r2_score, mean_absolute_error

# Regenerate the sin(x) data used in the ridge example.
x_ridge = np.array([degree * np.pi / 180 for degree in range(60, 304, 4)])

np.random.seed(10)
y_ridge = (np.sin(x_ridge) + np.random.normal(0, 0.15, len(x_ridge)))

ridge_data = pd.DataFrame({"x": x_ridge, "y": y_ridge})

# create from x^2 to x^15
for degree in range(2, 16):
    ridge_data[f"x^{degree}"] = ridge_data["x"] ** degree

ridge_predictors = ["x", *[f"x^{degree}" for degree in range(2, 16)]]

# split training set and validation set.
X_train, X_valid, y_train, y_valid = train_test_split(
    ridge_data[ridge_predictors],
    ridge_data["y"],
    test_size=0.3,
    random_state=0
)

# compare different alpha
for alpha in [0.001, 0.01, 0.1]:
    model = make_pipeline(
        StandardScaler(),
        Ridge(alpha=alpha)
    )

    model.fit(X_train, y_train)
    predictions = model.predict(X_valid)

    r2 = r2_score(y_valid, predictions)
    mae = mean_absolute_error(y_valid, predictions)

    print(
        f"alpha={alpha}: "
        f"R2={r2:.4f}  "
        f"MAE={mae:.4f}"
    )

alpha=0.001: R2=0.9699  MAE=0.0991
alpha=0.01: R2=0.9747  MAE=0.0920
alpha=0.1: R2=0.9649  MAE=0.1112

Therefore, in this division, alpha=0.01 performs the best because its validation set $R^2$ is the highest while its MAE is the lowest.

import pandas as pd

from sklearn.preprocessing import OneHotEncoder
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, r2_score

ResearchData = pd.read_csv("Airbnb.csv")
y = ResearchData["log_price"]

def prepare_features(feature_cols, categorical_cols):
    x = ResearchData[feature_cols].copy()

    encoder = OneHotEncoder(
        drop="first",
        sparse_output=False
    )

    encoded = encoder.fit_transform(x[categorical_cols])

    encoded_df = pd.DataFrame(
        encoded,
        columns=encoder.get_feature_names_out(categorical_cols),
        index=x.index
    )

    return pd.concat(
        [x.drop(columns=categorical_cols), encoded_df],
        axis=1
    )

def evaluate_model(x):
    x_train, x_test, y_train, y_test = train_test_split(
        x, y,
        test_size=0.30,
        random_state=0
    )

    model = LinearRegression()
    model.fit(x_train, y_train)

    predictions = model.predict(x_test)

    return {
        "Number of features": x.shape[1],
        "MAE": mean_absolute_error(y_test, predictions),
        "R2": r2_score(y_test, predictions)
    }

# 原模型
original_x = prepare_features(
    [
        "property_type",
        "accommodates",
        "bathrooms",
        "bedrooms",
        "beds"
    ],
    ["property_type"]
)

# 加入 cancellation_policy 的新模型
new_x = prepare_features(
    [
        "property_type",
        "cancellation_policy",
        "accommodates",
        "bathrooms",
        "bedrooms",
        "beds"
    ],
    ["property_type", "cancellation_policy"]
)

results = pd.DataFrame(
    {
        "Original model": evaluate_model(original_x),
        "New model": evaluate_model(new_x)
    }
).T

display(results)
Number of features MAE R2
Original model 7.0 0.438920 0.359504
New model 11.0 0.437968 0.361610

The original model obtained an MAE of 0.438920 and an $R²$ of 0.359504. After adding cancellation_policy, the new model obtained an MAE of 0.437968 and an $R²$ of 0.361610.

The new model performs slightly better because its MAE is lower and its $R²$ is higher. However, the MAE decreased by only approximately 0.22%, while $R²$ increased by about 0.0021. Therefore, cancellation_policy provides only limited additional explanatory power for Airbnb log prices after the other predictors have already been included.
