本课按[异步收尾规范](../../_meta/final-review-2026/ASYNC-MAINTENANCE.md)执行：主会话每轮只保存 maintenance/inbox 原始交接并立即继续；复用一个 `gpt-6.1-sol` 维护子代理顺序归档、自检、适用独审及三端同步。不要等发布结束才给下一题；当前正确性疑点仍即时处理。后台独占本课进度文件，主会话只追加事件；共享 Git/发布须互斥。 本课此前单独安排中“根 Git 和共享本地/线上看板仍交总监督”的边界，现由总监督明确委派本课维护子代理按统一互斥规则执行；旧事件及旧分工说明保留为历史，不覆盖本条当前执行职责。


## 日常复习：本地笔记优先（2026-11-27）

先按当前分支读取本课 `../notes/` 的对应小节及已有学习解析，再开展讲解和练题；不是先打开 PPT/PDF。入口示例：[名录中的笔记入口：M01 导论笔记](../notes/M01-导论-AI与伦理.md)，实际按当前单元定位，不要求每次从 M01 重读。

原件只在笔记缺内容/题图、有疑点/冲突或新通知/版本需要核验时定向读取；先说明要核什么及页/题/时段范围。sources 的排列和“原始资料权威”不决定读取队列；v0.9/转录待补标签不自动触发整篇回源。复用笔记已有图、原题、解析和勘误；核验结果回填以便复用。详情以统一协议“本地笔记优先”为准。


适用本目录及其子目录；继承课程/根规则，不用于正式作业提交。登记的复习会话：`01a207d2-9cd6-7491-aed6-aa50fbebae46`。任何接替会话依文件恢复，不把聊天记忆当最新状态。

1. 先读 [README.md](README.md) 和 [五课统一协议](../../_meta/final-review-2026/WORKSPACE-PROTOCOL.md)。
2. 用 [动态路线](final-2026/route.md)、[真实进度](final-2026/progress.json) 和最近 session/mistake 定位本轮，然后先读相应本地笔记/已有解析。考试依据、资料准备、框架和地图按需或在有更新时读取；不要把原始课件读取作为默认启动步骤。
3. 本课只有一个后台维护写者；主会话只追加不可变原始交接，不同时修改 sessions/mistakes/progress/route/README。后台取本课锁、写前核旧哈希，不覆盖并发修改。只在明确委派范围内完成本课三端收尾，不改其他课程、正式作业或共享代码。
4. 按 [本课学习地图](final-2026/learning-map.md) 先建立总体脉络，再讲当前分支的结构与连接，最后进入知识点、例子、小题及变式。每一步说明理由和适用条件；不要直接用零散诊断题代替导览。已做过地图则从真实停点接续，不重复开头。先考内训练/模拟，后完整补学不考内容；固定框架不改。
5. 每轮结束先把实质问答、讲解、本人原答、提示、纠错、方法、复测和下一步保存为唯一原始交接，立即继续教学；后台顺序整理 sessions/mistakes 并更新 progress、route、README。没有作答不得改“独立做对/复测通过”；按事件 ID 幂等，不回退新停点。
6. 框架与 ID 不因反馈随意重写；后台每批核一次 `_meta/tools/review_workspace_check.py --course IS5113`。纯记录/复用已核笔记不重审旧教学；新增解析按适用流程一次独立轻量抽检，作者/审查者分离。主会话不等待维护检查，不能把管理校验当教学认证。
7. 后台取得 shared-publish 锁后完成本课 Git、本地与线上收尾，并逐轮留回执；可合批发布，不省略任何轮次。忙/失败则保留待处理原因与恢复点，不阻断可独立开展的教学。跨会话消息、外部提交/发送权限不由本文件扩大。

本课特别注意：不得将“约一页案例材料”改成答卷限长；前三题合计 25% 不是每题 25%；不称 Q1 为已确认选择题。

每轮接续位置同时写明“全课主干 → 分支 → 当前知识点/题型”，保留理解理由和独立作答的不同证据；分支结束回到总图串联，下轮用简短提取/变式复测。完整执行规范见统一协议“先整体、后分支，再到知识点与考题”。
