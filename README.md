## 三个核心机制

**① 前置知识台账** — 每门课 `_meta/知识层级台账.md` 记录「L0 入场基线」和「每个概念首现于哪一讲」。写第 N 讲时，不在表里的概念**必须就地展开**并登记回表。这是"读到第 N 讲不出现陌生概念"的机制保证。

**② 正文按学习逻辑重排** — 课件顺序是讲课顺序，不是学习顺序。正文重排，另附「笔记小节 ↔ 讲义页码」映射表。

**③ 讲义 × 转录双源比对** — 讲义是"教授准备讲什么"，转录是"教授实际讲了什么"。**两者的差集最值钱**：课件没有但课上讲了的（🎙️ 最高价值）、课件有但课上略过的（⏭️ 可降优先级）、教授明说会考的（🔴 直接考点）。
