# IS5113 知识层级台账

> **这是本课连贯性的机制文件。写任何 module 笔记前必读，写完后必须回写。**

## 使用规则

写 M(N) 笔记时，正文里每出现一个概念，按下表判断：

| 情况 | 怎么处理 |
|---|---|
| 在 **L0 入场基线** 里 | 直接用，不解释 |
| 在 **L1** 里且 `首现 ≤ N` | 直接用 + `[[回指]]` + **一句话唤醒** |
| 在 **L1** 里但 `首现 > N` | 只给一句话预告，标明"第 X 讲展开"，不提前展开 |
| **不在表里** | **必须在本 module 就地完整展开**，然后登记回 L1 |

**验收**：把 M01…M(N) 连读，不应出现"没定义过、这里也没解释"的词。

## L0 · 入场基线

读者进门时**已经具备**的知识。以下内容在笔记里可直接使用，不需要解释。

**AI / 机器学习基础**
- AI 的宽泛直觉（会用 ChatGPT 这类工具）
- 机器学习：监督学习、无监督学习、训练集 / 验证集 / 测试集、标注数据
- 模型、算法、参数、训练、推理、部署
- 评估指标：准确率 accuracy、精确率 precision、召回率 recall、F1 分数
- 过拟合 / 欠拟合
- 神经网络、深度学习的基本概念
- 大语言模型（LLM）、生成式 AI 的基本概念
- 数据的基本概念：结构化 / 非结构化、数据质量、数据清洗

**一般常识**
- 基本的商业词汇（公司、客户、成本、效率）
- 基本的统计直觉
