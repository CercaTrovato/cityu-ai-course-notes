## 3. 从官方材料能推出的"攻略" ⚪

在没有学长口碑的情况下，以下是从课程材料本身推出的、可执行的判断。**这些是我的推断，不是过来人经验。**

### 3.1 三条硬约束（必须知道）

1. **持续评估 ≥25% 且笔试 ≥25%，两部分都要过。** 一边高分补不了另一边。这是官方课程目录写死的，讲义上没有
2. **Participation 和 Group Project 官方明确允许用 GenAI。** 这条很实用——小组项目 40 分，允许用工具意味着门槛在"批判性思考"而不是产出速度
3. **笔试 2 小时，英文作答。** 术语必须能用英文写出来

### 3.2 评分维度暗示的题型

三项评分维度**全都强调 application 与 critical thinking，没有一处提"记忆"或"复述"**：

- 小组项目：Original thinking / Rational analysis / Structure and formation / Reasonable conclusion
- 笔试：Application of learned knowledge with critical thinking

⚪ **推断**：笔试大概率不是名词解释，而是**给场景、用理论分析**。M02 的作业（交警摄像头案例，五问结构）很可能就是题型样板。

### 3.3 精力分配建议 ⚪

| 内容 | 建议投入 | 理由 |
|---|---|---|
| M02 七大道德理论 | **最高** | 是全课的工具箱，后面每一讲都要用；且 M02 的 *Case for / Case against* 结构直接示范了评价题怎么答 |
| W3–W6（FATP 四议题） | 高 | 对应 ILO-2，且占四周 |
| W9 全球 AI 治理与监管 | **高** | 对应 ILO-5 和小组项目 (b) 部分；也是官方 CILO 中法律权重（50%）最可能落地的一讲 |
| M01 的 p.36–59 商业 AI 全景 | **低** | 24 页低信噪比模板内容，见 [[M01-导论-AI与伦理#9.3 课件自身的问题\|M01-导论-AI与伦理 › 9.3 课件自身的问题]] |

### 3.4 小组项目的早动手理由 ⚪

讲义 p.9 写项目 "beginning soon"，且演示在 **W12–W13（11/17、11/24）**。40 分的比重 + 要"设计一套治理策略"，意味着需要真实调研。**W9 的监管内容是项目 (b) 部分的直接输入**，但 W9 在 10/27 才上——**如果等到 W9 之后才开始做项目，只剩三周。** 建议 W9 之前就把行业和公司选定、把研究部分（(a)）做完。

## 4. 小红书抓取（待你登录后我再跑）

**当前状态**：❌ 未取到。

**原因**：两层阻塞，2026-09-08 实测确认。

1. **缺 Chrome 扩展**（先决条件）：`opencli rednote login` 报 `BROWSER_CONNECT: Browser Bridge extension not connected` —— 它靠一个 OpenCLI 的 Chrome 扩展驱动浏览器，**本机未安装**，所以命令根本没能弹出登录窗口
2. **未登录**：装好扩展后还需要小红书登录态，否则报 `AUTH_REQUIRED: Rednote web_session cookie missing`

**另外**：`WebSearch` 基本不索引小红书正文，中英文各试一轮返回的全是留学中介页面。搜索引擎这条路走不通，**必须用 rednote 适配器**。

### 你需要做的（一次性）

**第 1 步 · 装 OpenCLI Browser Bridge 扩展**

从 <https://github.com/jackwener/opencli/releases> 下载扩展，然后 `chrome://extensions` → 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选中解压出来的目录。

**第 2 步 · 保持 Chrome 开着，登录小红书**

```bash
opencli rednote login
```

这条会驱动浏览器等你登录，完成后自行退出。验证：

```bash
opencli rednote whoami
```

> ⚠️ 我不能代你登录（涉及账号凭据，必须你本人操作）。装扩展这一步也建议你自己做——需要从 GitHub 下载并加载未签名的扩展，你应该自己确认来源。
