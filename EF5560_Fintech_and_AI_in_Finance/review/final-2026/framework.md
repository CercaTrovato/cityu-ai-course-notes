## 2. 整门课怎样连起来

前半程回答“能否用当时已有的信息预测并投资”；后半程回答“金融服务靠什么机制运作、收益从哪里来、损失由谁承担”。两半共享一个习惯：先确认对象和证据，再判断数字能推出什么。

| 学习链 | 前一步给后一步什么 |
|---|---|
| U01 数据与收益 → U02 回归和样本外评估 → U03 线性 ML → U04 非线性 ML | 先做出没有偷看未来的观测，再比较预测方法 |
| U03、U04 → U05 模型解释 → U06 投资决策与绩效 | 先分清模型怎样使用输入，再看权重、成本、风险和结果 |
| U07 区块链与共享记录 → U08 加密资产 → U09 DeFi、U10 代币化资产 → U11 数字货币 | 逐步分清记录、资产、合同权利、资金和退出渠道 |
| U07、U11 → U12 支付 → U13 信贷与众筹 | 沿着一笔资金走完服务，再算收入、成本、信用损失与责任 |
| U06、U13 → U14 智能投顾；U01、U07、U12、U13 → U15 网络安全与合规 AI | 将预测、客户需求、权限、人工复核和恢复联系起来 |

默认按 U01→U15 学。U03–U04 内部保留市场月度预测与股票周度截面两条任务，不能把两者的观测、目标、基准混在一起。U07 可在前半程较累时提前开始；这只是穿插顺序，不删除 U01–U06。

百分比、百分点、基点、带正负号的金额、均值和简单平方运算会在首次用到时补；统计与编程均不作为你已经会的前提。不要求背 Python/R 代码，仍要看懂数据输入、时点、变换和输出检查。

## 3. 逐单元要学什么、会做什么

以下是完整路线，尚未展开各单元答案。`A/B` 指卷名，`MC` 指 Section A 选择题，`SA` 指 Section B 短答，`CAL` 指 Section C 计算。精确题号和物理页在第 4 节。L02–L04 一律使用 `canvas-20261020` 新版物理页；旧笔记部分仍保留旧页码，打开时先看其版本说明。

### U01 · 做出一行可信的金融数据

从价格、简单收益和复权开始，区分股票超额收益与减去市场收益；再检查日期、币种、频率、缺失、异常值、固定股票池与幸存者偏差。沿 PDD/JD 配对交易辨认多空方向、投资假设与历史回测各能说明什么。财报所属期和公开披露时间必须分开。

完成后应能审查 AI 下载的表，指出一列最早何时能进入预测，并解释为什么“回测赚钱”不能直接证明一个商业事件造成收益。先修只需基本四则运算；难点是未来信息、权重口径与因果多推一步。

材料：L01 p.6–25、27–38、其余数据/风险页面；L03 p.29–35；A-SA1，B-MC2、B-SA1。全文覆盖仍回到 L01 p.1–58，不因只列重点页删去内容。

### U02 · 看懂回归，再公平检验预测

读散点与分箱、截距、斜率、残差、标准误、p 值、样本内 R²。然后把训练、验证、测试的用途分清，比较固定、滚动与扩展窗口，手算 SSE/MSE 和相对正确基准的样本外 R²，检查方向命中率的基线。

完成后应能把“系数证据、训练拟合、后续预测、投资盈利”分别作答。先修 U01；难点是百分数单位、统计显著性和预测好坏不互相代替，以及 MA12 与零预测各自对应的目标。

材料：L02 新版 p.6–36、38–56；L03 p.2、5–8、22–24；A-MC2、A-CAL1，B-MC1、3。L02 p.26–27 是新版新增选择题。

**来源口径提醒**：L02 新版 p.45 的 weekly stock active return 用“匹配本地市场”说明零基准；L03 新版 p.29 与 B-MC2 则明确为股票收益减同期无风险收益。两者不能混减。学习时按该页或该题写明目标、分母/期间与基准；B-MC2 按无风险收益口径。保留原件差异，待末节课/TA 核实，不把两种口径悄悄统一。

### U03 · 为什么要收缩、选择或压缩输入

从相关输入令斜率不稳出发，对照前向选择、Ridge、LASSO、Elastic Net、PCR 与 PLS。学习标准化、惩罚强弱、成分构造、验证选择与冻结后的测试；股票模型还要看周内排序及预测数值与排序的区别。

完成后应能根据任务选方法、用已存训练均值/标准差处理新观测，并解释零系数在这一拟合规则中的含义。先修 U02；难点是 PCR/PLS 是否使用训练目标、缩到零不等于经济上永远无作用，以及测试数据不能参与挑模型。

材料：L03 新版 p.6–27、29–54，L02 p.32；A-MC1、3，B-CAL1。新增题 p.26–27 也进入练习。

### U04 · 什么时候一条直线不够

手走一棵树的分裂与叶均值，分清按月份的经济状态和同周股票分组；再对照 bagging、随机森林、逐轮修正的 boosting。用小型神经网络理解隐藏单元怎样表示条件变化，以验证损失选择训练时长，检查股票面板为什么按日期隔离。

完成后应能解释“动量在不同波动状态方向不同”，选择合适的停止点，并说明复杂度为什么不保证未来更好。先修 U02–U03；难点是分裂对象、交互作用、训练损失与验证损失用途不同。

材料：L04 新版 p.4–38、44–56；A-SA2，B-SA2。未被 mock 单独问到的森林、boosting、叶大小也保留。

### U05 · 模型的解释能说明到哪里

用线性系数、LASSO 系数、将输入置零的重要性和响应曲线，区分“这个模型如何改变预测”与“现实中改变该变量会怎样”。保留原例的固定输入、是否重训、比较样本与单位。

完成后应能读一张先升后降的响应图，并给出模型支持的结论及不能证明的因果判断。先修 U03–U04；难点是把重要性当显著性、把响应当真实收益或因果效应。

材料：L05 p.3–12、26；B-MC4。这部分虽在两卷题数不多，仍是课程独立目标。

### U06 · 把预测变成持仓，并检查是否值得做

从分组、多空和只做多开始，计算权重、总/净暴露、组合收益与交易成本。再读累计财富、均值/波动、同频 Sharpe、年化条件、最大回撤；最后解释市场择时、风险与仓位、CAPM 的 alpha/beta 和本地市场基准。

完成后应能回答“预测稍好是否已证明可赚钱”，并沿同一资金分母算毛收益、净收益与风险。先修 U01–U05；难点是买卖两边费用、超额/总收益、周/月/年单位及回撤分母。

材料：L05 p.14–54；A-MC4–6，B-MC5–6。权重构造、择时和仓位虽未在两卷完整展开，仍逐项练。

### U07 · 共享账本究竟替银行解决了什么

先看出口商为什么要融资，再学账本、哈希、签名、区块、共识、重复支付和公有/许可网络。用同一应收账款在两家银行申请的过程，计算总融资上限和剩余额度，检查谁负责更新记录、纠错与现实核验。

完成后应能区分“文件没改、贷款已登记、货物真实、债务可收回”四个判断，也能评估处理时间改善是否证明信用风险下降或因果效果。先修 U01 的金额/证据思路；难点是链上记录不能自动保证链下事实。

材料：L06 p.3–54，重点 p.17–38、46、52–54；A-SA4，B-MC7–9。保留 TradeLens、J.P. Morgan、Broadridge 等案例的采用与成本问题。

### U08 · 加密资产的机制与经营现金流

学习 BTC 发行、区块空间/手续费、分叉、密钥与托管；对照 ETH 智能合约、预言机、staking、费用和 rollup。再分别看矿工、交易平台和持币公司的收入、成本与风险，手算发行新股前后的每股 NAV。

完成后应能解释共同历史为何不锁定分叉后的价格，区分账户资产、合同权利及破产回收，并判断增发价相对 NAV 的作用。先修 U07；难点是股权比例稀释与每股资产变化不同、代币奖励和法币回报不同。

材料：L07 p.3–35、41–54；A-MC7–8，B-CAL2。AMM 单独放 U09，避免两处重复讲但无人负责完整计算。

### U09 · DeFi 的交易、借款与清算

沿一次 USDC/ETH 交易追踪池子储备，分清交易前边际价、平均成交价与交易后边际价。再学 TVL 的边界、储蓄收益来源、抵押借贷、借款限额、清算门槛、健康因子、清算奖金、资金利用率与跨链背书。

完成后应能手算小型 AMM 与清算例，解释“还能保持账面余额”为什么不保证可提现或背书安全。先修 U07–U08、U01 百分比；难点是不同价格/不同分母，以及抵押仍高于债务也可能到清算线。

材料：L07 p.36–40；L08 p.3–8、35–54。两卷没有独立的大题直接覆盖这些计算，因此特设覆盖检查与自编变式，不能据 mock 漏题而跳过。

### U10 · NFT 与现实资产代币化：持有人得到什么

逐层核对 token、媒体/metadata、版权或兑换权，区分代币化基金、黄金、债券的底层现金流、托管与权利。分清按 NAV 赎回和在二级市场按可成交价卖出，并计算折价及卖出所得。

完成后应能追问“谁欠我什么、谁保存资产、怎样退出”，而不把转账次数当收入或流动性。先修 U07–U08；难点是持有 token 与持有完整法律权利不等同，24/7 交易与按 NAV 即时赎回不同。

材料：L08 p.9–34、54；A-MC9–10，B-MC10–12。所有条款按课件版本理解，涉及现行产品判断时再核一手来源。

### U11 · 稳定币与 CBDC：承诺、储备和兑现

比较储备支持、加密抵押、算法式稳定币的机制；走完铸造、转移、卖出与赎回，检查资格、截止时间、费用及实际到账。对照 CBDC、商业银行存款和稳定币的发行/债权关系，讨论银行资金流出、钱包故障与支付采用指标。

完成后应能解释有足额储备为何仍可能短时脱锚，区分货币债权安全与访问可用性，并用活跃/复用及明确分母评价采用。先修 U07–U10；难点是银行时钟、储备的市值/流动性、钱包运营方与负债方。e-CNY 的不同阶段/钱包产品不机械套同一债权描述。

材料：L09 p.3–54；A-MC11–13，B-MC13、B-SA4(a)。保留 Terra、USDC/SVB、储备收入与分销成本、货币主权等未被 mock 逐项覆盖的内容。

### U12 · 支付完成之前，钱经过了谁

沿卡支付、预付钱包、账户转账、跨境汇款走授权、清算、结算、商户到账和争议处理。分开界面与底层轨道、汇率与转账速度、商户费与处理商留存收入。再学 open banking、嵌入式金融、BNPL 的商户结算、融资及信用损失，并保留 AI 代付授权边界。

完成后应能以相同收款币种金额比较两家报价，算 fee/留存/贡献，并解释交易量不变为何利润仍会变。先修 U07、U11；难点是总流水、收入、利润和客户本金不能混记。

材料：L10 p.3–54，重点 p.23–30、33–41、43–53；A-CAL2，B-SA3。

### U13 · 数字信贷与众筹：谁出钱，谁最终承担损失

沿申请、身份核验、授信、放款、资金持有、还款与服务追踪责任。比较银行、marketplace、嵌入式信贷与基础设施模式，区分风险排序、概率校准、完整贷款观察期；计算预期信用损失、贡献、回收与 first-loss guarantee。最后对照捐赠、奖励、股权、债务众筹和 all-or-nothing 门槛。

完成后应能把模型好坏与贷款定价联系起来，沿合同分摊违约损失，并判断众筹达标究竟证明了什么。先修 U02、U07、U12；难点是高低排序正确仍可能低估损失，平台不直接出资仍可能保留保证风险。

材料：L11 p.3–54；A-SA3，B-MC14–15。L11 p.39–54 在 S34 中未讲完，但已是发布材料，不能视为免考。

### U14 · 智能投顾：客户能不能承担这项风险

根据期限、近期现金需要、承担损失的能力和主观意愿，讨论建议与再平衡；比较按 AUM 收费的收入、可变成本、固定成本和盈亏平衡规模。

完成后应能解释为什么同样说“不怕亏”的两位客户未必适合同样配置，并列出 AUM 业务的计算输入。先修 U06；难点是意愿和能力不同、再平衡不保证到期资金。现有依据是 syllabus p.3、A-MC14、16 与 B-MC16；**Lec12 详细内容待取得，不伪造其页码或完整授课范围**。

### U15 · 网络安全、RegTech 与金融文本 AI

现已能从 mock 定位两条任务：备份为什么需要独立访问/恢复安排；名单匹配出现身份冲突时为什么需要验证与人工处理。结合 L01 的 AI 输出核查、L07 的可疑交易筛查、L10–L11 的权限与恢复，再等待 Lec12 补入实际文本 AI 与课程总结。

完成后应能区分“模型给线索”与“已经确认身份/合规结论”，解释共同凭证会让备份同遭破坏的风险，并指出应核来源与责任人。先修 U01、U07、U12–U13；难点是不能由姓名相近直接定罪或由一个矛盾字段直接放行。材料：A-MC15、B-SA4(b)、L07 p.49–52、L10 p.7、27、L11 p.42–43；Lec12 待补。这里是题型路线，尚非完整的网络安全/RegTech 教程。

## 6. 第一轮诊断与以后每轮的教法

今晚先完成框架，不占用小组录制熟稿时间。你开始复习时，先用约 20–25 分钟做 8 个短任务；可分两次，每次只呈现一题，先听你说如何开始，再决定是否提示。题目将自编并标来源，暂未出题、未实施：

| 诊断任务 | 观察什么 | 决定从哪里补 |
|---|---|---|
| D1 单位与收益 | 百分比/基点、分母、超额收益 | U01；必要时先补四则运算和单位 |
| D2 一行信息何时可用 | 财报期、披露日、预测日 | U01，再接 U02 的日期隔离 |
| D3 两张模型结果表 | 显著性、训练/验证/测试、基准 | U02–U03 |
| D4 条件变化与训练停止 | 分裂对象、交互、验证损失 | U04–U05 |
| D5 一笔投资的账 | 权重、成本、风险、收益分母 | U06 |
| D6 一笔应收账款 | 总上限、记录完整性、真实性和偿付 | U07 |
| D7 一笔数字资产/支付/贷款 | 谁欠钱、怎样退出、收入/成本和损失 | U10–U13；可追加一个分支查 U09 |
| D8 客户与系统例外 | 风险能力、筛查冲突、恢复责任 | U14–U15，材料不齐的细节标待教 |

这不是期末预测分数。若某处需要提示，记录具体卡点及提示，不把提示后答案计为独立做对。若诊断遗漏一个单元，记“未测”，不能由相近题推定掌握。U08 的每股 NAV 首轮不直接测，进入 U08 前再用一个短任务定位起点；U09 只有实际追加了 D7 分支才算测过对应技能。

之后每个知识点按同一节奏进行：提出一个具体任务 → 短讲解与小例 → 你尝试原型题 → 按卡点逐级提示 → 改一个关键条件重做 → 反馈及记下方法。英文题保留原题与全部选项，中文讲清条件，再练简短英文作答；先理清意思，不一次堆整章术语。

每轮结束保存你关键原问题、原作答、错误原因、提示和修正过程，链接当轮用到的来源。状态区分：看过讲解、提示后会做、独立做对、延后复测通过；只有真实作答才推进。一次答对只支持该题/条件下的表现，不自动把整个单元标掌握。
