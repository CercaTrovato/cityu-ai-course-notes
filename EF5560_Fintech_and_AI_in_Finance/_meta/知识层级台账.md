## 使用规则

写 M(N) 笔记时，正文里每出现一个概念，按下表判断：

| 情况 | 怎么处理 |
|---|---|
| 在 **L0 入场基线** 里 | 直接用，不解释 |
| 在 **L1** 里且 `首现 ≤ N` | 直接用 + `[[回指]]` + **一句话唤醒** |
| 在 **L1** 里但 `首现 > N` | 只给一句话预告，标明「第 X 讲展开」，不提前展开 |

## ⭐ 本课的两条口径判断（写死，不要每次重新想）

### 判断一：**金融概念一律不在 L0，必须就地解释**

**结论**：收益率、对数收益、复权价、波动率、市值加权指数、基准、宏观面板、配对交易、多空/美元中性、alpha/beta、夏普比率、回撤、期限利差、财务报表科目、10-Q/10-K …… **全部不在 L0**。凡出现必须在当讲展开「是什么 / 为什么需要它 / 一个具体数字」。

**理由**
1. 全库核心读者假设是「只有 AI/ML 基础，其余零基础」（根 [[CLAUDE]] §1）。金融在"其余"里。
2. 官方目录写明本课 **Prerequisites: Nil**，**这是一门对金融零基础学生开放的课**。
3. 教授自己就是这么假设的：他在课上被学生问到时会顺带解释（🎙️`01:13:19`「if you don't know about this word, [let me explain]」；`01:20:47`「if you don't know what is adjusted price or stock split or dividend payment, ask the AI」）。
4. **教授把"数感"列为本课第一优先级学习目标**（🎙️`02:12:27`）。数感的前提是先懂概念本身。

**执行细则**：金融概念的解释必须**带量级**。写「波动率是收益的标准差」不合格；写「年化波动率 15% ≈ S&P 500 的常态，27% ≈ CSI 300 的常态，50% 是危机水平」才合格。

---

### 判断二：**Python 基础语法算 L0；库 API 不算 L0；不教编程**

**结论**
- ✅ **在 L0**：变量赋值、函数调用、`import`、点号取属性、字符串/列表/字典、`for`/`if`、能看懂 `a = f(b, c=1)` 是什么意思。
- ❌ **不在 L0**：`pandas`（`resample` / `pct_change` / `shift` / `rolling` / `join` / `loc`）、`yfinance`、`akshare`、`matplotlib`、R 的 `quantmod` / `TTR`。**讲义出现的每一行库调用都要说明"这行在干什么、为什么参数取这个值"**。
- 🚫 **不做的事**：不系统教 Python 语法，不写"什么是 for 循环"，不做编程练习。

**理由**
1. **教授明说不教编程、也不考编程**：🎙️`01:15:10`「**there's no coding test. Because I [didn't] teach you any coding.** Coding is not the [core] of my course at all.」；`01:16:22`「I'm not teaching you coding. We use [vibe] coding.」
2. 课堂上学生**不需要打字**：讲义 p.54「You do not need to type Python in class.」
3. 但**讲义里有 6 页整页代码**（p.17、18、29、35、36、46）。读者必须能看懂这些代码在做什么，否则整讲的"检查证据"逻辑就断了——而**看懂输出正是本课要考的能力**。
4. 与 IS6400 的口径对齐：[[材料处理规则]] §8.3 的默认是「Python 语法熟悉、但特定库 API 不熟」。本课取同一口径，两课笔记可互相引用而不冲突。

**执行细则**：代码块下面必须有一张"逐行说明"表，列出：这行做什么 ／ 关键参数为什么这么取 ／ 输出应该长什么样。**重点永远落在"时点对不对"，不在语法。**

**统计基础**
- 均值、标准差、分位数、相关系数、散点图、箱线图
- 正态分布的直觉、"厚尾"的直觉

**Python**
- 见上文「判断二」的 ✅ 清单

**一般常识**
- 公司会上市、会披露财报、股票会涨会跌

| 按日期切分 | Chronological split | M02 | 早期拟合、晚期评估；金融时间序列**绝不能随机切分** | 数据泄漏 |
| 训练 / 验证 / 测试 | Train / Validation / Test | M02 | 估计 / 挑选 / 只评一次分；看完测试集再改模型，测试集就作废了 | 按日期切分 |
| 固定 / 扩展 / 滚动窗口 | Fixed / Expanding / Rolling window | M02 | 三种回测设计；任何合法设计都保持时间序、先拟合再评估 | 按日期切分 |
| 冻结规格 | Frozen design | M02 | 变量名、训练 μ/σ、系数、测试日期与行序，四样全部锁死 | 训练/验证/测试 |
| 均方误差 | MSE | M02 | `(1/T)Σ(r−r̂)²` | L0 |
| **样本外 R²** | Out-of-sample R² | M02 | `1 − Σ(r−r̂)²/Σ(r−r̂ᵇ)²`；**没有脱离基准的含义** | MSE |
| 滞后 MA(12) 基准 | Lagged MA(12) benchmark | M02 | 过去 12 个月收益的均值，本身无泄漏；数据集 `benchmark_ma12` 列就是它 | 基准 |
| 命中率 | Hit rate | M02 | 预测与实现符号一致的比例 | L0 |
| **基准命中率** | Positive-return base rate | M02 | 正收益月的占比；方向精度必须打败它，**不是 50%** | 命中率 |
| 中性预测（个股） | Zero active-return benchmark | M02 | 个股主动收益的基准预测取 0，即"与所在市场持平" | 主动收益 |
| 六条评价标准 | Six evaluation criteria | M02 | 样本内关联 / 预测误差 / 相对精度 / 方向 / 稳定性 / 经济价值 | 样本外 R² |
| 有效市场假说 | Efficient Market Hypothesis | M02 🎙️ | 公开信息秒级被消化，模式消失；长期平均成立，逐月不成立 | 收益可预测性 |
| F 检验 | F-test (joint significance) | M02 🎙️ | 检验全部斜率同时为零；F 显著而 t 全不显著 = 共线性症状 | 多元回归、多重共线性 |
| 数据挖掘偏差 / 发表后偏差 | Data mining / post-publication bias | M02 🎙️ | 试到显著为止；被发表后被交易掉——Welch & Goyal 结论的两个解释 | 样本外 R² |
| 历史均值基准 | Historical average | M02 🎙️ | 所有斜率为零时的预测 = 样本均值；很难被打败（Campbell & Thompson） | 滞后 MA(12) 基准 |
| 残差分析 | Residual analysis | M02 | 残差是数据不是废料；金融残差在压力期成簇出现 | 拟合线 |

### H. 线性机器学习：收缩、降维与排序（M03 引入）

| 概念 | English | 首现 | 一句话定义 | 依赖 |
|---|---|---|---|---|
| 超额收益 | Excess return | M03 📄🎙️ | 总收益减去同期无风险收益 `r^e = r − r_f`；两个任务的预测目标都是它 | 收益率 |
| 无风险收益代理 | Risk-free proxy | M03 📄🎙️ | 美国 / 香港用美国 3 个月国债收益率，内地用中债 3 个月，用上月末值折算到持有期 | 超额收益 |
| 惩罚项 · 收缩 | Penalty · Shrinkage | M03 📄🎙️ | 在 OLS 损失后加 λ·P(β)，把斜率往零压；截距不罚；预测式不变 | 拟合线、训练集标准化 |
| 超参数 | Hyperparameter | M03 | λ、ρ、K 这类不由拟合估计、只能在验证集上选的设定 | 训练 / 验证 / 测试 |
| 前向选择 | Forward selection | M03 📄🎙️ | 逐个加变量，验证 MSE 不再下降就停；会漏掉"合起来才有用"的变量 | 多元回归 |
| 岭回归 | Ridge regression | M03 📄🎙️ | 平方惩罚 λ/2·Σβ²：压小不归零，稳定相关变量的斜率 | 惩罚项、多重共线性 |
| LASSO · 软阈值 | LASSO · Soft-thresholding | M03 📄🎙️ | 绝对值惩罚 λ·Σ\|β\|：零点有角，斜率可恰好归零 = 选变量；相关变量之间选谁不稳 | 惩罚项 |
| 弹性网 | Elastic Net | M03 📄🎙️ | 两种惩罚按 ρ 混合：能归零且同族相关信号一起保留；λ 与 ρ 都在验证集选 | 岭回归、LASSO |
| 软件惩罚参数 | Software alpha | M03 | scikit-learn 的 alpha = n·λ；不同实现尺度不同，报告时写明 | 惩罚项 |
| 系数路径 · 验证曲线 | Coefficient path · Validation curve | M03 📄🎙️ | 斜率随 λ 的走势；验证 MSE 随 λ 的 U 形，最低点 = 选定 λ；课上口头确认归零顺序：联邦基金利率最先、通胀最后（最重要） | 超参数 |
| 股-周面板 | Stock-week panel | M03 📄🎙️ | 一行 = 一只股票在一个预测周；恒指 80 只 × 156 周 = 12,480 格、12,281 行可用 | 数据表 |
| 固定股票池 | Fixed universe | M03 📄🎙️ | 2023-07 定名单后不再更换；缺失保持缺失——防生存者偏差（M01 §2.8 的冻结样本池） | 生存者偏差 |
| 技术指标六族 | Six indicator families | M03 📄🎙️ | 趋势 / K 线几何 / 活跃度 / 波动 / 振荡器 / 市场风险；30 列只问六个问题 | 预测变量 |
| 截面排名 · 中心化排名 | Cross-sectional / Centered rank | M03 📄🎙️ | 同一周在股票池内的百分位减 0.5，取值 −0.5～+0.5；统一单位、压极端值、只用 t−1 周数据（教授当堂口述"减 0.5" `01:38:49`） | 技术指标六族、预测时钟 |
| 特征分组组合 | Characteristic-sorted portfolio | M03 📄🎙️ | 每周按一个滞后特征把股票等分五组、等权持有，看各组下周超额收益 | 截面排名 |
| 降维 | Dimension reduction | M03 📄🎙️ | 把 30 个相关列换成 K 个方向再回归；本课数据 3 个方向 = 61% 方差 | 多重共线性 |
| 主成分回归 · 载荷 | PCR · Loading | M03 📄🎙️ | 先取训练输入方差最大的 K 个正交方向（载荷 = 各列权重），再 OLS；只看 Z；课上口头解读第一成分正载荷在趋势/振荡器类、负载荷在波动/风险类 | 降维 |
| 偏最小二乘 | PLS | M03 📄🎙️ | 方向按与训练收益的协方差平方最大来选；同时用 Z 与 r^e；预测仍线性 | 降维 |
| 常数预测 | Constant forecast | M03 📄🎙️ | 全部斜率为零、每只股票同一预测；MSE 上不吃亏但无法排序；教授明说这是 ML 作业最容易踩的坑 | LASSO |
| 预测分组排序 · 高减低价差 | Forecast sort · H−L spread | M03 📄🎙️ | 每周按预测分五组、比较 Q5 与 Q1 的实现超额收益；本课 Ridge +0.48%/周，t = 1.46 | 特征分组组合 |

| 阈值 · 交互 | Threshold · Interaction | M03（预告） | 斜率随其他变量变化——线性模型做不到，Class 4 的问题；转录缺结尾，课堂没有展开 | — |
| 主动收益 | Active return | M03 🎙️ | 个股收益减去大盘收益（不是减无风险收益）；教授口头提及的姊妹概念，本讲正文不用它，只用超额收益 | 超额收益 |
