# EF5560 可读性细则

本文件只补充 EF5560 的学科要求。句子、段落、版面、表格尺寸、分层和三种阅读场景，全部按 [[可读性总规则]] 执行。两者冲突时以总规则为准；原件或正式题面需保留特殊格式时，旁边另给可读解释。

本课读者懂机器学习，但金融零基础。最常卡住的不是模型，而是四件事：

- 收益的单位和时点；
- 多空头寸怎么记账；
- 统计量（$t$、标准误、$R^2$）怎么读；
- 验证期和测试期的结果为什么不能混着用。

下面的规则都围绕这四件事。

## 1. 本课默认版式（补充总规则 §3）

| 内容类型 | 默认版式 |
|---|---|
| 一个实验或回测的设定 | 设定卡：先放一张两列表“项目 / 本节取值”，再讲结果（见 §2） |

| 多个符号的金融公式 | 符号表必须有“单位”和“何时已知”两列（见 §4） |

## 2. 实验设定与结果分开

### 2.1 规则

每个出现收益数字的小节，先给设定卡，再给结果。设定卡固定为下面这些行，不适用的写“不适用”：

| 项目 | 本节取值 |
|---|---|
| 样本与频率 | 例：恒生成分股，52 周，2025-07-04 至 2026-06-26 |
| 收益口径 | 例：简单周收益，小数；超额 = 减同期无风险收益 |
| 信号何时已知 | 例：周初已知，用来预测本周收益 |
| 基准与暴露 | 例：买高组 100 万元、空低组 100 万元，总暴露 2 |
| 成本 | 例：未扣交易与借券成本 |

结果段落里不再重复这些设定。只在设定改变时写一句：“这里改为……”。

### 2.2 示例

❌ 不合格（M05 §2.10 一段同时讲金额、做空、总暴露、净暴露、计算基准和融资条件，共 6 件事）：

> 用金额解释这条规则：以 100 万元作为计算收益的基准，买入高组股票合计 100 万元，同时做空低组股票合计 100 万元。做空是先借到股票卖出……两边头寸绝对金额合计 200 万元，除以 100 万元基准，总暴露为 $2$；保留买入为正、做空为负，金额相减为零，净暴露为 $0$。所以多头暴露是 $1$，空头暴露是 $-1$。这里的基准是收益记账的分母……

✅ 合格：设定卡给出“买 100 万、空 100 万、总暴露 2、未扣成本”；正文只按总规则 §9.3 的写法，分两段分别解释总暴露和净暴露。融资和借券条件放进「适用边界」列表。

## 3. 统计量的固定读法

### 3.1 规则

一个统计量在本篇第一次出现时，用四行列表解释，每行 ≤ 80 单元：

1. **问什么**：这个数在回答什么问题。
2. **怎么算**：公式，或一句话加公式链接。
3. **代入一行**：用本表一行的数字算一遍。
4. **怎么判断，限制是什么**：阈值、阈值成立的条件、常见误读。

推导较长时（如自由度、Newey–West 的滞后），在列表后用 `####` 子节分步讲；支撑本节操作的核心推导不能藏到核验日志。

同一统计量在本篇后面再出现，写一句唤醒并回链第一次的位置。

### 3.2 符号冲突

- 时间下标写“第 $t$ 周 / 第 $t$ 月”。
- 统计量一律写 $t_{\mathrm{stat}}$ 或“$t$ 统计量”，不单写 $t$。
- 表头里的 $t$ 列，表后第一句说明“这里的 $t$ 是 $t$ 统计量”。

### 3.3 百分比与百分点

- 一个水平值写 %：“平均周收益 0.32%”。
- 两个百分比相减的差写“百分点”：“高组比低组多赚 0.32 个百分点”。
- bp 第一次出现写“10 bp（基点，即 0.10%）”。

### 3.4 示例

❌ 不合格（M05 §2.34.1，一段 254 单元，读一行表要读者同时消化 6 个指标）：

> 把汇丰一行读成完整中文：2026 年 8 月 31 日，汇丰在恒生指数中占 8.91%；这是当日指数构成。另看 2023 年 7 月至 2026 年 6 月这批周收益，它的总收益平均按年表示为 39.0%……该截距约为 Newey–West(4) 标准误的 3.61 倍……恒生直线则解释了约 29.0% 的周超额收益变化……

✅ 合格：一句引导，再一列一项。

> 读汇丰这一行：
>
> - 指数权重 8.91%：2026-08-31 当天，汇丰占恒生指数的 8.91%。
> - 年化平均收益 39.0%：样本期内周收益的平均，换算成一年。不代表每年都赚这么多。
> - Beta 0.53：恒生超额收益变化 1 个百分点，汇丰通常变化 0.53 个百分点。
> - 年化 Alpha 32.4%：扣掉跟随市场的部分后，剩下的平均周收益，换算成一年。
> - $t_{\mathrm{stat}}=3.61$：Alpha 是其 Newey–West(4) 标准误的 3.61 倍。
> - $R^2=29.0\%$：恒生的涨跌解释了汇丰周超额收益变化的约 29%。

## 4. 金融公式的符号表

金融公式的符号表固定五列：

| 符号 | 是什么 | 单位 | 何时已知 | 本例取值 |
|---|---|---|---|---|
| $r_{i,t}$ | 股票 $i$ 在第 $t$ 周的简单收益 | 周收益（小数） | 第 $t$ 周结束后 | 0.02 |
| $\hat r_{i,t}$ | 模型对它的预测 | 周收益（小数） | 第 $t$ 周开始前 | 0.004 |

“何时已知”这一列专门防止前视偏差：读者一眼能看出哪个量在交易时还不知道。

## 5. 模型对比表

### 5.1 规则

1. 行是模型，最多 8 行。列是指标，最多 5 列，加一列“模型”。
2. 验证期和测试期分成两张表，或加“阶段”列。不能把两期数字放在同一行的相邻列里而不标阶段。
3. 验证期选中的模型用 ✓ 标出，表后一句说明 ✓ 的含义。
4. 表后“读法”必须回答两件事：
   - 差距有多大、是否评估了不确定性。没有做相应检验时，只能报告样本差值，不能凭肉眼称有或无统计差异。
   - 测试期最好的模型是不是验证期选中的模型。不是的话，写一句冻结原则。
5. 同一列的小数位数一致。价差、Alpha 带正负号，负号用“−”。

### 5.2 示例

M04 §2.6.4 / §2.6.5 把验证期表和测试期表分开，是正确做法，整改时保留。

❌ 不合格（M04 §4.2 速查表的一个单元格，把 3 个市场 × 3 个模型共 9 个结果塞进一格，还用了“森”“升”这样的自造缩写）：

> \| p.36 / 38 \| 市场三族 OOS $R^2$ \| 美：树 −2.6 / 森 −6.8 / 升 **+6.3**；港：树 **+4.7** / 森 +2.6 / 升 −3.6；内地：树 −176.3 / 森 **−36.4** / 升 −60.0；线性：LASSO −16.3 / EN +8.4 / LASSO −0.6 \|

✅ 合格：矩阵数据就用矩阵表，模型名写全称。

> 测试期 OOS $R^2$（%，相对 MA(12) 基准）：
>
> | 模型 | 美国 | 香港 | 内地 |
> |---|---:|---:|---:|
> | 决策树 | −2.6 | +4.7 | −176.3 |
> | 随机森林 | −6.8 | +2.6 | −36.4 |
> | 梯度提升 | +6.3 | −3.6 | −60.0 |
>
> 读第一行：决策树在美国比 MA(12) 基准差 2.6%，在香港好 4.7%，在内地差得多。

缩写规则：模型名在表格里写全称或标准英文缩写（OLS、PCR）。不得自造单字缩写。

## 6. 机器学习手算例

### 6.1 规则

1. 小数据集放表，不写成 `x=[0,1,2,3]` 这样的行内数组。
2. 每个节点、每一轮、每一次抽样，各占一个编号步骤。
3. 每一步只写：这一步用哪些行 → 试了什么 → 结果数字 → 选了什么。
4. 随机步骤（bootstrap、候选变量抽样）写明“本例指定的抽样结果”，并说明真实运行会随种子变化。
5. 最后一步写“新样本怎么走到叶子、输出多少”。

### 6.2 示例

❌ 不合格（M04 §2.3.1，一段 225 单元写完两次 bootstrap、两棵树和预测）：

> 四行训练 ID0/1/2/3，x=[0,1,2,3]、y=[0,0,2,4]。指定本次有放回索引 A=[0,0,2,3]、B=[0,1,1,3]……A候选中点1/2.5的SSE为2/2.666667，选1，左均值0、右3……

✅ 合格：

> 训练数据有 4 行：
>
> | 行号 | $x$ | $y$ |
> |---:|---:|---:|
> | 0 | 0 | 0 |
> | 1 | 1 | 0 |
> | 2 | 2 | 2 |
> | 3 | 3 | 4 |
>
> 1. 抽第一份样本 A：本例指定抽到行 0、0、2、3。行 0 出现两次，行 1 没被抽到。
> 2. 用样本 A 长树：门槛 1 的误差平方和是 2，门槛 2.5 是 2.67。选门槛 1。左叶平均 0，右叶平均 3。
> 3. ……

## 7. 本课高风险术语（脚本读取）

下表的词在独立学习单元首次实际使用时，用动作或例子展开；前文讲过则一句唤醒并回链。先解释后命名、紧邻段说明都可以，不强制重复词表。R6d 只提示未识别到解释线索。第一列的“/”用于同义匹配；语义不同的指标分行，实际含义以本表和数据来源为准。

| 术语 | 第一次在本节出现时，至少要讲成这样的人话 |
|---|---|
| 冻结 / 冻结模型 / 冻结测试 / 冻结的 | 测试开始前就定好，测试期间不再改动 |
| 五分位 / 五分位组 / 五分位分组 | 按预测从低到高排队，平均切成五组，每组约五分之一 |
| 高组 / 低组 / 最高组 / 最低组 | 预测最高的那一组 / 预测最低的那一组 |
| 价差 / 高减低价差 / 周价差 | 高组这周的平均收益减去低组这周的平均收益 |
| 暴露 / 敞口 / 单位暴露 / 每侧单位暴露 | 用金额说清：买入多少、做空多少，相对于多少计算基准 |
| 总暴露 / 毛敞口 | 买入金额加做空金额（都按正数算），再除以计算基准 |
| 净暴露 / 净敞口 | 买入金额减做空金额，再除以计算基准 |
| 做空 / 空头 | 先借股票卖出，以后买回来还；股价跌就赚，涨就亏 |
| 多头 | 买入并持有；股价涨就赚 |
| 多空 / 多空组合 | 同时买入一组股票、做空另一组股票 |
| 金额中性 / 美元中性 | 买入金额和做空金额相等，相减为零 |
| hit rate / 命中率 | 必须按本表定义；方向预测正确率与正价差周比例不同 |
| 正收益周比例 | 价差为正的周数除以全部周数，无量纲 |
| 截面 / 横截面 | 同一时间点上，把所有股票放在一起比较 |
| 超额收益 | 收益减去同期持有现金能拿到的收益 |
| 样本外 / OOS | 用拟合该模型时未用的数据评估；另标验证还是最终测试 |
| t 统计量 | 估计值与待检验值的差，除以该估计值的标准误 |
| 标准误 | 按抽样模型衡量估计值的波动；具体估计对象须说明 |
| 显著 / 统计显著 | 在声明的检验假设和阈值下拒绝原假设，须写条件 |
| 常数预测 | 给所有股票同一个预测值，所以排不出谁高谁低 |
| 等权 | 组内每只股票分到相同的钱 |
| 年化 | 把一周或一个月的数换算成一年的口径 |
| 基点 / bp | 0.01 个百分点 |
| 回撤 | 当前账户金额相对此前最高点下降的比例 |
| 最大回撤 | 所考察期间最深的一次回撤 |
| 换手 / 换手率 | 一段时间里买卖的金额占账户金额的比例 |
| 夏普比率 | 平均超额收益除以其波动，频率与年化方式须一致 |

## 8. 本课逐块自查补充（加在总规则 §12 之后）

- 每个收益数字：单位、频率、是否超额、是否扣成本，能在设定卡里找到吗？
- 每个差值：写的是“百分点”吗？
- 每个 $t$：分得清是时间下标还是统计量吗？
- 每个模型比较：分得清验证期和测试期吗？
- 每个手算例：数据在表里吗？每步只有一个动作吗？
