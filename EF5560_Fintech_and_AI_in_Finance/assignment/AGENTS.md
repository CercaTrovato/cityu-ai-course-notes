# 作业进度管理入口

本目录的实际作业进度统一记录在各 `graded/Axx-*/assignment.json`。开始作业制作、核查或整理进度时，先读取目标元数据、根级 `_meta/assignment-board/README.md` 和[统一推进与收尾流程](../../_meta/assignment-board/SUPERVISION.md)。

完成本次工作后，将已核实的成果、负责人、阻塞、下一步、来源和核实日期准确写回元数据。通过 `_meta/assignment-board/update.py` 检查旧 SHA-256、验证候选、保存历史并原子写入；并发冲突先合并，不能覆盖别的会话成果。看板每 5 秒读取这些文件。

未知不等于未开始；工作稿存在不等于已提交；准备方案不等于团队已确认。任务、交付节点、本人提交状态分别维护。只有真实新证据才能升级状态，不因为本次重新查看旧记录而刷新制作进度日期。

**每批实质推进完成后的必做闭环（2026-11-11）：核验本批成果 → 按已确认范围提交并推送对应 GitHub、核实远端 → 回传总监督 → 更新并回读本地看板 → 发布线上并回读 → 给本人可直接发群的汇报稿，网址显式写全。** 具体时序、发布范围、失败与维护处理只在上述统一流程维护，不在各课另立版本。GitHub、本地看板、线上看板分别列本批核验证据，任一处未完成不得笼统称“已同步”。晚到补件也按新批次更新 GitHub 进度。群消息由本人发送；失败如实标待完成。

根级 AGENTS.md、课程作业制作规范、文件安全协议及原始材料只读要求继续适用。Git 日常收尾按本人 2026-11-10 的统一要求执行；本入口不改变邮件、正式作业提交、协作者邀请和教学独审的其他授权边界。
