### M06 · ACCESS 数据库构建与查询

| 复合主键（连接主键） | Concatenated / Composite Primary Key | **M04**（W6 重讲） | 📄 | 由两个及以上字段合起来构成的主键；在连接表里由两个类的主键"过账（posting）"而来 | 主键 | ⚠️ 讲义用了 `posting`（过账）这个会计词 |
| 连接表（关联表） | Association / Junction Table | **M04**（W6 重讲） | 📄 | 多对多关联落地时新建的那张表；**关联属性成为它的普通字段** | 复合主键 | ⭐ 兑现了 M05 的预告 |

| 查询 | Querying | M06 | 📄 | *"asking questions about the data in the database and manipulating or combining the data in different ways"*。输入是表、输出也是表 | 关系数据库 | |
| 关系代数 | Relational Algebra | M06 | 📄 | 三个算子（Select/Project/Join）构成的概念体系；*"provides the **conceptual basis** for SQL and QBE"* | 查询 | |
| 选择（关系代数） | Select | M06 | 📄 | *"includes only certain **rows**"* —— 横着切。⚠️ **对应 SQL 的 `WHERE`，不是 `SELECT`** | 关系代数 | |
| 投影 | Project | M06 | 📄 | *"includes only certain **columns**"* —— 竖着切。⚠️ **对应 SQL 的 `SELECT`** | 关系代数 | |
| 连接 | Join | M06 | 📄 | *"combines **two or more** database tables on the basis of one or more **common attributes**"* | 关系代数 | |
| 内连接 | Inner Join | M06 | 📄 | *"includes **only the records from both tables that have the exact same values** in the fields that are joined"* | 连接 | |
| 外连接 | Outer Join | M06 | 📄 | *"includes **all records from one table**, and matches those records from the other table for which values in the joined fields are equal"* | 连接 | ⭐ **回答"什么没发生"的唯一手段** |
| 左外连接 / 右外连接 | Left / Right Outer Join | M06 | 📄 | 全保留的是左表还是右表。`A LEFT JOIN B` ≡ `B RIGHT JOIN A` | 外连接 | |
| 笛卡尔积 | Cartesian Product | M06 | 💡 | 漏写连接条件时的结果：A 的每一行配 B 的每一行。**语法合法、不报错、结果全错** | 连接 | 💡 讲义完全没警告 |
| 结构化查询语言 | SQL | M06 | 📄 | 三段式骨架：`SELECT 列 / FROM 表 / WHERE 条件;`。`WHERE` 在单表取全部行时可省 | 查询 | ⚠️ 讲义的 SQL 例句有 5 处语法错误 |

| 通配符 | Wild card (`*`) | M06 | 📄 | *"`*` is a wild card indicating **all columns** should be included"* | SQL | |
| 数学比较运算符 | Comparison Operators | M06 | 📄 | `= < <= > >= <>`。⚠️ **日期和文本也能比大小**：日期早 = 小；文本按字典序 `A<B<C` | SQL | |
| 逻辑运算符 | Logical Operators | M06 | 📄 | `AND` = 集合**交集**（结果变少）；`OR` = 集合**并集**（结果变多）；`NOT` = 取反 | SQL | ⚠️ 中文的"和"常对应 SQL 的 OR |
| 范围运算符 | BETWEEN | M06 | 📄 | *"used to define the range limits"*；⚠️ ***"the end points of the range are included"*** —— **两端都含** | SQL | |
| 空值 | Null | **M04**（W6 重讲） | 📄 | "这里没有值"。**不是 0，不是空字符串**。⚠️ `Null = Null` 结果是 Null，所以 `WHERE x = NULL` 永远查不出东西 | 字段属性 | ⭐ 本讲最容易考的细节 |
| 空值判定 | IS NULL | M06 | 📄 | 取"空的那些"。Access QBE 里写 `Is Null` | 空值 | |
| 非空判定 | IS NOT NULL | M06 | 📄💡 | 取"非空的那些"，⚠️ **余额为 0 算非空**。讲义写的 `EXISTS` 在 Access 里跑不通 | 空值 | 💡 正确写法由笔记补充 |
| 聚合函数 | Aggregation Function | M06 | 📄 | *"summarizes the data values **within a field (column)**"* —— **竖着算** | 查询 | |
| COUNT / AVERAGE / SUM / MIN / MAX | 同左 | M06 | 📄 | 五个聚合函数。⚠️ 💡 **除 `COUNT(*)` 外全部忽略 Null**，因此 `AVG` 的分母只算非空行 | 聚合函数 | 💡 Null 行为由笔记补充 |
| 横向计算 | Horizontal Calculation | M06 | 📄 | *"mathematically **combine values from different fields for each row**"* —— **横着算**，结果行数不变 | 查询 | ⚠️ 讲义只给定义、零例子 |
| 查询网格 | Query Grid | M06 | 📄 | QBE 的下半屏：Field / Table / Sort / Show / Criteria / or（点 Σ 后多一行 Total） | QBE | |
| AND/OR 在 QBE 里的摆放 | — | M06 | 📄 | ⭐ ***"same line"* = AND；*"separate lines"* = OR** | 查询网格, 逻辑运算符 | ⭐ 讲义用红箭头批注专门强调 |
| 汇总行 | Total row | M06 | 📄 | 点求和符号 Σ 后出现；*"defaults to '**Group By**' for each field"* | 查询网格, 聚合函数 | |
| 分组 | Group By | M06 | 📄 | 按该列的值分组，每组输出一行 | 汇总行 | ⚠️ 讲义没教对应的 SQL `GROUP BY` 关键字 |
| Where（Total 行选项） | Where | M06 | 📄 | 该列**只用于筛选**，不进结果也不参与分组；Show 必须取消勾选 | 汇总行 | 💡 相当于 SQL 的 `WHERE` vs `HAVING` 之分 |
| 空值转零函数 | `Nz()` | M06 | 📄 | Access 专用；把 Null 转成 0（或指定替代值）。标准 SQL 用 `COALESCE(x,0)` | 空值 | ⭐ 不用它则整个算式变 Null |
| 反连接 | Anti-join | M06 | 💡 | **外连接 + 在右表字段上加 `Is Null`** —— "找出什么都没发生的那些实体"的标准套路 | 外连接, IS NULL | 💡 术语由笔记补充；讲义 p.91 用了这个做法但没给名字 |
| 行项目金额 | Line Item Extension | M06 | 📄 | 一行明细的金额 = 数量 × 实际单价（`ExtSaleAmt` / `LineItemExtension`） | 横向计算 | |
| 加权平均单位成本 | Weighted Average Unit Cost | M06 | 📄 | *"Divide total line item extensions by total purchase quantities for each item"*。⚠️ **必须先聚合再相除**，顺序决定了"加权"。⚠️ 讲义标题注明 ***"not for Financial Statement use"*** | 行项目金额, 聚合函数 | ⭐ 会计口径限制见 M06 §2.24.4 |
| 汇款通知 | Remittance Advice | M06 | 💡 | 客户随款附上的单据，说明这笔钱付的是哪几张发票；是 CashReceipt 表的主键 | 现金收款 | 💡 讲义未解释 |
| 佣金率 | Commission Rate | M06 | 💡 | 销售员按销售额提成的比例（`.12` = 12%） | 销售员 | 💡 讲义未解释 |
| 资产负债表日 | Balance Sheet Date | M06 | 📄 | 资产负债表所报告的那一个时点；查询名里的 `ThroughBSDate` / `OnBalanceSheetDate` | 会计分期假设 | 💡 与审计的截止性测试相通 |
| 订单履行天数 | Days to Fill (Sale Order) | M06 | 📄 | 从销售订单日期到实际发货日期的间隔天数。⚠️ **只有 REA 数据库算得出**（传统总账不记订单） | 销售订单, 销售事件 | ⭐ 证明 REA 价值的最强例子 |
