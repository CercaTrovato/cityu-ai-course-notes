## 每单元要学什么、做到什么

下面的页码均为 PDF 物理页；Notebook cell 从1计数。源文件的稳定 id、完整路径、哈希及读取范围在 [sources.json](sources.json)。每一单元未来仍按“认题 → 必要知识 → 一个例子 → 你尝试 → 提示/纠错 → 改条件再做”推进。

### U00 · 业务问题、数据表与 Python 读题起点

学完要能：从一行一客户、一列一属性出发，分清预测对象、标签、特征与业务决策；能跟踪 import→建对象→fit→predict。

先修：无课程内先修。四则运算、百分数；必要 Python 赋值/索引现场补。

练的题型：任务识别、代码/数据形状解读。

回源位置：W1 p.13–45；T01 cells 3–23；安装页面仅按需要回查。 来源：S-W1, S-T01, S-SYL。

最容易卡住或用错的地方：看到输出会问“一个数对应谁、单位是什么”，不把能运行当作结果有效。

### U01 · 数据类型、描述统计与关联规则

学完要能：会判断属性类型，解释缺失/离群；算均值、方差、分位数/IQR，读箱线与相关；从交易表计算关联规则。

先修：U00。排序、比例、平方与简单求和；概率分母用具体样本补。

练的题型：缺失值处理、IQR/分位数、读图、支持度/置信度/lift。

回源位置：W3 p.4–49、51–72；T03 cells 2–43；Sample Q1(1)(2)。 来源：S-DATA, S-T03, S-SAMPLE。

最容易卡住或用错的地方：Q1 all customers 的总体不能被另一问的删行偷偷改变；相关不证明因果，confidence 不等于 lift。

### U02 · 回归、拟合与正则化初步

学完要能：能把业务问题写成回归，解释系数/dummy，计算预测和误差；理解最小二乘、梯度下降以及正则化改变什么。

先修：U00, U01。代数直线、平方误差；导数/矩阵只在真正用到时逐步搭桥。

练的题型：系数/显著性解读、预测与残差、梯度更新、Ridge/Lasso 比较、代码填空。

回源位置：L2 p.2–53；T02 cells 3–36；S32 01:26:17–01:26:33。 来源：S-REG, S-T02, S-S32。

最容易卡住或用错的地方：拟合训练数据与预测未来不同；标准化/正则化不能从测试集学参数。

### U03 · 特征选择、纯度与 PCA

学完要能：会算分裂前后加权不纯度，解释前向选择/RFE；区分保留原变量与生成主成分，读解释方差和变换。

先修：U01, U02。加权平均、概率、对数；向量投影用二维例补。

练的题型：Gini/entropy/information gain、filter/wrapper/搜索、PCA 读图与解释、代码输出对照。

回源位置：W4 p.16–69；L5 p.2–8回顾；T04 cells 2–37。 来源：S-FEAT, S-T04, S-CLUST, S-S32。

最容易卡住或用错的地方：纯度指标、搜索策略和预测模型各管不同环节；PCA 大方差不是必然最有预测力。

### U04 · 聚类及距离：K-means、层次与 DBSCAN

学完要能：会做 K-means 分配/更新、解释 K-means++/bisecting；能按 linkage 合并距离矩阵，辨认 DBSCAN 核心/边界/噪声；理解谱聚类的教程用途。

先修：U01, U03。坐标距离、平均、标准化；矩阵按距离表来读。

练的题型：迭代手算、距离矩阵合并、方法选择、参数/输出解释。

回源位置：L5 p.9–67，尤其 p.23–40、42–60、62–67；T05 cells 4–34。 来源：S-CLUST, S-T05, S-S32。

最容易卡住或用错的地方：分组没有现成真标签；缩放和簇形状影响结果，簇编号无大小意义。

### U05 · 决策树、集成与 SVM

学完要能：能沿树逐例分类，区分树深度与软件 max_depth；解释 bootstrap/随机特征、加权改错、元模型与支持向量。

先修：U01, U03。U03 不纯度；分类标签和训练数据；加权投票。

练的题型：沿树预测、Hunt/分裂手算、bagging/boosting/stacking 比较、SVM 边界、模型导入与参数。

回源位置：L6 p.3–74；T07 cells 3–16；Sample Problem3(4)。 来源：S-CLASS, S-T07, S-SAMPLE, S-S32。

最容易卡住或用错的地方：不能用验证集真值改叶标签后再报同集成绩；API 参数必须连接模型行为。

### U06 · 分类/回归评价与不平衡成本

学完要能：能固定正类与分母，算评价指标并解释错判成本；选择符合业务目标的阈值/指标。

先修：U02, U05。比例和平方平均；每次先标实际/预测方向。

练的题型：混淆矩阵、precision/recall/F1/ROC、MAE/RMSE/MAPE、成本敏感选择。

回源位置：L6 p.75–92；Assessment p.8–15；T07 cells 16–22。 来源：S-CLASS, S-ASSESS, S-T07。

最容易卡住或用错的地方：极少数欺诈时 accuracy 可误导；MAPE 在真值为0或很小时有问题。

### U07 · 时间序列：模式、平滑与趋势季节

学完要能：能辨别水平/趋势/季节/周期，按已知状态预测，选择平滑模型并解释窗口、权重及季节周期。

先修：U01, U02。时间顺序、加权平均；递推用同一小例跟踪状态。

练的题型：图形识别、移动平均/SES/Holt/Holt-Winters、一步更新、加法/乘法季节、代码读值。

回源位置：L8 p.7–45，重点 p.20–37；T08 cells 4–48；S32 01:29:36–01:29:48、01:32:03。 来源：S-TS1, S-T08, S-S32。

最容易卡住或用错的地方：统计 MA 模型与平滑 moving average 区分；未来真实值不可提前放入多步预测。

### U08 · 平稳化、AR/MA/ARIMA 与恢复预测

学完要能：能解释历史值/误差项、差分含义，依据原/差分序列看图选阶，再把预测恢复到原量纲。

先修：U02, U07。滞后、差分、残差；必要相关系数与统计检验解释。

练的题型：差分/平稳性、ACF/PACF 判读、ARIMA(p,d,q)、多步预测恢复、滚动预测设计。

回源位置：L9 p.14–46；T09 cells 4–81；Sample Q5(1)(2)(3)。 来源：S-TS2, S-T09, S-SAMPLE, S-S32。

最容易卡住或用错的地方：不能仅凭价格上涨保证差分后平稳；不能比较不同变换尺度 RMSE 后直接宣布胜者。

### U09 · 选模、剪枝、交叉验证与整体业务评价

学完要能：能设计不泄漏的数据切分，区分选超参与最终报告；计算树复杂度惩罚并比较剪枝；评价聚类和整体方案的业务贡献。

先修：U04, U06, U08。前三类模型与误差；超参数与拟合参数重新辨认。

练的题型：训练/验证/测试、k-fold/nested CV、剪枝与悲观误差、rolling evaluation、A/B 设计、聚类评价。

回源位置：Assessment p.16–84；T11 cells 3–61；Sample Problem3(1)–(3)、Q5(3)。 来源：S-ASSESS, S-T11, S-SAMPLE, S-S32。

最容易卡住或用错的地方：样卷每叶 penalty=1，课件例可用0.5，须按题面；A/B 随机分配与离线验证不混同。

### U10 · 全课补全：深度学习、文本与图像

学完要能：按课程完整性补 ANN 激活/训练、RNN/LSTM、文本表示/NLP、图像表示与 CNN；接回传统模型比较。

先修：U02, U03, U08。带权求和、向量/矩阵与函数；从输入形状逐步补。

练的题型：前向计算/形状、RNN/LSTM 状态、TF-IDF、图像/CNN 流程解读。

回源位置：98页版 p.1–98；137页版 p.99–137 图像/CNN补充；T10源 86 cells。 来源：S-DL98, S-DL137, S-T10, S-S32。

最容易卡住或用错的地方：S32 01:26:11、01:30:32–01:30:49 明确 Week10排除；保留全课学习，但考试主线优先完成。两个深度PDF非同一版本，不能按文件名 L11 误当模型评估。

## 建议顺序与每次怎样学

首轮诊断 → U00 → U01 → U02 → U03 → U04 → U05 → U06 → U07 → U08 → U09 → U11。U10 在考试核心线后补全，若用户希望严格全学期顺序，可在 U09 前加入；这只是学习安排选择，不改当期考试排除证据。

这不是按天硬排课。首轮回答决定哪里需要搭桥；会做的单元用一个未见变式确认后缩短讲解，卡住的单元分成较小步骤。一次围绕一个可以实际做出的动作，不连续灌输长篇笔记。每题先让你作答：首次卡住先提示读题对象，再提示方法，最后才给完整例解。未答题时只记录等待，不替你填答案或算完成。

每轮至少保留原问题、你的原作答、提示到第几步、改错理由和后续变式。仅“看过解释”与“提示后能做”“独立做对”“延迟复测通过”分别记录；聊天次数和笔记数量不当掌握率。复盘区分读题、概念、运算、API/形状、数据泄漏、业务解释及英文表达，不靠一个总分掩盖卡点。
