1.4 Percentile analysis on log_price and price¶

percentiles = [0.25, 0.50, 0.75, 0.90, 0.95, 0.99]

pd.concat([log_q, price_q], axis=1)

0.99 6.856462 950.0

Why the percentiles of price are not simply exp() of the percentiles of log_price:

Percentiles are not preserved under nonlinear transformations.
Even though price = exp(log_price) is a monotone transformation, the p-th percentile of price equals exp( p-th percentile of log_price ) only if we refer to the same rank ordering. Since both variables rank objects identically, we actually have:

$$Q_p(\text{price}) = \exp(Q_p(\text{log\_price}))$$

Check the numbers: e.g. exp(4.29) ≈ 72.9, matching the 25th percentile of price. What is not true is that mean(price) = exp(mean(log_price)), because mean is not rank-based. This is the classic gap between the arithmetic mean and the geometric mean. Similarly, skewness and kurtosis differ between log_price and price.

2.1.2 Outlier detection: IQR vs Z-score¶

In [26]:
def iqr_flag(s, k=1.5):
    q1, q3 = s.quantile(0.25), s.quantile(0.75)
    iqr = q3 - q1
    return (s < q1 - k * iqr) | (s > q3 + k * iqr)

def z_flag(s, threshold=3):
    z = (s - s.mean()) / s.std()
    return z.abs() > threshold

comparison = []
for col in ['log_price', 'accommodates', 'bathrooms']:
    comparison.append({
        'column': col,
        'IQR outliers': int(iqr_flag(air_clean[col]).sum()),
        'Z-score outliers': int(z_flag(air_clean[col]).sum())
    })
pd.DataFrame(comparison)

When to use which:

  • StandardScaler assumes roughly symmetric features and is preferred when outliers are rare. It matches the assumptions of many linear models.
  • RobustScaler is preferred when features are skewed or contain outliers. Here, bathrooms, bedrooms and beds are all skewed, so the RobustScaler keeps the transformed values in a tighter and more meaningful range.

Correlation does not imply causation. Consider accommodates and log_price. Bigger apartments do not cause higher prices by themselves. Location, amenities, host reputation, and demand are confounding variables that simultaneously increase listing capacity and price. A causal statement would require a controlled experiment (e.g., listing the same apartment with different capacity settings) or a careful quasi-experimental design.

Example of the summary paragraph¶

The dataset contains 5,000 observations across 12 attributes. Two columns (income and age) are numeric, while education and region are categorical. After auditing missing values we observed that income has 8% missingness, likely because customers with low income skip the optional field. Using median imputation we preserved the center of the distribution.
