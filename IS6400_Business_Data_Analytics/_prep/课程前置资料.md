## 3. 考核构成 —— 官方 2 项 ↔ Syllabus 6 项的对应关系

官方目录的 ATs 表**只有两行**（合计 60%），Syllabus 把它拆成六项。两者**能完全对上**：

```mermaid
flowchart LR
    subgraph 官方目录 ATs（60%）
        A1["AT1 · Class performance<br/>and assignments · 30%<br/>GenAI: Yes"]
        A2["AT2 · Group Project · 30%<br/>GenAI: Yes"]
    end
    subgraph Syllabus 明细
        S1["① Class Participation 5%"]
        S2["② Individual Assignments 25%"]
        S3["③a Project Briefing 5%"]
        S4["③b Presentation 15%"]
        S5["④ Project Report 10%"]
    end
    E["Examination 40%<br/>2 小时 · GenAI 未标注"]
    A1 --> S1
    A1 --> S2
    A2 --> S3
    A2 --> S4
    A2 --> S5
```

**验算**：5 + 25 = 30 = AT1 ✅；5 + 15 + 10 = 30 = AT2 ✅；60 + 40 = 100 ✅。

> 💡 **这个对应关系有实际用途**：官方把 GenAI 许可挂在 **AT1 和 AT2** 上，而 AT1 = 参与 + 个人作业、AT2 = 整个小组项目。因此**八次个人作业和小组项目的全部环节，官方口径都允许使用 GenAI**。这和 Syllabus ILO 第 3 条（"Manage GenAI tools for BDA proposal and Python programming"）以及 tutorial notebook 里的 `🤖 AI Prompt` 单元格完全自洽。

### 3.1 Syllabus 明写的评分细则

| 项 | 细则（Syllabus 原文要点） |
|---|---|
| **Class Participation 5%** | "In several classes that are **chosen randomly**, an **in-class quiz (and signup sheet)** will be conducted during the class. The **portion of times that you conduct quiz correctly** (and in class) will be used to assess your participation grade." |
| **Individual Assignments 25%** | "There are **about eight assignments**… Assignments are highly related to the lectures and the tutorials conducted in class. **Late submission will result in 20% deduction per day delay.**" |

> ❗ **迟交惩罚是本 vault 五门课里最重的**：个人作业每天 −20%（5 天归零），小组报告每天 −10%。
> ❗ **Participation 靠随机抽查的堂上小测**：不知道哪节课抽，缺一次就少一次分母外的机会。W1 讲义 p.9 还写着"Regular attendance is **compulsory**"。
> ❗ **8 次作业 ÷ 25% ≈ 每次 3.1%**，单次分量不大，但**累计等于 exam 的六成**。

## 4. 学习目标：三套 ILO 的差异（重要）

### 4.1 官方 CILO（4 条，带权重）

| # | 原文 | 权重 |
|---|---|---|
| 1 | Describe the target and requirements for a spectrum of business data analysis problems in finance, marketing, etc. | **25%** |
| 2 | Employ **scripting and database tools** to retrieve data and use **spreadsheet** and Python to discover patterns in data to address the selected problems. | **35%** |
| 3 | **Creatively apply and adapt** the introduced modelling techniques to propose **original findings** for practical organizational data analysis problems. | **30%** |
| 4 | **Creatively communicate** analytical procedure and results effectively in **presentations with oral, written and electronic formats**. | **10%** |

### 4.2 Syllabus ILO（5 条，无权重）

1. understand the target and requirements of a selection of critical business data analysis problems
2. manage the statistical techniques and machine learning models for data analytics
3. **Manage GenAI tools for BDA proposal and Python programming** ← 官方目录**完全没有**
4. implement the models into a software packages, such as Python, and adapt the models through programming capabilities
5. analyze and interpret the outputs of models to support decision making in finance, marketing, accounting, etc.

### 4.3 三处必须留意的差异

**① GenAI 只在 Syllabus 里，不在官方 CILO 里**
Syllabus ILO 3 把"用 GenAI 写代码"写成正式学习目标，官方 CILO 四条里一个字都没提。原因很可能是官方目录还是 2025/26 版。
→ **实践含义**：GenAI 是**本学期新增**的教学重点（W11 还有 "Competition: GenAI for BDA"），但它在官方权重表上没有位置。**考试是否直接考"怎么向 AI 提问"，无法从官方文件判断**。

**② "沟通与演示"只在官方 CILO 里，Syllabus ILO 没有**
官方 CILO 4（10% 权重）明确要求 oral / written / electronic 三种形式的呈现能力。Syllabus 的五条 ILO 全是技术能力，没有一条讲表达。
→ **实践含义**：小组项目的 **Presentation 占 15%**（比 Report 的 10% 还高），这条 CILO 就是它的官方依据。**别把演示当附属品。**

**③ 官方 Keyword Syllabus 与实际 13 周计划对不上**

| 官方 Keyword Syllabus 主题 | 13 周计划里有吗 |
|---|---|
| Business intelligence · Python for BDA | ✅ W1 |
| Feature Engineering | ✅ W3 |
| Regression | ✅ W2 |
| Time Series Modelling | ✅ W7–W8 |
| **Association Analysis** | ❌ **没有** |

| **scripting and database tools（SQL）· spreadsheet（Excel）** | ❌ **没有**（推荐读物里还有一本 *Data Analysis Using SQL and Excel*） |
| — | 13 周计划里有、官方没有：**Clustering (KMeans/DBSCAN)、Decision Trees / Ensemble、Image Mining、GenAI 竞赛** |

→ **实践含义**：官方主题表是"这门课**可以**涵盖的范围"，教授每年从中取舍。**复习以 13 周计划为准**，但如果考卷上冒出 association rules 或 text mining 的概念题，它在官方口径上是合法的。⚪ 这是我的推断，非教授明示。

## 5. 教材：三份材料给了三个书单

| 来源 | 书单 | 性质 |
|---|---|---|
| **官方目录** | ① Tan, Steinbach, Karpatne, Kumar, *Introduction to Data Mining*, Pearson **2019**<br>② **Aurélien Géron, *Hands-On Machine Learning with Scikit-Learn and TensorFlow*, O'Reilly, 2017** | **Compulsory Readings（必读）** |
| **Syllabus** | ① Tan et al. **2019**（ISBN-13 978-0133128901）<br>② **Albright & Winston, *Business Analytics*, Cengage 2014** | **optional** |
| **W1 讲义 p.4** | ① **DM** = Tan, Steinbach, **Kumar**, *Introduction to Data Mining*, ISBN **0-321-32136-7, 2005**（**第 1 版**！）<br>② **HM** = *Hands-On Machine Learning with Scikit-Learn & TensorFlow* | **"Required Textbook"** |

**结论与取舍**

- **DM = Introduction to Data Mining；HM = Hands-On Machine Learning（Géron）。** 讲义每一讲的 "Reading Material" 都用这两个缩写：W1 = DM Ch.1 + HM Ch.1；W2 = **HM Ch.4**。
- **⚠️ 版本冲突**：W1 讲义写的是 **2005 年第 1 版**（ISBN 0-321-32136-7），Syllabus 和官方目录写的都是 **2019 年第 2 版**（978-0133128901）。两版章节编号不同，**按章号找内容时要注意用哪一版**。采信 **2019 第 2 版**（两份文件对一份，且是新版）。
- **⚠️ 必读/选读冲突**：官方说必读、W1 讲义说 Required、Syllabus 说 optional。**采信"实质上必读"**——因为讲义每讲都指定了具体章节，这已经是事实上的必读。
- Albright & Winston 那本只有 Syllabus 提，讲义从未引用；官方把它列在 Additional Readings。**优先级最低。**
- 官方 Additional Readings 还有：Linoff *Data Analysis Using SQL and Excel*（2015）、Mayer-Schönberger & Cukier *Big Data*（2013）、Foreman *Data Smart*（2013）、Mayes & Shank *Financial Analysis with Microsoft Excel*（2006）。**这四本讲义全没提，属于官方目录的历史残留。**

## 6. L0 基线的官方依据

官方目录写死了一条先修：**"Prerequisites: Basic knowledge on statistics"**。

**它说了什么**：进这门课，学校认为你应该会**统计学基础**（分布、均值/方差、正态分布、假设检验、p 值这一层）。

### 9.3 ⚠️ Project Guideline 自身的三处矛盾

1. **Briefing 到底是 W5 还是 W6？** Guideline 说 "Due: **End of Week 5**"，但 Syllabus 和 W1 讲义的课程表里 **W6 才是 "Project Briefing"**。Guideline 自己下面又写 "detailed instructions, guidance, and training will be provided in **Week 5** (lecture + tutorial)" 和 "Preview: **Week 6** will be an engaging and meaningful session"。
   → ⚪ **最可能的真实安排**：W5 讲怎么写 proposal，W5 末交书面 proposal，**W6 上台做 briefing**。但这只是推断，**必须在课上或 Canvas 确认**。按最早的日期准备（W5 末 ≈ 2026-10-02/03）最安全。
2. **"Due by May 1"** —— 本课是 **Semester A（9 月–12 月）**，5 月 1 日是 Semester B 的时间。这是**上一学年 Guideline 的复制残留**，日期不可信。真实截止日应在 W13 之后（⚪ 推算 2026-11 月底至 12 月初），**必须以 Canvas 为准**。
3. **组队人数** —— Guideline 写 "max **6** students"，Syllabus 写 "maximum … is **5**"，官方目录写 "**4 to 6**"。
