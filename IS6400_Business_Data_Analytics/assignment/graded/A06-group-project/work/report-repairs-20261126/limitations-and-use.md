# 写作时保留的边界

1. 源导出缺修改/入库日志，静态金额/州、支付等扩展属性及预计送达承诺的历史可得性仍有假设。已核事件截断不等于证明源系统从未回写或漏采。本包修的是表述与可追溯性，不虚构不存在的日志。
2. 模型原始加权输出用于排序，不直接称客户自然复购概率。概率扩展是独立校准协议，不与核心run拼接。
3. 一月已反复用于开发，四月也有历史结果；新字段实验不是新盲测。三个跨期窗口和客户重叠，不能相加当独立样本。
4. 反映历史购物行为的群差异、名单交换和捕获金额都不证明营销因果增量。当前数据没有成本、毛利或真实干预，不能声称利润或长期CLV改善。
5. 严格全流程折内聚类CV不在主线必需范围；现有群CV明确条件，不以它证明完整端到端泛化。原历史训练软件/优化日志没有的部分不由今天的环境倒填。
6. 3个新模型与其输入和分数可在本机私有目录加载回放，公开仓库只存聚合证据。旧成员数据/ZIP保留原件，不将新增实验或Codex生成内容写成某成员亲自执行。
7. 本包是可开始分工写正文的证据/方法/图表包。封面个人信息、成员最终认领、正式全文通读、Canvas最终格式和实际提交是后续真实步骤，不标为已经发生。
