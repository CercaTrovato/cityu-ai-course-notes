|---|---|---|---|

| 回归分析 | Regression Analysis | A statistical procedure used to develop an equation showing how the variables are related | M02 §2.2 |

| ⭐ 因变量 | **Dependent Variable**（统计学家）<br>= Target Variable（数据挖掘）<br>= Response Variable（社会科学） | **"The thing you want to predict"** | M02 §2.2.1 |
| IV / DV | Independent Variable / Dependent Variable | 讲义常用的缩写（p.39 "How many **IVs**…"） | M02 §2.2.1 |
| ⭐ 简单线性回归 | Simple Linear Regression | **"To predict the value of one dependent variable on the basis of another independent variable"**：`Y = β₀ + β₁X` | [[M02-预测分析-线性回归#2.5.1 公式与三个符号（讲义 p.14–15）\|M02 §2.5.1]] |
| 截距 | Intercept (β₀) | **"Constant or intercept"** —— the predicted value of Y when X = 0 | M02 §2.5.1 |
| ⭐ 斜率 / 回归系数 | Slope / Coefficient (β₁) | **"the change of sales when the egg price increases 1 unit… how sensitive the value of Y is to changes in X"**（多元回归里要加上 **holding other variables constant**） | M02 §2.5.1 |
| 随机误差项 | Random Error (ε) | The part of Y the model cannot explain; assumed **ε ~ N(0, σ²)** | M02 §2.5.1 |
| ⭐ 线性回归四假设 | Assumptions of Linear Regression | **(1)** The relationship between X and Y is **linear**; **(2)** Y is distributed **normally** at each value of X; **(3)** The **variance of Y at every value of X is the same** (homogeneity of variances); **(4)** The observations are **independent** | [[M02-预测分析-线性回归#2.5.2 四条假设（讲义 p.17–18，⭐ 必考）\|M02 §2.5.2]] |

| 曲线拟合 | Curve Fitting | Selecting β₀, β₁ … such that they provide **the best fit, or the minimal errors between the data and the model** | [[M02-预测分析-线性回归#2.5.3 曲线拟合：怎么定义"最好的那条线"（讲义 p.19, p.28）\|M02 §2.5.3]] |

| ⭐ 协方差矩阵 · 特征值 · 特征向量 | Covariance matrix $S = D^{\top}D$ · Eigenvalue · Eigenvector | For mean-centered $D$, eigenvectors of $S$ are the PC directions, eigenvalues their variances; $D' = DU_{\text{reduce}}$, $z = U_{\text{reduce}}^{\top}x$ | M04 §2.14 |
| 特征值 > 1 准则 · 累计方差 | Eigenvalue-greater-than-1 rule · Cumulative proportion | With a correlation matrix keep components with eigenvalue > 1 | M04 §2.15 |

| 噪声点 | Noise point | Any point that is neither a core point nor a border point.（p.62） | M05 §2.9.1 |

## 13. 译名注意事项（本课内部）

| English | 本课采用 | 不用 | 理由 |
|---|---|---|---|
| Bias | **偏差**（统计语境） | 偏见 | 全库规则：伦理语境用"偏见"，统计语境（bias-variance、omitted variable bias）用"偏差" |
| Dependent / Independent Variable | **因变量 / 自变量** | 应变量 / 独立变量 | 讲义给了三套英文叫法，中文统一 |
| Validation Set | **验证集** | 校验集、开发集 | ⚠️ 必须与 **Test Set（测试集）** 严格区分 |
| Regularization | **正则化** | 规则化 | ⚠️ 与 **Normal Equations（正规方程）** 区分，两者无关 |
| Overfitting / Underfitting | **过拟合 / 欠拟合** | 过度拟合 / 拟合不足 | 学界通用 |
| Principal Component Analysis | **主成分分析** | — | ⚠️ **Syllabus、W1 讲义 p.6、W4 讲义 p.68–69、T04 notebook 都拼成了 "Princip**le**"，正确是 "Princip**al**"**。考试写英文时别跟着错 |
| Feature Reduction | **特征约简** | 特征降维、特征缩减 | 讲义 p.48–49 与 Feature Selection 对举；"降维"留给上位词 Dimensionality Reduction（两者都是它的手段） |
| Impurity | **不纯度** | 杂质度、不纯净度 | Gini / 熵的统称；"纯度"（purity）是它的反面 |
| Filter / Wrapper model | **过滤模型 / 包装模型** | 筛选式 / 封装式 | 与 sklearn 中文社区常用译法一致；第三类 Embedded 译"嵌入式" |
