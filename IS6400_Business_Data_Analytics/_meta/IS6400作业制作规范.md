# IS6400 作业制作规范：能复做，也让老师读得顺

本规范是 IS6400 课程层唯一的作业细则，适用于个人 Notebook 作业和项目代码分析，继承全局 [[作业规范]]。学习/提交分工、正文不加粗文字、自然表达、末尾一句 AI 声明和安全验收统一按全局，不另设相反默认。具体周次题目、截止、分值与文件要求在各 Axx 任务说明核定。依据是前三周原始题目、已有提交的实际代码和文字，以及 2026-09-30 核对的 Canvas。历史提交的详细复盘保持私有；这里只保留可迁移的方法和验收要求。

## 1. 沿用什么，改进什么

| 前三周可沿用的做法 | 后续固定要求 |
|---|---|
| W01 保留原教程，在答案处说明自己对含糊题意的理解 | 从老师原件的副本续写；题目、代码示例和顺序保留。题意有冲突就写明采用口径 |
| W02 对比模型时固定划分与随机种子 | 比较对象共享训练／验证行和评价指标；只有被研究的因素变化 |
| W03 先写分析目的，再给代码、结果和数字解释 | 每个分析单元形成完整阅读顺序，避免一段代码后面只写“效果很好” |
| W03 遇到题目预设与数据不符，展示真实结果及原因 | 不伪造缺失值、差异或改进来迎合题面；保留核对证据 |
| W03 讨论样本量、异常值和相关关系的局限 | 必答之外必须有基于结果的理解、拓展检验及限制，见 §5 |

需要改进的地方也成为门槛：不能把“代码运行成功”当成数学问题已经答对；不能先对全数据学习编码再划分；表格、正文和图注中同一个数值的精度要一致；长代码块要拆成可理解的步骤，输出后解释具体数字；减少重复表格和连续大段文字。

## 2. 先锁定现行题目，再开始续写

每次开始及定稿前核 Canvas Assignments、Announcements、Files、Modules。记录任务 ID、四入口、当前附件名、题目小问、截止时区、允许格式、评分与版本哈希。旧件不删，也不继续套旧题：题号、分值或任务有变化，说明新旧差异。

Canvas points 与 notebook 内部评分分开记。例如 W04 当前 Canvas 10 分，四题内部合计 100 分。不要自己假定课程总评折算比例，也不要根据上周规律推定正式截止。

原件在 `course_files_export/` 只读。复制到 `assignment/graded/Axx/work/` 后续写，文件名沿用已核实的学生身份；新增环境／路径设置可放在教程前，答案按原题编号出现。原单元格的实质内容和相对顺序须能逐格比对。作答副本保留原题、示例代码与教学次序；可删除教师文字中的强调标记以符合全局段内不加粗规则，不改变题意，并记录这类纯格式差异。新增的私人操作、自测和提交检查必须移出可提交 Notebook。

## 3. Notebook 的阅读顺序

提交 Notebook 按原题顺序作答：先说本题方法和参数，再给代码、输出与具体解释。语法课、软件操作、自测和内部核对移到私人中文导览；不能把每段都写成带固定标签的教程。答案仍须让老师看懂输入、结果与依据。

私人学习导览按 Python 零基础写。首次遇到变量、函数、循环、参数、索引、布尔掩码、路径和 sklearn API，给最小例子与逐行解释，并对应到正式 Notebook 的代码；后续一句唤醒即可。正式答卷保留必要算法原理和数据处理依据，不逐行教老师 Python。

老师评阅部分采用自然、直接的英文学生语言：每个结论带具体结果，词义清楚，不写浮夸意义、空泛“深刻洞见”或复杂套话。中文导览解释操作和知识衔接；英文 Notebook 保留完整实际分析。完整教学解释必须在私人导览实际写好，不能用空链接代替。提交稿中不出现面向用户的学习确认、下一步上传、自查问答、SHA-256 和工作区管理信息。正常的数据来源和方法引用继续保留。

优先维持一个连续 Notebook 和一份有实质内容的中文学习入口。其他文件仅用于真实需要的源代码、数据结果或验收记录。未完成练习只登记在索引，不制造几十份空 tutorial。

## 4. 正确性与复现

### 4.1 题意、公式、代码、结果同时核对

为每小问登记“要求 → 所在小节 → 代码 → 输出 → 解释”。至少抽核一处能手算的数值：例如合成数据系数、F 统计量、误差指标或标准化结果。描述目标函数的公式必须与代码相同；报告 MAE、MSE、RMSE 时核实际计算，不能改标签冒充指标。

代码使用未舍入数值完成拟合、选择和汇总，展示才格式化。检查数据行数、列名、目标类型、缺失、训练与测试索引、特征数量和有限预测。断言只核输入／计算关系，不把预期答案硬编码成自动通过，也不把“测试没报错”说成模型质量好。

### 4.2 预测评估与描述性分析的边界

涉及预测或泛化评估时，划分后才拟合填补、缩放、编码和选择。交叉验证中的预处理必须在每个训练折内部拟合；嵌套验证时，特征选择也只能看到外层训练行。选择时用过的 CV 分数称选择分数，不当成独立测试分数。测试结果用于最终一次评估，不能看到后再改参数并继续称其为“未见测试”。

纯描述性聚类可对其所描述的全体样本拟合预处理与模型，但必须说明距离、样本和选择口径，不把该数据上的轮廓系数或调参结果称为独立测试成绩。

报告目标的单位与变换：`log_price` 的误差是对数价格单位，不是美元；直接取指数不自动得到无偏美元预测。ID、目标、从目标派生的价格排除，说明原因。类别编码后选择的是哪一级别须明确；不同方法比较必须共用候选矩阵。

### 4.3 从空内核运行，检查实际成品

固定并记录软件版本、随机种子、划分、模型和选择参数。用空内核按单元格顺序执行，数据路径从一个明确入口开始；避免依赖其他 Notebook 的变量。导出后查错误输出、缺图、乱码、悬空链接和未渲染公式；下载源文件的哈希与完成前后比对。

## 5. 加分深度是必做项

完成题目以后，至少增加一个明确问题的检验，提出自己的判断并说明局限。合适的问题包括：两种选择是否实际改善测试误差、贪心选择是否错过更好子集、样本变动是否影响结论、指标和业务目标是否一致、相关特征是否冗余、模型重要性是否被误解成因果效应。

拓展必须真的计算或有可靠材料依据。不能只写“未来可以分析”，也不能堆模型名称来冒充深度。新增复杂度应带来可以解释的证据。即使拓展发现原方法没有改善，也要如实报告，这仍体现理解。

保留教师规定的 Figure／Table 顺序。新增拓展使用独立附录编号 `Figure A1`、`Table A1` 等，在正文引用。教师若禁止附录或限制篇幅，改用允许范围内的精炼分析；不挤掉规定图表。W04 当前题面未要求图表编号、篇幅或六位精度，本次主动采用六位展示，必答表为 Table 1–6，拓展为 Table A1–A5 与 Figure A1。

## 6. 人工阅读、公式与一致性

HTML 默认正文 **18 px、行距 1.65**，正文最大宽度约 1080 px；代码约 14–15 px，表格至少约 16 px。屏幕上阅读舒适后再检查窄窗口和打印。宽表允许在独立容器滚动，不能把全篇字号缩小。长特征名允许换行，指标列右对齐。

所有答案、解释、表格、图形和字号设置先在 `.ipynb` 完成并保存。**提交 HTML 必须由 Jupyter 菜单或标准 `nbconvert --to html` 从该 Notebook 直接导出**，保留相同的单元格顺序、内容与输出；不得另写 HTML 页面、重排原教程、隐藏单元格或单独维护报告。`export_html.py` 如保留，只允许调用标准 HTMLExporter 并保存返回结果。首页身份和题目也来自 Notebook，导出后只核查，不另改 HTML 内容。标题能说明这一节做什么，正文小段落，代码前后留空，图轴、图例与数值正常缩放下可辨。

数学用正确渲染的上下标、分式、根号和符号，Notebook 用 LaTeX。Jupyter 原生 HTML 的数学通常由 MathJax 渲染，导出后必须实际核查，避免只检查 LaTeX 源码。默认导出依赖联网加载 MathJax，不能冒称完全离线；如需离线版，要通过明确的标准导出资源配置处理。关键式子配符号、单位与数字例子；公式渲染后的视觉复核是独立验收项。

每次从现行要求确定精度表。没有特别要求时统计量、误差、相关系数及比例用六位小数，计数用整数，小 p 值用六位小数的科学计数法并说明下溢。科学计数法中的 0 不能被解释成真实概率为零。同一指标在表、正文、图注重复时完全一致。年份、学生信息、题号、模型标签、大小写、目标变量和单位也统一。原教程保留旧精度时明确它是原始教学区，学生答案遵循新精度。

## 7. 完成与提交门槛

| 门槛 | 必须拿得出的证据 |
|---|---|
| 来源 | 当前 Canvas 四入口核对、下载原件与 SHA-256、版本变化记录 |
| 完成度 | 每个小问直接答案、实际代码、输出与解释 |
| 零基础可学 | 每个新增代码步骤有目的、首次概念和语法解释、输出读法、排错 |
| 计算与复现 | 空内核执行、关键手算／关系复核、无泄漏、版本／种子、无错误输出 |
| 必做深度 | 已实施的拓展、具体证据、自己的解释与局限 |
| 阅读 | 足够字号、导航可用、公式实际渲染、图表编号及数字一致 |
| 行为状态 | 文件生成、验收、本人学会、Canvas 提交分别记录 |

缺任一必需项保持 `draft`。身份沿用已核实历史记录时写明依据，用户审阅后再提交。AI 辅助声明按全局 §5a：实际用过 AI 的答卷末尾默认一句话写工具名；有任务指定的额外要求再按其来源处理。源码、学习指南及完整答案保持本地私有，不进入公开 Git。
